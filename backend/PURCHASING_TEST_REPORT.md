### recordsCount 和 totalActualCost 计算 ✅

**测试场景:** 当采购清单包含采购记录时，系统应正确计算：
- `recordsCount`: 采购记录数量
- `totalActualCost`: 所有采购记录的actualCost之和

**实现位置:**
- `src/domain/purchasing/purchase-list.entity.ts:196-208`
- `src/infrastructure/repositories/prisma-purchase-list.repository.ts:include`

**验证方法:**
```typescript
// PurchaseList.fromPrisma()
if (data.records && Array.isArray(data.records)) {
  recordsCount = data.records.length;
  totalActualCost = data.records.reduce((sum: number, record: any) => {
    return sum + Number(record.actualCost);
  }, 0);
}
```
