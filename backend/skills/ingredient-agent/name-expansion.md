# 名字扩展

目标：**每个库，都要给它最可能命中的那些词**。一个词查不到，不代表这个库没有。

## 怎么扩展

对每个库，围绕下面几类写法各想一遍，挑 2–6 个最像的：

1. **正名**：用户原话。
2. **俗称 / 别名**：鸡蛋白、蛋清、蛋白。
3. **词序倒置**：鸡蛋清 ↔ 清鸡蛋（多数时候不成立，但值得想一下）。
4. **简繁**：简体给 CFCT，繁体给 TFDA（雞蛋白）。
5. **外语**：英文常用名与学名（egg white / albumen）；日文（卵白）；韩文（난백）。
6. **状态词**：生、熟、水煮、干燥、粉——只有当你需要区分生熟档案时才加。

## 怎么判断词够不够

- 每查完一轮，看返回的**每库命中数**；
- 某库 0 命中 → 这个词大概率不对：看别的库返回的名字长什么样，照着它的用词换一版再查（最多两轮）；
- 某库命中很多但你只看到前 20 条 → 换更具体的词（加部位/状态）再查。

## 不要做的事

- 不要指望系统替你翻译或扩展——没有词典，也没有自动翻译。
- 不要只查一个词就下结论说“这个库没有”。
- 不要把同一个词重复写进同一组。

## 交方案时

`findings` 里写清楚：**每个库用了哪些词、命中几条、你从中看到了什么**。
用户要靠这段话判断你有没有漏。
