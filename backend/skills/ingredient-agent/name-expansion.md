# 名字扩展

目标：每个库都要给到最可能命中的词。一个词查不到，不代表这个库没有。
工具不按语种分流：同一个词可以同时给多个库。

## 每个库想这几类词（挑 2–6 个）

1. 正名 + 俗称（鸡蛋白、蛋清、蛋白）；
2. 简繁：简体、繁体两套都要分别给 CFCT 和 TFDA 各一份（鸡蛋白 + 雞蛋白）；
3. 外语：英文常用名 / 学名、日文、韩文（egg white、卵白、난백）；
4. 需要区分生熟时加状态词（生、熟、水煮、干燥、粉）。

## 命中不够就重查

某库 0 命中或明显偏少 → 看别的库返回的名字怎么写的，照着换一版再查（最多两轮）；
命中很多但只看到前 20 条 → 加部位 / 状态词再查。

## 交方案

findings 写清：每个库用了什么词、命中几条、你看到了什么。
