# recipe-supplement

## 时机
- 只在 DESIGN 阶段、`assess` 出现明确营养缺口后使用。
- 先食物后补剂：能靠食材调整解决的，先调食材。
- 不要因为方案里写了某个营养素，就提前加补剂。

## 可选范围
- 只选原料库里的补剂，不用库外产品。
- **只选已开启“生产/采购”开关的补剂**；未开通的不能推荐、不能加。
- 必须有可用的每份/每粒营养档案，能算出实际含量。

## 建议方式
1. 从 `assess` 的缺口里找到还差多少。
2. 用 `find_food` 按名称/营养素找库内补剂。
3. 计算：
   - 当前值、目标值、还差多少；
   - 每个补剂单位补多少；
   - 建议几个单位；
   - 加入后对钠、脂肪、其他硬约束的影响。
4. 用 `ask` 告诉用户：缺什么、推荐哪个、每单位含量、建议用量、影响，以及“换一个/不加”的选项。
5. 用户确认后才 `edit_recipe` 添加；加完再次 `assess`。

## Omega-3 来源选择
- 需要补 omega-3（EPA/DHA）时，按以下顺序判断：
  1. **无海产过敏/忌口**：优先鱼油、磷虾油、多脂海鱼等动物来源。
  2. **海产过敏/明确不吃海产**：优先**藻油**（裂壶藻等，直接含 DHA/EPA，不是海产；先确认无海产交叉污染/过敏原标注）。藻油不是动物来源，但它是直接的 EPA/DHA，不是亚麻籽油那种 ALA；这是海产过敏时允许的例外。
  3. **海产 + 蛋/禽都过敏**：只用藻油；没有藻油就明确说“没有可靠来源”，保留缺口。
  4. **海产过敏但可吃蛋/禽**：可考虑 DHA 强化蛋（动物来源、非海产），但必须有可信的 DHA 数据；数据不足就不要硬凑。
- 不要用亚麻籽油、亚麻籽、奇亚籽、火麻籽等植物 ALA 作为 EPA/DHA 的替代；植物 ALA 转化有限，不能按 1:1 计入。
- `find_food` 按 `dha` / `epa` / `鱼油` / `藻油` 查，不要只搜“omega”；植物油命中“omega”不等于有 EPA/DHA。
- 先看评估缺口是 EPA/DHA、亚麻酸还是亚油酸；不要把亚麻籽油同时当成 omega-3 和 omega-6 的万能补丁。
- 加鱼油/藻油时同时看脂肪、能量和胰腺炎脂肪上限；不能为了补 omega-3 破脂肪约束。
- 过敏/忌口优先：海产过敏时鱼油、磷虾油、海鱼一律不用；藻油也要确认无海产交叉污染。

## 边界
- 无缺口不加。
- 不选未开通生产/采购的补剂。
- 不用补剂替代食物；补剂只补食物补不上的缺口。
- 不提药物、用药、处方或剂量。
