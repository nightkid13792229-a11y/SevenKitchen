## 1. 这是什么

SevenKitchen（赛文的食堂）是一套面向**狗狗鲜食厨房**的 SaaS + ERP：

- 顾客端：微信小程序，选食谱、看营养、下单、管理狗狗档案和订单；
- 员工端：同一小程序里的员工页面，处理订单、厨房、采购、库存、发货；
- 管理后台：Vue 后台，管理食谱、营养、订单、生产、采购、补剂、财务、客服和配置；
- 后端：一套 NestJS API，承载所有业务写操作和营养/订单/生产规则。

一句话：**把“食谱设计 → 营养计算 → 下单 → 采购/生产 → 发货 → 售后”串成一条可追溯的链路。**

---

## 2. 核心价值

1. **营养计算可解释**：不是拍脑袋配方，能量/营养按标准和算法算，能解释来源。
2. **历史可复现**：食谱快照、订单快照、库存流水，保证“当时为什么是这样”查得到。
3. **以销定产**：订单驱动采购、生产、发货，减少盲目备货。
4. **多角色协同**：顾客、员工、管理员各看各的，权限和状态边界清楚。
5. **知识库可追溯**：营养/健康结论要有来源和证据，不靠模型记忆。

---

## 3. 用户与场景

| 用户 | 主要场景 |
|---|---|
| 顾客（狗家长） | 建狗狗档案、看食谱、算饭量、下单、查订单、售后、补剂、定制食谱 |
| 员工 | 订单中心、厨房生产、采购、库存、打包发货、客服、补剂汇总 |
| 管理员/老板 | 食谱与营养治理、订单/售后、生产/采购/库存、补剂/试吃装、财务、配置、分析 |

---

## 4. 业务范围

- 狗狗档案 / 健康：体重、体况、生命阶段、疫苗、过敏、健康记录、分享。
- 食谱 / 营养：食谱设计、营养计算、营养治理、标准、食材库。
- 订单 / 支付 / 售后：鲜食订单、补剂订单、定制食谱订单、退款/售后。
- 生产 / 采购 / 库存 / 物流：排产、生产批次、采购 SKU、库存流水、发货。
- 补剂 / 试吃装：独立商品、订单、售后、等价组。
- 定制食谱：需求、报价、订单、交付、退款。
- 知识库 / 证据：来源登记、证据政策、引用锚点。
- 财务 / 客服 / 分析 / 配置。

---

## 5. 明确不做

- 不做兽医诊断/治疗建议；健康内容只做营养/护理参考，边界见知识库证据政策。
- 不做开放式宠物商品 marketplace；商品和食谱由自己维护。
- 不用“模型记忆”替代营养库/知识库；AI 输出必须可追溯。
- 不在页面里写业务公式/价格/状态机；规则在后端领域层。

---

## 6. 质量原则

- **数据准确**：字段、单位、时区、金额口径统一；不猜字段名。
- **历史可追溯**：快照/流水/状态历史，不靠删记录“修正”。
- **逻辑显性**：营养/订单/库存规则集中，不散落在多个 controller/页面。
- **角色隔离**：CUSTOMER / STAFF / ADMIN 各端权限分开。
- **小步可回滚**：一次只改一个关注点，先测试后重构。

## 8. AI 协作边界

- AI 是执行者，不是产品经理/架构师/营养专家；业务规则变更要人确认。
- 改代码前先读 `AGENTS.md` + 对应领域文档；字段以 schema 为准。
- 不自动部署/发布小程序；部署按 `AGENTS.md` 的授权和门禁执行。
- 文档与代码冲突时，以代码/schema 为准，并顺手修文档。
