# B3S标签打印机连接故障排查指南

## 问题描述
在生产管理板块打印标签页面，可以搜索到B3S标签打印机，但点击无法连接，打印设置中一直显示"未连接"。

## ⚠️ 重要修复

### SDK初始化配置（已修复）
**问题**: 精臣SDK需要设置编译平台为uniapp，否则蓝牙功能无法正常工作

**修复位置**: `miniapp/src/utils/jcing-printer.ts`

```typescript
// 初始化SDK：设置编译平台为uniapp（必须在SDK使用前调用）
JCAPI.setBuildPlatform('uniapp');
```

**如何验证**:
1. 打开微信开发者工具控制台
2. 查找日志：`[JCPrinter] SDK已初始化，编译平台: uniapp`
3. 如果看到此日志，说明SDK配置正确

## 故障排查步骤

### 第一步：检查打印机状态

#### 打印机是否开机？
1. 查看打印机左侧指示灯
2. **绿灯常亮** = 已开机 ✓
3. **无灯光** = 未开机，按一下左侧电源键

#### 打印机是否在配对模式？
1. 正常开机后，绿灯应该**快速闪烁**
2. 如果绿灯**常亮不闪**，说明被其他设备连接了
3. 解决方法：
   - 长按电源键直到红灯闪烁（关闭蓝牙）
   - 再次按一下电源键（重新开启蓝牙）
   - 确认绿灯快速闪烁（配对模式）

### 第二步：检查手机蓝牙

#### 蓝牙是否开启？
1. 打开手机"设置" → "蓝牙"
2. 确保蓝牙开关已打开

#### 距离是否合适？
1. 手机和打印机距离在 **2米以内**
2. 中间不要有太多障碍物（墙壁、金属等）

#### 重启手机蓝牙
1. 关闭手机蓝牙
2. 等待5秒
3. 重新打开手机蓝牙

### 第三步：清除旧的配对记录

#### 在手机蓝牙设置中
1. 找到已配对的"B3S"或类似名称的设备
2. 点击"忽略此设备"或"取消配对"
3. 重新在小程序中搜索连接

### 第四步：检查小程序权限

#### 蓝牙权限
1. 微信 → "我" → "设置" → "通用" → "微信蓝牙"
2. 确保蓝牙功能已开启

#### 位置权限
1. 微信 → "我" → "设置" → "通用" → "地理位置"
2. 确保位置权限已开启（扫描蓝牙设备需要）

### 第五步：重启小程序和打印机

#### 重启打印机
1. 长按电源键直到指示灯熄灭
2. 等待3秒
3. 按一下电源键重新开机
4. 确认绿灯快速闪烁

#### 重启小程序
1. 完全关闭微信（从后台清除）
2. 重新打开微信
3. 进入小程序

## 常见问题

### Q1: 搜索不到打印机
**可能原因**:
- 打印机未开机
- 打印机不在配对模式
- 手机蓝牙未开启
- 距离太远

**解决方法**:
1. 确保打印机开机且绿灯快速闪烁
2. 确保手机蓝牙已开启
3. 将手机靠近打印机（2米内）

### Q2: 搜索到但连接失败
**可能原因**:
- 打印机被其他设备连接
- 蓝牙配对记录冲突
- 蓝牙适配器未初始化

**解决方法**:
1. 在手机蓝牙设置中"忽略"打印机设备
2. 重启打印机蓝牙（长按电源键后重新开启）
3. 重启手机蓝牙
4. 重新在小程序中连接

### Q3: 连接成功但无法打印
**可能原因**:
- 打印机缺纸
- 打印机盖子未关好
- 数据传输失败

**解决方法**:
1. 检查打印机是否有纸
2. 确认打印头盖已关闭
3. 重新尝试打印

## B3S打印机快速参考

### 指示灯状态
- **绿灯常亮**: 已开机，已连接
- **绿灯快闪**: 已开机，配对模式（可连接）
- **红灯快闪**: 关闭蓝牙中
- **无灯光**: 关机

### 操作按键
- **短按电源键**: 开机 / 开启蓝牙
- **长按电源键**: 关机 / 关闭蓝牙

### 配对模式
1. 打印机开机后自动进入配对模式（绿灯快闪）
2. 如果被连接过，需要：
   - 长按电源键关闭蓝牙（红灯快闪）
   - 短按电源键重新开启（绿灯快闪）
