Temporary Alignment Artifacts
=============================

- Files in this directory are **TEMPORARY alignment artifacts** for human review only.
- They are **NON-AUTHORITATIVE** and must **NOT** override or extend:
  - `docs/07_Core_Architecture.md`
  - `docs/04_Domain_Model_and_Algorithms.md`
  - `docs/05_API_Specs.md`
- Lifecycle: after a patch is accepted or rejected, the related alignment files must be archived to `docs/_history` or deleted.
- Explicitly forbidden as inputs for:
  - database schema design
  - Prisma models
  - migrations
  - domain/entity definitions
  - algorithm definitions
