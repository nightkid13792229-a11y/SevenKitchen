## 使用规则

1. 可以引用，但要标明“历史记录，不代表当前实现”。
2. 新计划不默认新建长期文档；直接写进任务工位/提交说明，确需长期保留再和用户确认放哪。
3. 不要为了让旧文档“看起来对”而大改正文；需要时在文首加一行状态说明。
4. 活文档索引见 [docs/README.md](../README.md)。
