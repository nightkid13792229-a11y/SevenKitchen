## 项目从初期到现在，功能一共经历了哪些变化

### 阶段 1：项目骨架、订单持久化、生产与发货闭环（2025-12-16 ~ 2025-12-21）

- 完成项目初始结构搭建，并补齐 Phase 8 系列的对齐、验收和验证文档。
- 上线狗狗能量计算服务 `DogCalcService`，为后续喂食建议和订单计算打底。
- 给订单补齐 `dailyIntakeG` 快照、能量密度持久化和订单项来源字段。
- 给生产批次增加分配锁，避免同一批次被重复分配。
- 上线厨房任务数据采集 MVP，开始记录生产执行过程。
- 上线厨房任务扣减库存能力，把生产执行和库存变化打通。
- 上线发货履约与订单完成链路，形成订单从生产到发货再到完结的主流程。
- 建立订单验证工作流、Prisma 迁移修复和腾讯云 Lighthouse 部署基础设施。

### 阶段 2：狗狗档案、犬种库、后台管理初版（2025-12-23 ~ 2025-12-30）

- 上线狗狗档案录入和喂食建议展示功能。
- 导入 200 个犬种数据库，并按 AAHA 标准管理基础数据。
- 补齐混种狗、自定义品种、虚拟品种 ID 等兼容能力。
- 上线管理后台狗狗档案管理模块，并持续优化创建、编辑和展示体验。
- 上线管理后台犬种管理，包括分页、常用品种维护与后台配置。
- 上线原料管理模块，支持原料表格展示、补剂种子数据和排序优化。
- 上线原料标签管理和自动补全。
- 后端新增用户模型、主人信息接口、管理员登录认证和短信 / 微信能力。
- 管理后台新增用户管理与认证 UI，小程序新增登录页和 API 基础能力。

### 阶段 3：健康标签、定价链路、DIY 流程和采购生产重构（2026-01-01 ~ 2026-01-14）

- 完成健康标签架构迁移，扩展围绕食谱、原料与展示层的健康标签能力。
- 上线购物车、价格系统、运费模板，随后又移除购物车，改造为更贴近业务的 DIY 制作单流程。
- 上线 DIY 制作单功能、订单状态系统和图片上传重构。
- 给食谱订购页增加生命阶段不匹配警告，提升下单前校验。
- 上线食谱收藏功能，并修复收藏数量统计。
- 对采购清单、采购记录、采购 API 和管理后台采购模块做了完整重构。
- 上线生产管理相关改造，小程序也补齐采购管理、生产管理入口。
- 给订单、采购、生产链路补齐多份测试文档、人工验证报告和 AI 协作规范。

### 阶段 4：采购 / 生产深化、打印链路、健康记录与报销增强（2026-01-17 ~ 2026-01-31）

- 持续优化采购和生产管理模块，并新增打印能力。
- 统一修复采购与生产管理中的时区问题，抽出前后台通用日期工具。
- 小程序接入标签打印 SDK，补齐订单 API、打印份数修复和数据清理脚本。
- 订单状态从 `WAITING_FOR_PRODUCTION` 重构为 `PURCHASING`，采购状态流转更加贴合业务。
- 给狗狗管理补齐健康记录、病史 / 体检附件删除与 COS 同步删除。
- 上线过敏记录完整 CRUD、附件上传、立即保存与前端交互。
- 报销单新增费用明细、费用汇总、重提回填、详情展示和 API / 数据库支持。
- 小程序生产环境构建配置与 API 地址识别能力完成修复。

### 阶段 5：微信能力、分享、PDF 制作单、权限修复（2026-02-01 ~ 2026-02-11）

- 上线用户头像、昵称展示与微信头像昵称填写功能。
- 小程序首页、食谱详情页、收藏页接入分享能力，并补齐分享图配置。
- 完成开发库与生产库的数据库同步、迁移脚本整理和历史脚本归档。
- 上线生产任务 PDF 制作单生成、中文字体支持、COS 上传与打印接口。
- 持续优化 PDF 排版、A4 自适应、预览布局和字段稳定性。
- 从小程序移除评价、发货管理和完成订单功能，收敛用户端边界。
- 修复管理员 / 员工在小程序端查看采购单、报销单、订单详情的权限问题。
- 修复常用品种点选、后台常用品种数据源、标签字体和图片上传等问题。

### 阶段 6：标签、封面、食谱设计、环境隔离与分享照片（2026-03-03 ~ 2026-03-30）

- 上线原料照片分享功能。
- 上线后端标签图片生成 API，让预览和打印统一走后端渲染。

- 上线食谱封面标题、食谱设计功能模型，并补齐封面批量重新生成接口。
- 后端新增营养食品能力，小程序补齐隐私政策和用户协议页面。
- 上线环境隔离配置和统一部署脚本，并强化部署时健康检查和服务重启。
- 修复购买链接跳转、DIY 制作单跳转、新用户首次登录存储等问题。
- 修复首页食谱排序、生命阶段匹配、生产批次删除误删已完成订单等关键问题。

- 启动标准原料 SKU 解耦设计，明确标准原料、DIY SKU、采购 SKU 三层分离。

- 启动财务中心设计并把财务与采购后台版本合流发布。
- 重做狗狗档案创建流程，拆分为向导式多步页面，并补齐概览页、专注编辑页和分析页。
- 修复狗狗创建权重校验、预览门槛、数据标准化和 CORS 发布问题。
- 优化犬种搜索、别名管理和热门犬种自动化维护。
- 优化狗狗头像上传流程，小程序新增头像裁剪能力。
- 修复食谱统计刷新、DIY 制作单推荐文案、首页筛选确认动作和启动流程。
- 启动标准原料统一营养档案结构化改造，先完成后端营养结构标准化与兼容写入。

## 按业务模块归纳，项目改过哪些功能

### 1. 狗狗档案与犬种体系

- 狗狗档案创建、编辑、详情展示、喂食建议。
- 混种狗、自定义品种、虚拟品种 ID 兼容。
- 200 犬种库、常用品种、热门品种、犬种搜索和别名管理。
- 狗狗档案向导式创建流、概览页、专注编辑页、分析页。
- 头像上传、头像裁剪、昵称展示、主人信息与个人资料完善。
- 病史、体检、过敏记录、附件上传删除、健康记录立即保存。

### 2. 原料、营养、食谱与标签体系

- 原料管理、补剂管理、原料标签管理、自动补全。
- 健康标签架构迁移与营养食品能力。
- 食谱收藏、生命阶段匹配校验、首页排序修复。
- 食谱封面标题、食谱封面批量重生成功能。
- 食谱设计能力与封面 / 元数据渲染优化。
- 标签打印、后端标签图片渲染、真机字体与排版修复。
- 标准原料、DIY SKU、采购 SKU 解耦与营养档案结构化改造。

### 3. 订单、DIY、发货与分享

- 订单创建、快照、状态系统、付款确认、发货履约、完结链路。
- DIY 制作单、购买链接、订单分享照片、分享入口和页面跳转修复。
- 订单详情、狗狗信息展示、历史快照与配方快照修复。
- 订单统计、收藏统计和相关审计工具。

### 4. 采购、库存、生产与厨房

- 采购清单、采购记录、采购渠道、采购预览、采购金额展示。
- 采购状态重构为 `PURCHASING`，与订单 / 生产联动。
- 生产管理、厨房任务采集、库存扣减、生产批次分配锁。
- PDF 制作单生成、打印支持、字体支持和预览优化。
- 删除生产批次时的数据保护，避免误删已完成订单。

### 5. 财务、报销与后台管理

- 管理后台用户管理、认证、收款确认。
- 报销单费用明细、公式汇总、详情增强、权限与列表修复。
- 财务中心设计、财务与采购后台发布合流。
- 全局配置、图片上传修复、后台 API 与菜单补齐。

### 6. 小程序体验与微信生态

- 小程序登录、自动重试、API 工具、环境切换。
- 分享、头像昵称、隐私政策、用户协议。
- 标签打印 SDK、订单与员工工作台入口。
- 启动流程、筛选抽屉确认动作、首页反馈入口、页面布局和文案优化。

### 7. 基础设施、测试、部署与治理

- Prisma 迁移补齐、生产库同步、迁移恢复和命名规范文档。
- CI 验证工作流、E2E / 验证脚本、手工验证文档。
- 腾讯云 Lighthouse 部署套件、统一部署脚本、健康检查。
- 只读生产库审计、SKU 治理设计文档、营养录入设计与实施计划。
