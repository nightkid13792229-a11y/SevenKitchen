## 一、先说一个必须先处理的风险（实测发现）

**上一轮（2026-09-17）的合规清理只删除了「健康标签」，没有处理「封面角标」与「说明文案」。**

线上实测（2026-09-18，24 道公开食谱）：

### 1.1 封面角标含疾病名（出现在首页货架最显眼处）

| 食谱 | 封面角标 |
|------|----------|
| 兔里脊大米土豆 | **IBD**（炎症性肠病） |
| 糙米西葫芦牛肉 | **草酸钙结石** |
| 小米山药猪肉 | **胆泥淤积** |

> 这三道菜的「IBD / 草酸钙结石 / 胆泥淤积」标签，**在上一轮已作为标签被删除**（见上一轮记录），
> 但**同样的词仍然以「封面角标」的形式对外展示**，且封面角标比标签更显眼（在首页橱窗卡片上）。

### 1.2 说明文案含疾病名与治疗建议

| 食谱 | 实测文案（节选） |
|------|------------------|
| 兔里脊大米土豆 | 「成年犬 **IBD/慢性肠胃敏感**支持型食谱…不等同于兽医**处方**粮，也不用于替代诊断、药物或个体化**治疗**」 |
| 糙米西葫芦牛肉 | 「**草酸钙结石**无法通过饮食或者药物溶解，只能延缓结石增大和防止复发。请密切观察毛孩子，如果出现梗阻，请立刻送医！！！」 |
| 小米山药猪肉 | 「适用于成犬，轻微**胆泥淤积**或并发轻微**高脂血症**。！！！不适用于**胆管梗阻**、并发**胰腺炎**、**肝衰竭**等重症」 |

### 1.3 违反了什么

《宠物饲料标签规定》**第二十条第（一）项**：

> **禁止对宠物饲料作具有预防或者治疗宠物疾病的说明或者宣传。**

- 三个封面角标是**疾病名称**；
- 三段说明是**疾病状态的适用说明与处理建议**，其中「延缓结石增大和防止复发」构成**预防性说明**。

且这些内容**出现在首页商品橱窗**，属于对外宣传，不只是内部数据。

> ⚠️ **结论：这是当前的最高优先合规风险，必须先于「特殊需求专区」处理。**
> 因为专区本身没有合规问题，**不合规的是被放进专区的内容**。

## 二、法规关键条款（本次确认的依据）

| 条款 | 内容 | 对我们的含义 |
|------|------|--------------|
| **第二十条（一）** | 禁止作具有**预防或治疗宠物疾病**的说明或宣传 | 疾病名、疾病状态的适用说明 **一律不能用** |
| **第二十条（二）** | 所有声称**应当具备证明材料**（出版物、教科书、配方组成、检测数据、试验报告） | 每个标签/角标都要能拿出依据 |
| **第五条（一）** | 为满足宠物**特定生理、病理状态**营养需要生产的配合饲料，通用名称**应当标示「处方」字样** | 「处方」是**法定产品类别**，不是营销词 |
| **第十二条** | 标「处方」的产品须按附录 5 标示适用状态，并在醒目位置标「**请在执业兽医指导下使用**」，且须能提供**科学试验数据及配方组成** | 「处方」路径的门槛极高，**我们不建议走** |
| **附录 5** | 列举「特定状态」表述（减少草酸盐结石形成、降低原料和营养素不耐受、改善消化不良、改善超重状态、改善皮肤炎症和过度脱毛、改善关节炎症…） | 这些**全部属处方产品专属**，非处方产品不能使用 |
| **第二十条（五）** | 功能声称**仅限非疾病性问题**（示例：预防毛球产生、预防牙垢聚集） | 只有「非疾病性问题」才可用「预防」 |
| **第二十条（三）** | 成分声称门槛：「含××」≥**4%**；「含××配方」≥**14%**；「××配方」≥**26%** | 「含三文鱼」这类词**要核对添加量** |
| **第二十条（四）4** | **低脂肪**声称的门槛（犬：水分>65% → 脂肪 ≤4%） | 需先算湿基脂肪 |
| **第二十条（四）5** | **低能量**声称的门槛 | 需先算代谢能 |
| **第二十条（三）7** | 「无××/不含××」**仅限原料与添加剂** | 「无防腐剂」可用；「无过敏原」不可用 |
| 《广告法》第十七条 | 非医疗广告不得涉及疾病治疗功能 | 同上，禁止疾病指向 |

> **一句话**：法规允许我们讲「**这袋里有什么、怎么做的、适合哪个生命阶段的狗**」，
> 不允许我们讲「**能治/能防什么病**」。
> 「低脂」「低能量」「易消化」这类**有明确门槛的词可以用，但必须先算数据、留证据**。

## 三、特殊需求专区：合规用词方案

### 3.1 核心原则

> **专区按「配方特征」分类，不按「疾病」分类。**

顾客带着"我家狗有情况"的需求来，我们要让他找得到，但**入口词必须是配方事实，不能是疾病名**。

### 3.2 词表（可直接落库）

#### ✅ A 类 · 可直接使用（成分事实，需标注添加量）

| 词 | 门槛 |
|----|------|
| 含三文鱼 / 含鳕鱼 / 含青花鱼 / 含兔肉 / 含鹿肉 / 含牛肉 / 含鸡胸 / 含火鸡 … | 该原料 ≥ **4%** 产品总重，且须在原料组成中标注添加量 |
| 含红薯 / 含南瓜 / 含藜麦 / 含糙米 … | 同上 |
| **单一动物蛋白** | 须核对配方确为单一动物源 ✅ 高价值词 |
| 无谷物 / 不含麸质 | 「无××」仅限原料与添加剂，可用 |
| 无防腐剂 | 同上，可用 |

#### ✅ B 类 · 可用但**必须先算数据并留证据**

| 词 | 前置条件 | 现状 |
|----|----------|------|
| **低脂肪** | 犬：水分>65% → 湿基脂肪 ≤4%；20–65% → ≤7%；<20% → ≤9% | ⚠️ 上一轮实测 7 个用「低脂」的食谱里 **4 个超标**，系统已有保存拦截 |
| **低能量** | 按第二十条（四）5 的能量门槛（ME 值） | 需新增校验 |
| **易消化** | 须提供可消化性数据或文献 | 需举证 |
| **鲜肉现制 / 低温蒸煮 / 冷链配送** | 须与实际工艺一致 | ✅ 与事实相符 |
| 符合 FEDIAF 2021 / 2025 | 须能提供检测报告或配方 | ✅ 已具备 |

#### ⚠️ C 类 · 无对应门槛但风险中等（建议慎用或改造）

| 词 | 问题 | 建议 |
|----|------|------|
| 高适口性 | 「高」属比较性声称，法规要求以**本企业产品为参照物**并明确列示 | 改为「**适口性优先**」或直接用风味声称「××味」 |
| 均衡营养 | 表述笼统、无依据 | 改为「**符合 FEDIAF 成犬维持**」（有依据的正面表述） |
| 适合春季食用 | 无任何法规依据，且无实际意义 | **删除** |
| 皮肤与毛发 | 附录 5「改善皮肤炎症和过度脱毛」属处方范畴，此词有功能暗示 | 改为「**含 Omega-3（三文鱼）**」等成分事实 |
| 体重管理 | 附录 5「改善超重状态」属处方范畴 | 改为「**低能量**」（须达门槛）或「**成犬维持**」 |

#### ❌ D 类 · 禁止使用

| 词 | 原因 |
|----|------|
| IBD / 肠胃敏感 / 软便 / 腹泻 / 呕吐 | 疾病或症状名 |
| 肾 / 肝 / 胆 / 胆泥淤积 / 胰腺炎 / 高脂血症 / 肝衰竭 | 器官病变名 |
| 草酸钙结石 / 尿酸盐结石 / 胱氨酸结石 / 鸟粪石 | 疾病名（且属附录 5 处方专属） |
| 关节 / 炎症 / 抗炎 / 肿瘤 / 控铁 / 控磷 / 低蛋白 | 疾病名或处方专属表述 |
| 低敏 / 抗过敏 / 不耐受 | 附录 5「降低原料和营养素不耐受」属处方专属 |
| **处方 / 处方粮** | **法定类别词，需兽医指导 + 科学试验数据，我们不满足条件** |
| 预防 ×× / 治疗 ×× / 改善 ×× | 第二十条（一）明文禁止（「预防」仅可用于非疾病性问题） |

### 3.3 推荐给顾客的专区入口形态

```
特殊需求选餐
不是"对症找药"，而是"按配方特征筛选"

┌─ 蛋白来源 ──── 单一蛋白 / 多种蛋白
├─ 脂肪水平 ──── 低脂（已达标食谱）
├─ 谷物 ──────── 含谷物 / 无谷物
├─ 能量密度 ──── 低能量（已达标食谱）
└─ 动物蛋白 ──── 兔 / 鹿 / 羊 / 鱼 / 鸡 / 牛 …
```

### 3.4 专区导语（建议文案）

> **如果你的狗狗有明确诊断，或正在遵医嘱进行特殊饮食，请先咨询执业兽医。**
> 我们的食谱是按犬营养标准（FEDIAF）设计的**日常鲜食方案**，不是药物，也不能替代诊断与治疗。

- ✅ 这段是**免责提示**，不是产品声称，可以使用疾病治疗相关字眼；
- ✅ 不承诺任何疗效，不出现"适用/不适用于 X 病"式的表述。
