## 二、第 1 条：置灰 + 一条"我还是想…"的路

### 问题
体况在理想区间（4-5）时，后端 `resolveSuggestedPlan` 按 FEDIAF 的口径**不给**任何
增减重建议，所以那个按钮点进去只有一句「当前体况属于理想区间，不需要增减重计划」——
顾客白跑一趟，还会以为功能坏了。

### 改法
- 体况理想（BCS 4-5，与后端同一套阈值）→ 按钮**置灰不可点**（保留在那里，
  让顾客看得见"本来有个入口"，而不是以为没了）
- 建议维持那句后面给两个文字入口：**「我还是想减重」「我还是想增重」**
- 点进去带 `direction=LOSS|GAIN` → 计划页原样传给后端
  `GET /weight-goal-plan/suggestion?direction=…`

### 一条不能松的边界
后端 `resolveSuggestedPlan` 新增 `forcedDirection`，但**只在系统本来没有建议时才听顾客的**：

| 体况 | 顾客坚持 | 结果 |
|---|---|---|
| 理想（4-5） | 减重 / 增重 | 按顾客说的方向给，并在方案说明里写明「它现在的体况属于理想区间，系统原本建议维持；这一版是按你要求的…方向给的」 |
| 偏胖（≥6） | 增重 | **仍按减重**（给偏胖的狗建增重计划不是自由，是危险） |
| 偏瘦（≤3） | 减重 | **仍按增重** |
| 理想（4-5） | 没坚持 | 仍旧不给建议（老行为不变） |

顾客坚持的方向同样走原有的安全边界（增重不超过维持能量的 1.4 倍、减重不低于
RER(目标)×0.6），增重方向的站内排查也照旧要答。

## 三、第 2、3 条：过敏先问一句，不过敏就跳过

- 标题改成「**过敏信息（可选）**」
- 进来先问「**小家伙是否对部分食物过敏？**」（有过敏 / 没有过敏）
  - 答**有** → 展开录入界面（快选标签 + 手输 + 拍报告 + 已上传报告）
  - 答**没有** → 整块录入界面收起，只留一句说明
- **档案里已经有过敏记录 → 默认答"有"**（本来就是事实，让家长再答一遍是多余的）
- **换狗重置**（上一只狗的答案不能替新狗作答）
- 没作答时提交按钮为灰，点它提示「请先回答：小家伙是否对部分食物过敏」
- 答"没有"的那句话必须写出**仍会避开的那些**：
  「好的，这一单不再新增过敏信息；下面这些仍会避开：鸡肉、小麦。」
  —— 答"没有"只是这一单不再新增，档案里的记录一条都不会被抹掉

## 四、第 4 条：一个真丢数据的 bug（已修）+ 份数显示

### （1）"传了两份只显示一份"——数据没丢，是页面没说清

生产库里那份报告的实际形态：**1 份报告 + 2 张附件**（两张照片是同一份报告的
第 1、2 页，日期、机构、报告编号都对得上）。页面只写了"1 份"，家长自然会以为另一张丢了。

改法：标题写成「已上传的检测报告（**1 份 / 2 张**）」，每条后面写「2 张照片 · 15 项结论」，
并加一句「同一份报告的多页照片会合并成一份，点「查看」可以翻页」。
（一次选的多张照片 = 一份报告的多页；要分开存就分两次上传。）

### （2）强阳性为什么没被识别出来 —— 真凶是**条数上限**

老板那份报告两页合计 50 多项，而老代码里过敏草稿跟普通关键词**共用 30 条上限**
（`slice(0, 30)`）。模型是按表格顺序输出的，**被砍掉的正好是最后那几项 ——
也就是报告标了「阳性 / 强阳性」的花生与海带**。最不能丢的偏偏先丢。

改法：
- 过敏草稿上限单独给到 **120**（真实报告 50~100 项都放得下）
- 真要截断时**先按严重程度排序**：强阳性 → 阳性 → 弱阳性 → 疑似 → 阴性 → 没写，
  先砍"没写结论"的，绝不动阳性/强阳性
- 新增 **STRONG_POSITIVE（强阳性）**等级：报告把强阳性与阳性分成两档，
  家长最需要一眼看到的就是强阳性那几条。后端两档**都落成"确诊"**（食谱彻底避开），
  只是显示上分开
- `normalizeAllergyLevel` 认报告上的中文与符号写法（强阳性 / +++ / ± / 可疑 / 阴性…）
  —— 老代码只认英文枚举，模型照抄中文时等级会被当成"没写"

### 生产实测（用老板上传的那两张原图，跑生产配置与生产提示词）

| | 第 1 页（无判定区） | 第 2 页（有判定区） |
|---|---|---|
| 条数 | 52 项（**全部 UNKNOWN**，符合规则） | 53 项：强阳性 4 / 阳性 5 / 弱阳性 44 |
| hasVerdict | false | true |

合并后（小程序看到的就是这一份）：**共 69 项 · 食物 35 · 环境 34**

- 食物 · **强阳性**：花生、海带、橙子
- 食物 · 弱阳性：大麦、小麦、大米、亚麻仁、蚌肉、圆白菜、土豆、红薯、玉米、
  西兰花、鸡蛋、蟹、鸭肉、羊肉、鸡肉、兔肉、菠菜、西红柿、牛肉、牛奶、菠萝

即：**强阳性的花生、海带这次读出来了**，而第 1 页照颜色条"猜"出来的阳性
一律不采信（只在名字与分组上使用）。
