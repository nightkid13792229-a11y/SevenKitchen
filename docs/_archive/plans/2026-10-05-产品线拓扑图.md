## 二、矩阵视图（更清楚地看出跨区关系）

真正的关系是**二维**的：纵向是配方区，横向是产品线。**同一个产品线跨越两个配方区**——有幼犬版，也有成犬/老年版。

|  | **通用配方区**（成犬 / 老年共用） | **专用配方区 · 幼犬** | **专用配方区 · 繁殖哺乳** |
|---|---|---|---|
| **日常安心线**<br>「托付」 | 成犬版 + 老年版卖法 | 幼犬版 | 繁殖版 |
| **换换口味线**<br>「轮换」· 单一动物蛋白 | 成犬版 + 老年版卖法 | 幼犬版 | 繁殖版 |
| **珍稀臻选线**<br>「最好的」 | 成犬版 + 老年版卖法 | 幼犬版 | 繁殖版 |
| **轻负担线**<br>「减法」· 低脂肪/低能量 | 成犬版 + 老年版卖法 | 幼犬版 | 繁殖版 |

**读出三件事：**

1. **纵向（配方区）= 用什么配方。** 由营养科学决定，我们说了不算。
2. **横向（产品线）= 怎么卖。** 由购买动机决定。
3. **老年版不是独立配方**——它和成犬版是**同一个配方**，只是卖法（喂食建议、质地、沟通口径）不同。

## 三、各产品线的完整定义

### 专用配方区

#### 幼犬线

| 项 | 内容 |
|----|------|
| **购买动机** | 新手家长，什么都不懂，怕喂错 |
| **定位** | 陪它长大的第一口鲜食 |
| **核心承诺** | 按生长阶段配比，钙磷比和能量密度符合幼犬标准 |
| **独立配方依据** | 幼犬钙 0.7–1.7% DM、能量 2–3× RER、脂肪 8.5–25%；**成犬粮不能喂幼犬**（钙磷比与能量密度无法靠喂食量调整）；10 月龄前过量钙 → 发育性骨科病风险 |
| **商业作用** | **获客枢纽。KPI = 过渡到成犬线的转化率，不是利润率** |
| **必须附带** | 喂养指导（喂多少、几顿、何时换段）+ 按生日自动提醒换段 |
| **优先级** | **最先做** |

#### 繁殖哺乳线

| 项 | 内容 |
|----|------|
| **购买动机** | 繁殖者，专业采购，看数据 |
| **定位** | 母犬和小狗的营养方案 |
| **核心承诺** | 按妊娠/哺乳分期的能量密度与营养配比 |
| **独立配方依据** | 妊娠/哺乳能量密度 ≥4.0 kcal ME/g、粗蛋白 25–35%、粗脂肪 ≥20%、钙 1.0–1.7%；**哺乳是成年犬中营养需求最高的阶段，甚至高于生长** |
| **客群特征** | 与普通家长完全不同（决策逻辑、采购周期、采购量） |
| **上线顺序** | 待定（本轮不做） |

### 通用配方区

> 成犬与健康老年犬**共用同一套配方**。依据：知识库 senior-001「'老年'不等于'疾病'，营养方案必须逐只评估，而不是按年龄段统一处理」；senior-003「健康老年犬通常不需要限制蛋白」。

#### 日常安心线

| 项 | 内容 |
|----|------|
| **购买动机** | 省心托付——"我不想研究营养，你配好就行" |
| **定位** | 不懂营养也能放心每天喂的主食 |
| **核心承诺** | 符合 FEDIAF 全价营养标准；鲜肉现制、低温蒸煮、冷链到家 |
| **产品逻辑** | **不要求顾客做任何判断**——每款都是全价主食，选口味即可 |
| **蛋白质构成** | 常规蛋白，配方稳定 |
| **边界规则** | 不做稀有食材（留给臻选线） |

#### 换换口味线

| 项 | 内容 |
|----|------|
| **购买动机** | 怕它吃腻 / 想给它换换 |
| **定位** | 只含一种肉，换肉不换配方 |
| **核心承诺** | 整份只有一种动物蛋白 |
| **产品逻辑** | 一个蛋白一款，顾客按"要哪种肉"选 |
| **蛋白质构成** | 覆盖尽可能多的肉种（鸡/鸭/猪/牛/兔/羊/火鸡/鹿…） |
| **承接的隐性需求** | **食物不耐受**——家长想避开某种肉，我们提供"不含XX"事实 |
| **边界规则** | 不做配方减法（不含低脂/低能量表述） |
| **红线** | 禁止出现：低敏、抗过敏、不耐受、适合过敏犬 |

#### 珍稀臻选线

| 项 | 内容 |
|----|------|
| **购买动机** | 给它最好的 |
| **定位** | 用平时吃不到的肉，给它一顿特别的 |
| **核心承诺** | 稀有肉源 + 高级辅料 |
| **产品逻辑** | 款数少、每款独立，追求"每款都值得记住" |
| **商业作用** | 拉高品牌天花板；给日常线一个信任理由 |
| **边界规则** | 不做单一蛋白主张（它的卖点是"稀有组合"） |

#### 轻负担线

| 项 | 内容 |
|----|------|
| **购买动机** | 它现在有点状况（胖了 / 吃得太油） |
| **定位** | 配方做减法 |
| **核心承诺** | **有法定门槛可验证的配方特性** |
| **产品逻辑** | 不做"治什么"，做"配方上做了什么减法" |
| **承接的隐性需求** | **体重 / 血脂管理**——法规里这两件事的合法表达就是低能量和低脂肪 |
| **门槛（犬用湿粮）** | **低脂肪**：水分>65% → 湿基脂肪 ≤4%<br>**低能量**：水分>65% → ≤376 kJ ME/100g（≈898 kcal/kg） |
| **边界规则** | 不做单一蛋白主张（那是换口味线的核心词） |
| **红线** | 禁止出现：体重管理、减肥、改善超重、肠胃敏感、皮肤问题 |

## 四、贯穿所有产品线的四条规则

| # | 规则 | 内容 |
|---|------|------|
| **1** | **四个核心词各占一个，不许串** | 安心 = **全价** · 换口味 = **一种肉** · 臻选 = **稀有** · 轻负担 = **减法** |
| **2** | **一道菜 = 一个系列 = 覆盖所属区域内全部适用阶段** | 5 个阶段共用同一主料与工艺，只调比例；换主料就是另一道菜 |
| **3** | **老年版 = 同一配方 + 不同卖法** | 不是独立配方，靠喂食建议、质地、沟通口径区分 |
| **4** | **配方特性进产品线，处方级进服务，疾病词一律不出现** | 慢病需求三层拆解（见下） |

## 五、特殊需求的归属（三层拆解）

慢性病 / 处方类需求**不进产品线**，按三层分别归属：

```
【慢性病需求】
     │
     ├─ ① 配方特性可承接的 ────► 进产品线
     │     低脂肪 / 低能量 → 轻负担线
     │     单一动物蛋白 / 不含XX → 换换口味线
     │
     ├─ ② 需一对一判断的 ─────► 进定制服务（不进产品线）
     │     已确诊慢性肾病 / 心脏病 / 老年多病共存 / 术后恢复
     │     ⚠️ 定制页面的选项词也不能用疾病名
     │
     └─ ③ 处方级的 ──────────► 不做
           需「科学试验数据 + 配方组成」（法规第十二条）
```

**关键约束：** 以疾病命名产品线 = 产品类别从"全价配合饲料"变成"**处方**配合饲料"，标签义务、举证义务、销售路径全部改变。这不是多做一条线，是换一门生意。

## 八、一个需要你确认的结构歧义

「幼犬线」这个说法有两种理解，拓扑图采用的是第一种：

| 理解 | 结构 | 含义 |
|------|------|------|
| **① 幼犬 = 一个配方区**（本图采用） | 四条产品线各有幼犬版 | 幼犬家长能看到安心/换口味/臻选/轻负担四种选择 |
| ② 幼犬 = 一条独立产品线 | 幼犬家长只能看到一条"幼犬线" | 幼犬家长的选项被收窄 |

**采用 ① 的理由：** 幼犬家长同样有"想换换肉""想给它点好的"的动机。如果采用 ②，这些动机在幼犬阶段就接不住了。

**但这会带来一个影响：** 如果采用 ①，那么"幼犬线"不是一个产品线，而是**四条产品线在幼犬配方区的版本集合**。这会影响后面给产品线起名和做货架入口的方式。

**请你确认采用哪种理解。**
