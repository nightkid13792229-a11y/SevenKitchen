# 处方食谱 / 慢性病调理食谱，该不该进产品线？

> 日期：2026-10-05
> 前置：`2026-10-05-生命阶段与产品线结构修正.md`（已定：先做幼犬线；老年犬用"卖法"承接；本文只画产品线，不做入口设计）
> 法规依据：《宠物饲料标签规定》（农业农村部公告第 20 号）第五条、第十二条、第二十条、附录 5

---

## 一、结论

**不进产品线。** 但要拆成三层分别处理，因为"慢性病需求"里有一部分是我们**已经在做的**。

| 层次 | 处理方式 |
|------|----------|
| **① 配方特性可承接的** | ✅ **进产品线**（这本来就是我们的「轻负担线」和「换换口味线」） |
| **② 需要一对一判断的** | ✅ 进**定制服务**，不进产品线 |
| **③ 处方级的** | ❌ 不做 |

**一句话：慢性病需求我们已经在接一半了，只是没意识到。**

---

## 二、为什么不能把"慢性病"做成产品线

### 2.1 法律上：「处方」是法定类别，不是营销词

法规**第五条（一）**：

> 为满足宠物**特定生理、病理状态**营养需要生产的宠物配合饲料，其通用名称**应当标示「处方」字样**。

法规**第十二条**（这是真正的门槛）：

> 标「处方」的产品须按附录 5 标示适用状态，并在醒目位置标「**请在执业兽医指导下使用**」，且须能提供**科学试验数据及配方组成**。

**注意"科学试验数据"这四个字。** 不是营养计算，不是 FEDIAF 对标，是**喂食试验或公开发表的试验报告**。这个成本和时间投入是产品线级别的，不是配方级别的。

**你们自己的合规文档结论是：「处方」路径的门槛极高，**不建议走**。

### 2.2 组织上：以疾病命名产品线，等于换了一个经营范围

这一条比法律门槛更根本。

**「处方」不是一个标签，是一个产品类别。** 一旦你按"胰腺炎""肾病""心脏病"来组织产品线：

| | 今天的经营范围 | 以疾病命名产品线之后 |
|---|---|---|
| 产品类别 | 宠物配合饲料（全价） | **处方**宠物配合饲料 |
| 标签义务 | 标示"全价"和生命阶段 | 必须标示"处方" + 适用病理状态 + "请在执业兽医指导下使用" |
| 举证义务 | 声称需证明材料 | **科学试验数据 + 配方组成** |
| 销售路径 | 电商直销 | 行业惯例是**兽医渠道** |

**这不是"多做一条产品线"，是"换了一门生意"。** 而且变成处方粮之后，你原有的全价粮产品线跟它是**两个法律类别**，不能混在一个货架逻辑里。

### 2.3 需求上：慢病需求的大部分，我们已经在接了

这是我核查附录 5 之后的发现。附录 5 列了 19 条"特定状态"，其中：

| 附录 5 的处方专属表述 | 我们合法的对应表达 | 已经在哪条线 |
|----------------------|-------------------|--------------|
| 十六、**改善超重状态**（能量密度经过科学调整） | **低能量**（法定门槛 ≤898 kcal/kg） | 轻负担线 |
| 十三、**改善高脂血症**（脂肪经过科学调整） | **低脂肪**（法定门槛 湿基 ≤4%） | 轻负担线 |
| 八、**降低原料和营养素不耐受**（蛋白质/碳水经过科学调整） | **单一动物蛋白** · **不含XX** | 换换口味线 |
| 七、降低急性肠道吸收障碍发生 | 易消化（需举证可消化性数据） | ⚠️ 可做但要证据 |
| 九、改善消化不良 | 易消化 | ⚠️ 同上 |
| — | 含 Omega-3 | 可做功能声称 |

**三条主要的慢性病饮食需求（体重、血脂、食物不耐受），它们的合法表达就是我们已经规划好的产品特性。**

所以答案不是"要不要新增慢病产品线"，而是——**轻负担线和换换口味线，本来就是慢病需求的产品线，只是不能按疾病命名。**

## 三、三层结构

### 第一层 · 进产品线：配方特性

**能进的判断标准：有法定门槛、达得到、可验证。**

| 特性 | 门槛 | 承接的真实需求 |
|------|------|----------------|
| **低脂肪** | 犬用湿粮：水分>65% → 湿基脂肪 ≤4%；20–65% → ≤7%；<20% → ≤9% | 家长觉得"吃得太油了"、血脂偏高 |
| **低能量** | 犬用湿粮：水分>65% → ≤376 kJ ME/100g（≈898 kcal/kg） | 家长觉得"它有点胖了" |
| **单一动物蛋白** | 配方只有 1 种动物源 | 家长想避开某种肉 / 想排查 |
| **不含XX** | 仅限原料与添加剂 | 家长明确知道要避开某样东西 |

**定位口径必须是"配方特性"，不是"疾病管理"。**

| 写 | 不写 |
|----|------|
| 低脂肪 · 单一动物蛋白 | 胰腺炎专用 |
| 低能量 | 减肥 · 体重管理 · 改善超重 |
| 不含鸡肉 · 不含谷物 | 低敏 · 抗过敏 · 不耐受 |

**为什么不按疾病命名也能卖出去：** 顾客带着"我家狗有点胖"进来，他看到"低能量"，**自己就把这两件事连上了**。你不需要说那个词，他的大脑会补全。这比直接说"体重管理"更可信——因为低能量是有法定门槛的，而"体重管理"没有任何标准。

### 第二层 · 进定制服务：需要一对一判断的

**有些需求确实承接不了产品线，但它可以承接服务。**

这类需求的特征：**需要看具体这只狗的情况才能定，不能标准化。**

| 需求 | 为什么不能标准化 |
|------|------------------|
| 已确诊慢性肾病 | 蛋白/磷限制**取决于疾病分期**，不能套用通用建议（知识库 senior-002 原话） |
| 已确诊心脏病 | 钠的调整量取决于心衰分级 |
| 老年犬多病共存 | 知识库明确说"**营养方案必须逐只评估，而不是按年龄段统一处理**" |
| 术后恢复 | 取决于手术类型和恢复阶段 |

**这些走「食谱定制 ¥300」这条服务链路。**

**⚠️ 关键设计约束：定制的入口词也不能是疾病名。**

| 定制页面的选项 | 不能是 |
|----------------|--------|
| 单一动物蛋白 / 低脂肪 / 低能量 / 不含XX | 胰腺炎 / 肾病 / 心脏病 / 关节炎 / 肿瘤 |
| 自由填写"需要特别注意什么" | "适用于X病"式选项 |

**理由：** 产品页面的声称受法规约束，定制页面的**选项设计**同样构成对产品的说明。而且疾病相关的具体信息，应该由家长在**备注里用自己的话**写，或者由营养师**一对一沟通**获取——那是咨询服务，不是产品声称。

### 第三层 · 不做：真正的处方粮

需要**科学试验数据**才能做的那些。不做。

## 四、这对已定的产品线结构意味着什么

**结构不变，只是把"慢病承接"这件事显性化。**

```
【专用配方区】
  ├─ 幼犬线            ← 先做
  └─ 繁殖哺乳线

【通用配方区】（成犬 / 老年犬共用配方）
  ├─ 日常安心线        「托付」
  ├─ 换换口味线        「轮换」——单一动物蛋白、不含XX
  │                      ↑ 同时承接"食物不耐受"需求
  ├─ 珍稀臻选线        「最好的」
  └─ 轻负担线          「减法」——低脂肪、低能量
                         ↑ 同时承接"体重/血脂"需求
```

**四条线的定位不变，但要在内容层补一件事：**

在**轻负担线**和**换换口味线**的详情页做合规的科普内容，把"配方特性"和"家长的真实焦虑"连起来：

| 产品特性 | 详情页科普内容（合法的，不涉及疾病） |
|----------|--------------------------------------|
| 低能量 | "如何判断狗狗是否偏胖"（讲 BCS 体况评分，不讲疾病） |
| 低脂肪 | "鲜食里的脂肪从哪来"（讲工艺和食材，不讲疾病） |
| 单一动物蛋白 | "为什么要给狗轮换肉类"（讲饮食多样性，不讲过敏） |

**这是运营层的活，但它是这层需求能不能被接住的关键。**

## 五、这样处理的三个好处

| 好处 | 说明 |
|------|------|
| **不越界** | 所有声称都有法定门槛兜底，可举证、可检查 |
| **不浪费已有规划** | 轻负担线和换换口味线本来就要做，只是现在知道它们还承接了慢病需求 |
| **给定制服务一个明确的定位** | 定制不再是"说不清楚的副产品"，而是"承接处方级需求的服务"，¥300 的定价有了依据 |

**还有一个隐性好处：** 把慢病需求导向定制服务之后，最愿意付钱的那批家长（有明确健康焦虑的）有了一个**付费出口**，而不是因为"你们没有对症的产品"而流失。
