## 已知的「看不到」，不是 bug

| 现象 | 原因 |
|---|---|
| 老订单的交付第 2 页**没有**「一键买齐」 | 老快照里没有 `ingredientId`。**重新交付一次**就会有 |
| 老订单的交付页可能还带采购量文案 | 快照是**冻结契约**，老数据不改。新交付的才干净 |
| AI 封面图按钮是灰的 | 没配智谱 API Key（设计如此） |
| 「定制」筛选是空的 | 生产只有 1 张定制单，已取消 |
| 交货历史里只有 1 条 | 只交付过一次（重新交付会变成 2 条） |
