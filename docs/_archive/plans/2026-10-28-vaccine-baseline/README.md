## 重新生成

```bash
cd backend
npx ts-node -r tsconfig-paths/register scripts/vaccine-plan-baseline.ts
```

脚本只读：不写数据库、不改业务代码；同样的输入每次输出一样（`today` 固定在场景里）。

## 每批修复后怎么用

1. 重新生成 `snapshot.json` / `snapshot.md`。
2. 和上一版逐条 diff（建议先备份上一版，或用 git diff）。
3. **每一条差异都要能解释**：
   - 该变的：只能是这一批点名要改的案例（见下表）；
   - 不该变的：原型 3 屏（P-A/P-B/P-C）＋ 16 组对照（C-*）必须一字不差；
   - 如果对照案例也变了 → 停下来查，不要“顺手接受”。
4. 特征测试 `b0-baseline.spec.ts` 里对应的断言会变红 → **翻成期望行为**（不是删掉）。
