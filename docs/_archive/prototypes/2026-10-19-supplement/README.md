# 预分装补剂 · 原型说明（2026-10-19）

## 怎么打开

**最省事**：双击本目录的 `打开原型.command`，会自动起本地服务并打开浏览器。如果 macOS 提示“无法打开”，右键 → 打开。

也可以直接双击 `index.html`；如果是在聊天/IDE 的嵌入式预览里，点击可能被拦截，请用浏览器打开，或右键卡片复制链接。如果浏览器限制本地文件，可以在本目录起一个静态服务：

```bash
cd docs/prototypes/2026-10-19-supplement
python3 -m http.server 8765
```

然后打开 `http://127.0.0.1:8765/index.html`。

## 原型里已经体现的业务决定

- DIY 制作单**不显示价格**；首次买补剂后冻结整张制作单快照。
- 下单页：商品明细 + 服务费 ¥10 + 运费 ¥6 + 合计 + 每天约 + 确定发货日。
- 部分缺货可买可买的，缺的标灰。
- 30 单/天产能；超过顺延；管理员可超排留痕。
- 未发货可自助改地址；已发货不可改；已打面单提示重打。
- 缺料允许排产但标红；员工不能强制分装，管理员可以。
- 售后 7 天、无理由退/补、不要求寄回；多次售后、累计退款不超实付、每个 case 最多一张补发。
- 正常发货、延迟、排期、售后都发站内 + 订阅。
- 40×60 标签直接印用法/储存/原品/分装者/干燥剂提示；不放二维码/卡片。
- 再次购买无需当前制作单，按快照清单/用量重新报价。

## 状态覆盖

原型主要画“成功态”，另有缺料、售后、退款失败等少数异常态；空/加载/错误/权限/部分失败没有逐张画。完整状态矩阵见五类专项审查第三节，开发按需求 v2 4.4 的页面状态要求实现。

## 已知简化

- 数据全部为演示数据，不接真实接口。
- 顾客订单列表里的“售后中”卡片点进去仍展示同一张补剂详情（原型只做了一套详情页）。
- 后台/员工的部分按钮只做视觉状态，不触发真实业务动作。
- 标签为网页示意，实际打印需按 40×60mm、203dpi 校准。

## 覆盖范围说明

原型覆盖核心**新增/改造**页：顾客 10 屏、后台 12 屏、员工 6 屏、标签 3 版、状态图 10 态。
