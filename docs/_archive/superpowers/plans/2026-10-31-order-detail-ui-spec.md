## 三、本次实际改动

1. **字号**：全文压到 20 / 24 / 28 / 34 四档（图标除外）。主标题 36→34，区块标题 32→28，正文 25/26→24，辅助 22→20。
2. **圆角**：4/6/10→8，40/44→999；只保留 8 / 12 / 16 / 999 四档。
3. **按钮**：
   - 底部操作 88→64；
   - 「联系客服」从全宽方块按钮改为「联系客服 / 在线咨询 ›」入口行；

   - 保存地址、错误页按钮统一成 64 胶囊；
   - 复制/编辑/分享统一成 48 小胶囊。
4. **颜色**：把 4 个近似灰合并成 `#6b6653`，3 个边框合并成 `#e3e6d4`，浅色底合并到 3 个品牌浅色；不新增颜色。
5. **删死样式**（模板已确认不再使用）：
   - `.order-center-*`（9 条）及其同组的旧商品卡 `.goods-*`、`.buyer-*`、`.cell-*`；
   - `.remark-*`（10 条）与 `.remark-section`；
   - `.merchant-note-toggle`、`.merchant-note-arrow`、`.item-spec-fold`；
   - 已废弃的售后锁定块 `.aftersale-locked-section`。
6. **保留**：所有既有函数名、调用表达式、回归测试锚点文案；只新增 `.entry-row / .entry-title / .entry-link` 三个类。
