# 小程序 DIY 配置页体验优化设计

## 背景

DIY 配置页需要向订购成品页对齐，让顾客在同一套交互里选择爱犬、查看参考饭量，并配置制作天数和分装方案。DIY 是个人制作指导，不是购买行为，因此页面不展示价格、最低下单量或袋均价。

## 目标

- 在 DIY 配置页的食谱信息中，于能量密度和营养标准后展示设计软件。
- 爱犬选择改为订购成品页同款横向狗狗卡片，选中后展示年龄、性别、体重、餐次。
- 选中爱犬后展示每日参考饭量、每餐参考饭量和主食能量。
- 配置天数使用 7 天、15 天、30 天默认选项，并支持自定义分装。
- 自定义分装同步到制作单页面和生成的制作单图片。
- DIY 配置和制作单链路不展示价格预览，不让用户误解为下单报价。

## 非目标

- 不改造下单、结算、购物车、订单价格逻辑。
- 不在 DIY 配置页引入原料来源方案。
- 不改造下单、结算、购物车、订单价格逻辑；DIY 制作单仅持久化制作所需的分装明细。

## 设计

DIY 配置页顶部保留食谱名称、标签、能量密度和营养标准，并新增“设计软件”。设计软件复用已有食谱展示格式化逻辑，内部设计来源统一对外显示为 `Setar`。

爱犬模块复用订购成品页的横向狗狗卡片。选中狗狗后展示年龄、性别、体重、餐次四个事实项；饭量区展示每日参考、每餐约、主食能量，并保留“国内城市犬、2-4 周观察、5%-10% 调整”的提示。

配置天数模块复用订购成品页的分装方案模型：默认按每日饭量、每日餐数和选中天数生成一行分装；用户打开自定义分装后，可以编辑每袋克数和袋数，也可以添加多个规格。自定义分装状态下切换天数时提示先取消自定义，避免覆盖用户手动方案。

生成制作单时，DIY 配置页把 `packagePlan` 作为页面参数传给制作单页。制作单页解析该参数后，用它计算总净重、总袋数、分装摘要、打印图片里的分装规格。没有 `packagePlan` 时，制作单页仍按旧参数生成默认单规格方案，保证旧入口可用。

保存制作单时，小程序把同一份 `packagePlan` 提交到 `/user/diy-sheets`。后端在 `diy_sheet.package_plan` JSONB 字段中保存该分装明细，并在制作单列表响应中返回。用户从“我的制作单”再次打开历史制作单时，小程序把已保存的 `packagePlan` 带回制作单页，保证跨设备或下次打开仍保留多规格分装。

制作单页可继续用现有内部接口获取原料明细和补剂明细，但不向用户展示价格预览或价格预览失败文案。

## 验证

- 回归测试覆盖 DIY 配置页新增狗狗卡片、饭量卡片、设计软件、分装编辑器和无报价文案。
- 回归测试覆盖制作单页能解析 `packagePlan`，并把分装摘要用于页面、分享路径和生成图片。
- 运行小程序测试和至少一次微信小程序构建或预览流程。
