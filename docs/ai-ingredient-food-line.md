# AI 添加原料 · 食材线（活文档）

> 2026-11-21 整理。代码入口：`admin-web/src/views/Ingredients/ai-agent/`、`backend/src/application/ingredient-creation/`。
> 设计取舍见 `docs/superpowers/specs/2026-11-21-ai-ingredient-food-line-overhaul-design.md`。

## 一、一条原料怎么走完

1. 进页面选「食材类原料」，输入一句话（如「帮我加鸡肝」）。
2. AI 查库后交「检索方案」，人点确认（或跳过换词重查）。
3. AI 把原料卡和营养档案写进**草稿**（只写草稿，不碰正式表）；未确认方案前写工具会被拒。
4. 右侧两页核对；改一格会自动保存，旧核验报告立即作废。
5. 两页都新鲜、无阻断、可例外项已登记理由，且勾选「我已核对两页报告与采购价」后，
   点「授权写入并确认可用」。
6. 写入是**一个事务**：原料 + 采购商品 + 营养档案 + 映射 + 审计一起落；营养档案
   直接是 `VERIFIED`（授权人/时间入 `verifiedBy/verifiedAt`），配方立即可选。

## 二、不能忘的口径

- **两页核验**：原料域（名称/重名/标签/单位/CFCT/采购策略/标签分类/名称/密度/可食部）
  与营养域（单位/来源口径/数值与来源一致/宏量和/生熟覆盖/能量反算）。
- **规则版本**：`CHECK_RULES_VERSION` 一改就必须升版本；旧版本报告不算新鲜。
- **例外**：`exceptionable` 没登记理由就挡住授权；审批人和时间由**服务端**盖章。
  同一条例外（code + 理由都没变）重存时**沿用原来的审批留痕**——后一个人登记
  新例外，不会把前一个人批的那条改成自己。
- **自动核验算数**：自动/人工跑同一套规则、同一份内容；内容改过或**规则版本升级**
  都会让报告失效。页面文案不再写「AI 自检不算」，也不再把「规则升级」说成
  「你改过草稿」。
- **营养值对源**：`writeNutrition` 写入前必须与来源记录同字段值一致（0.5% 容差）；
  来源口径是每 100g 或**每 1g（×100 等价换算）**才可写；每份 / 每 ml 拒绝写入。
  核验里也有同样的阻断。整份档案都是人工核对值时，不受来源口径限制。
  重复写同一个值不算改动：不重写证据行、不刷新 AI 基线、不 patch 草稿
  （否则核验报告会被无谓作废）。
- **人工值保护**：原料卡 `manualFields`、营养行 `status=MANUAL/confirmedBy` 的字段，
  AI 不覆盖。
- **采购价**：填**一个采购单位（整箱/整袋）多少钱**；换算倍数 = 件数 × 每件净含量。
  页面预览与后端同式，并显示「折合每件」供核对。按个计量的原料单位是「个」。
- **草稿**：地址带 `?draftId=`；进页面可继续/放弃未完成草稿；已提交草稿**服务端只读**
  （`PATCH` 直接 409，不是只靠页面置灰），页面上的问答卡 / 方案卡 / 输入框也一起锁。
- **审计**：`ingredient_creation_audit.changes` 里有 `aiBaseline`（AI 原值）、
  `ingredientFieldChanges`（人工改动前后）与 `confirmation`（授权即确认的人/时间）；
  对话全文不落库。`aiBaseline` 只能由 AI 写工具更新，客户端 `PATCH` 会被剥掉；
  可食部按「百分数」比较（草稿里存的是比例）。

## 三、已知限制 / 后续

- 按份、每 100ml 的来源目前**拒绝**而不是换算（没有可靠份量克数/密度）；要支持需补换算与证据。
  每 1g 已按 ×100 等价支持。
- `MAGNITUDE_OUTLIER`（量级异常）规则还没接数据源，暂不生效；目前靠「与来源一致」兜底。
- 对话/工具调用只保留页面内记录，未单独落表；审计只记 AI 基线 + 最终值。
- 候选来源元数据每次检索仍会全量读一次（约 2 万条），未加缓存；属性能优化。
- 草稿/核验报告没有自动清理策略，后续可加运维脚本。

## 四、常见问题

| 现象 | 先查什么 |
|---|---|
| 授权按钮灰着 | 两页报告是否新鲜/版本是否当前、有无阻断、可例外是否登记理由、采购商品/件数/单位是否填完、是否勾选「已核对」 |
| 写入报「已存在」 | 名称被占用；去原料库处理，别改名绕过 |
| 写入报「采购单位不在字典」 | 采购单位必须是后台维护的字典码 |
| 配方里选不到这条原料 | 营养档案是否 `VERIFIED`（写入即确认后不应再出现） |
| 页面说「报告已过期」 | 改过草稿；点「核验两页」重跑 |
| 页面说「旧规则版本」 | 核验规则升级过（`CHECK_RULES_VERSION`），重跑一次即可，不是内容有问题 |
