## 一、怎么用这份表

1. 每个组先看「成员」「能不能换」「依据」；
2. 在「结论」里选：**通过 / 改成员 / 拆组 / 合并 / 暂缓**；
3. 有异议直接写在「修改意见」；
4. 全部确认后，在后台「补剂等价组」逐组点「通过」并填审核说明；
5. 之后才打开「补剂商城设置 → 启用补剂等价组候选」。

**没有签字/没有依据的组不参与线上替换。**

## 二、分组原则

- 组 = **营养素 × 形态/来源**，不是“大营养类别”。
- 同组内按**元素/有效成分**换算，不按品牌/克数照抄。
- 跨组不换：骨源不换矿物盐，海藻碘不换碘化钾，鱼油不换藻油。
- 复方/多成分补剂单独成组，不与单一成分互换（避免顺带补进别的营养素）。
- 没有可换对象的原料也单独成组（组内 1 个），保证“35 种全部有归属”。
