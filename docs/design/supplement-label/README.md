# 补剂分装标签 · 尺寸打样

- 日期：2026-09-25
- 目的：确认 **60×40mm** 能不能装下标签内容、字够不够大
- 结论：**能，但必须精简内容**（详见下）

---

## 一、打样的结果

用真实打印像素（按 203dpi = 8 点/mm 换算，60×40mm 正好是 480×320 像素）排了四个版本：

| 版本 | 尺寸 | 内容 | 结果 |
|---|---|---|---|
| A | 60×40mm | 规格文档里的完整 9 行 | ❌ **排到 38.2mm，距底边只剩 1.8mm** |
| B | 60×40mm | 去掉储存条件、订单号 | ✅ 留白充足 |
| C | 60×60mm | 完整 9 行 | ✅ 留白充足，但要换更大标签纸 |
| **D** | **60×40mm** | **保留订单号，去掉原瓶效期** | ✅ **底部留 6.5mm，推荐** |

### 为什么 A 不行

热敏打印机边缘有 1–2mm 不可打印区。A 版最后一行贴在 38.2mm 处，**实际打印很可能被裁掉**，而最后那行正是「分装小样，非直接食用；内含干燥剂，请勿食用」——安全提示，不能被裁。

### 为什么推荐 D 而不是 B

B 版把**订单号**也去掉了。但分装 SOP 里明确写了「一单一个盒，避免串单」，订单号印在标签上是有用的防错信息。D 版用「原瓶效期」换回了订单号——原瓶效期是内部追溯用的，系统里有记录，标签上不是必须。

## 二、推荐版（D）的内容

```
赛文的食堂                         ← 品牌
海藻粉                            ← 品名（最大字号）
23平勺  1/3                       ← 每袋用量 + 第几袋/共几袋
──────────────────────
分装日期 2026-09-18
有效期至 2027-03-18                ← 放大加粗（最关键的安全信息）
批号 B2609-01   订单 SP20260918-004
原品 NOW FOODS · 227g/瓶
分装小样，非直接食用；内含干燥剂，请勿食用
```

比规格文档少了「储存 避光、密封、阴凉干燥处保存」和「原瓶效期」。

## 三、请你做一次实物打印确认

目录下有两个文件，是**同一个排版在两种分辨率下的 1:1 打印文件**：

- `print-test-60x40-at-203dpi.png`（480×320px）
- `print-test-60x40-at-300dpi.png`（709×472px）

**为什么要给两个**：精臣 B3S 的分辨率各商家标注不一致（多数写 203dpi，也有标 300dpi 的）。分辨率用错会导致标签被缩放。

**怎么判断哪个是对的**：用 60×40mm 标签纸各打一张，
**内容铺满整张纸的那个版本就是对的**——如果打出来内容只占左边一部分、右边空一条，说明分辨率选错了，换另一个文件。

### 要确认三件事

1. **字看得清吗**（尤其「有效期至」和最后一行安全提示）
2. **最后一行有没有被裁掉**
3. **内容有没有铺满整张纸**（判断分辨率）

> 提醒：目录里的 `preview-*.png` 是**放大 3 倍**的效果图，看着清楚不代表实际尺寸下清楚。
> 实物上正文字号是 2.3mm 高，大约是标签高度的 1/17。

### 如果 60×40mm 读不清

两个退路（都不用换机器，只换标签纸）：
- 把内容再砍一点（去掉「原品」那一行）
- 换 60×60mm 标签纸，完整内容都放得下（见方案 C）

## 四、和现有鲜食标签的关系

**完全不共用配置。** 现有鲜食标签是 **70×100mm**、版式完全不同的另一套（食谱名 / 原料表 / 营养成分 / 烹饪建议）。

⚠️ **换纸提醒**：补剂要换 60×40mm 标签纸，打完补剂标签**记得换回 70×100mm**，否则鲜食标签会打错。
