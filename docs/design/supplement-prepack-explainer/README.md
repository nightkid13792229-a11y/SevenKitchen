## 三个脚本

| 脚本 | 干什么 | 什么时候用 |
|------|--------|-----------|
| `generate-poster.mjs` | 走 Seedream 4.5（火山方舟通道）生图，可带参考图 | 出新构图 |
| `composite-poster.mjs` | 真实商品图抠图 + AI 生成场景 → 合成 | 瓶身文字必须 100% 准确时 |
| `retouch-labels.py` | 在已定稿的成品图上局部改字 | 只换文案，不想重掷构图运气 |

`generate-poster.mjs` 直接 import 磁盘上 `~/.dsh/mcp/media/` 的最新代码，刻意绕开 DSH 会话里
按会话 spawn 的 MCP 子进程（旧会话跑旧代码，会静默丢掉参考图）。

## 踩过的坑（决定了现在这套做法）

- **不能让 AI 重画别人的商标。** 实测把 KAL 那瓶交给了 AI，瓶身被写成
  `Bonen Meal Powstrotay`。所以真实瓶罐一律走**抠图合成**，AI 只负责背景、光影、
  铝箔袋、散落的半成品。
- **抠图不能用"去掉所有白色"。** 01/02/03 的瓶子本身就是白的，一刀切会把瓶子掏空。
  `composite-poster.mjs` 从**画面四边**做 `cv2.floodFill`，只把「与边框连通的近白区域」
  判为背景——白瓶内部与外界不连通，因此能保住。
- **改字要 `cv2.inpaint`，不能直接填色。** 直接填墨绿会抹掉标签本身的颗粒质感，
  以及第三个标签上那道斜向阴影。
- **一次只出一张。** 参考图张数不影响计费，但出图是抽卡；留档是为了记住哪一版被否、
  为什么被否（见 `*-对比.png` 与 `M-文字缺陷放大.png`）。

## 文案硬约束（产品定的，别再改）

- 只用三句：`无需囤多种补剂，做多少买多少。`、`一次份`、`制作量`
- 不写真实品牌 LOGO
- 铝箔袋必须**小分量、哑光银、不透明**
- 不出现"每袋 vs 每餐"的换算提示，不显示天数

## 目录

- `prompt*.txt` — 各轮提示词，按迭代顺序命名
- `A-`…`P2-` — 各轮出图候选（字母越后越新）
- `*-对比.png` — 决策依据的并排对比
- `ready/` — 交付尺寸成品
- `refs/`、`refs-focus/` — **不入库**（第三方品牌商品照片，见 `.gitignore`）
