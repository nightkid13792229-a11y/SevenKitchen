# 库存管理 · 界面与交互设计（2026-11-10）

> 配套：[台账与盘点方案](01-台账与盘点方案.md)
> 草图：`prototypes/inventory-ledger-ui-2026-11-10.html`、`prototypes/inventory-stocktake-ui-2026-11-10.html`
> 范围：员工端小程序（库存管理、盘点）。工作台红点、补货清单、流水三块留到下一轮。

---

## 1. 要解决的三件事

| 旧版问题 | 这版怎么改 |
|---|---|
| 首屏被 4 个统计卡和 3 个按钮占满，看不到真实库存 | 首屏先给「缺什么」：一条预警 + 卡片清单，2–3 条真实库存直接可见 |
| 一张卡里两种单位（克 / 袋），要心算 | 卡片直接给「当前 ×克 · 建议补 3袋 · 约 ¥186」 |
| 盘点要「先选原料 → 滚到底部填数」 | 盘点就是一屏清单，边数边填 |
| 报废 / 内部领用没有入口，最后都算进盘点差异 | 底部固定「记一笔」，30 秒完成 |

## 2. 页面结构

```
库存首页（导航右上角：盘点）
  ├── 记一笔（底部弹层）
  ├── 补货清单（下一轮）
  ├── 流水（下一轮）
  └── 盘点
        ├── 盘点记录（待复核 / 已入账）
        ├── 盘点录入（清单式、盲盘）
        └── 盘点结果（容差分层 → 提交复核）
```

## 3. 库存首页

从上到下：

1. **日期行**：`11月10日 周二 · 数据截至 17:20`，右侧 `上次盘库 11/8`
   —— 解决「不知道数字新不新」。
2. **预警条**：`3 项需要补货 · 5 项低于安全库存 ›`，整条可点，进补货清单。
3. **搜索**：原料名 / 渠道 / 规格。
4. **筛选项**：全部 / 需补货 / 低库存 / 未设阈值（选中＝深绿底米白字）。
5. **库存卡**（每张）：
   - 名称 + 状态徽标（需要补货 / 低于安全 / 库存充足 / 未设阈值）
   - 大数字：`1,240克`
   - 右上：`建议补货 3袋 / 约 ¥186`；不足时显示阈值
   - 最近一笔：`今天 17:20 厨房领用 −300克`（带颜色）
   - 操作：`看流水`、`去补货`（带着这个原料进补货页面）
6. **底部固定栏**：`记一笔` / `补货清单 3`

规则：

- **页面内不写大标题**，标题只在导航栏出现一次（员工端 UI 规范）。
- 数字统一走 `src/utils/staff-quantity.ts`：拉丁单位空格、中文单位不空格、去掉末尾 0。
- 空态、错误态分开：加载失败显示「加载失败，重试」，**不能显示成「暂无库存」**。
- 支持下拉刷新；每次进入页面显示最新「数据截至」。

## 4. 记一笔（报废 / 内部领用）

底部弹层，四个字段：原料（可改）、数量、分类、备注（可选）。

- 分类：内部领用 / 过期报废 / 破损污染 / 其他。
- 内部领用免批；报废单笔 ≥ 50 元进「待复核」。
- 单价按**发生当时**的采购价快照，不用现价。
- 提交后回到首页并刷新，流水里立刻能看到这一笔。

## 5. 盘点

### 5.1 入口

- **手动触发**，不排期、不提醒；入口在导航右上角「盘点」，常驻但不占首屏。
- 首页只显示「上次盘库 11/8」，不弹任务、不标红。

### 5.2 记录页

- 顶部：`盘点记录`，右侧 `共 3 次`。
- 说明条：盲盘 + 容差规则一句话。
- **待复核**：每张显示时间、项数、差异项数、金额；展开差异行（账面 / 实盘 / 差）；
  操作 `驳回重盘` / `通过并入账`。
- **已入账**：一行一条（时间 · 差异项数），点进去看明细。

### 5.3 录入页（核心）

- 一屏就是一张清单，**边数边填**，每行：名称 + 单位 + 输入框 + 打勾。
- **盲盘**：不显示账面数、不显示差异。
- 顶部进度 `4 / 42` + 进度条；分组筛选（全部 / 食材 / 补剂）。
- **排序：按上次盘点的顺序**（冻库摆放不常变，跟着上次走最省事）；首次盘点按分类 + 名称。
- 可留空、可「存草稿」；中途离开再回来能继续。
- 提交时若还有未盘项：提示一次「还有 N 项未盘，这些按不调整处理」，可继续提交。

### 5.4 结果页

- 汇总：`42 项已盘 · 差异 5 项 · 约 ¥86 · 待复核 2 项`。
- 分两堆：**超出容差，需要复核** / **容差内，自动入账**。
- 每行：账面 / 实盘 / 差（正绿负红）。
- 备注可选；底部 `提交复核`。
- 容差 = 差额的 `max(2%, 50克)`。

## 6. 与旧版的差异（验收时对照）

| 旧版 | 这版 |
|---|---|
| 页面内大标题「库存管理」+ 白导航 | 深绿导航，标题只出现一次 |
| 4 个统计卡点了没反应 | 预警条可点，直接进补货清单 |
| 筛选选中态文字＝底色（看不见） | 深绿底米白字 |
| 22rpx 小字 | 最小 24rpx |
| 一张卡两种单位不换算 | 给出建议补货与金额 |
| 盘点要滚过整张原料表 | 一屏清单直接填 |
| 加载失败显示「暂无数据」 | 显示「加载失败，重试」 |
| 工作台红点＝盘点草稿数 | 待定（下一轮） |
