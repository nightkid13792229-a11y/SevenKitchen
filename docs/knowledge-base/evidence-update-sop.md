# 知识库复核与更新 SOP

**建立日期**：2026-09-30
**作用**：让知识库不会悄悄过期。**"多久看一次、看什么"是可执行的规则，不是靠记性。**

---

## 一、复核周期

| 来源类别 | 多久复核一次 | 复核什么 |
|---|---|---|
| **WSAVA / AAHA 各指南** | **每 6 个月** | 有没有出新版、工具包有没有更新、有没有新的立场声明 |
| **免疫相关（疫苗指南、国内法规）** | **每 6 个月** | 免疫程序有没有调整；国内法规与地方条例有没有变化 |
| **FEDIAF / NRC 等营养标准** | **每 6 个月**（出新版立刻跟进） | 新版发布、生命阶段表变化 |
| **教科书（SACN5 等）** | **每 12 个月** | 有没有出新版、勘误、被新共识取代 |
| **疾病类共识（ACVIM / IRIS）** | **每次做这个疾病领域之前** | 有没有新的共识声明、系统综述 |
| **单篇研究** | 只在有具体悬而未决的问题时才找 | 研究设计、人群是否对得上、有没有更强的证据 |

---

## 二、什么时候必须跑一次更新检查

1. 要新开一个疾病领域或功能领域之前
2. 某条来源到了上面的复核周期
3. 老板或营养师提供了新资料
4. AI 的输出与实际临床判断冲突时
5. 涉及变化快的主题时（如免疫程序、新发传染病、处方粮相关）

---

## 三、去哪儿找

按顺序找，**不要跳步**：

1. `source-register.md` 里已登记、本地已有的来源
2. 官方机构页面：**WSAVA、AAHA、FEDIAF、ACVIM、IRIS**、农业农村部
3. 期刊页面 / PubMed：找共识声明、系统综述、指南原文
4. 老板提供的书、PDF、付费资料

**不找**：品牌营销页、自媒体、论坛、SEO 文章。

---

## 四、更新流程

| 步骤 | 做什么 |
|---|---|
| 1 | 说清这次要更新哪个领域、要回答什么问题 |
| 2 | 先查本地已登记的来源 |
| 3 | 本地不够或过期，才去官方渠道找 |
| 4 | 新来源登记进 `source-register.md` |
| 5 | 定证据分级 |
| 6 | 记录获取状态、链接或本地路径、检索日期 |
| 7 | 只提取本次要用的部分 |
| 8 | 标注这次更新的性质：**改了结论 / 加了提示 / 只是背景** |

---

## 五、过期了怎么办

| 情况 | 处理 |
|---|---|
| 来源出了新版 | 用新版重做受影响的条目；旧版条目**不要直接删**，标记"依据旧版"，等重做完再替换 |
| 来源被取代（如 AAHA 2014 被 2021 取代） | **降级为历史来源**，不再作为首选依据，并在登记表标注 |
| 找不到替代来源 | 条目**降级**：紧急程度一律降为"可观察"，并在结论里注明"依据较旧" |
| 来源链接失效 | 尽快补新链接；补不到就先降级，不要留着一个点不开的出处 |
