# 知识库入库 SOP

**建立日期**：2026-09-30
**什么时候用**：要往知识库加一个新来源、或者加一批新条目时。

---

## 一、加一个新来源

| 步骤 | 做什么 | 产出 |
|---|---|---|
| 1 | 在 `source-register.md` 里登记：ID、机构、文档名、版本、状态（📁/🌐/🛒/⛔）、位置或链接、用途 | 登记表新增一行 |
| 2 | 按 `evidence-policy.md` 定证据分级（A–E） | 分级确定 |
| 3 | 记录版权与本地存放策略（能不能存、能不能存进仓库） | 登记表备注 |
| 4 | 如果来源很厚，先写一页"这个来源在本项目里扮演什么角色、能用什么、不能用什么" | 一张来源说明 |
| 5 | 只提取本项目要用的部分，不要整本搬 | 见第二步 |

> **来源 ID 命名**：`机构-主题-年份`，例如 `WSAVA-VACC-2024`、`AAHA-2021-NUTRITION`。

---

## 二、加一批知识条目

| 步骤 | 做什么 |
|---|---|
| 1 | 确认**每一个**出处都已在 `source-register.md` 登记 |
| 2 | 按受控词表选领域与标签（见第三节） |
| 3 | 写条目：结论、要点、注意事项 |
| 4 | **必须**填"紧急程度"（立即就医 / 尽快就医 / 可观察） |
| 5 | 引用出处时用**来源 ID**，不要写自由文字 |
| 6 | 跑校验（标签合法性、出处是否登记、紧急程度是否填写） |
| 7 | 标注审核状态：待审 / 已审（审核人 + 日期） |

---

## 三、受控词表规则

**领域**（现有 20 个 + 新增 3 个）：

| 类别 | 领域 |
|---|---|
| 已存在 | 通用成年犬、幼犬生长、老年犬、体重管理、肾脏、胰腺炎、肠道、皮肤、泌尿结石、内分泌、肝胆、心血管、骨关节、肿瘤、神经、口腔、繁殖、食品安全、危重症、血液 |
| **本次新增** | **免疫**、**检查指标解读**、**常见病表现与就医时机** |

**标签**：必须来自一张**受控标签表**，不允许随手写。

- 新增标签要走审核：说清"哪个环节会产出这个标签"。
- **任何标签，如果系统永远不会产出它，就不许写进条目**——
  这正是现在 SAFE 领域 7 条知识失效的原因。

---

## 四、绝对不做的事

| 禁止 | 原因 |
|---|---|
| 从品牌营销页、自媒体、论坛、SEO 文章提取内容 | E 级，见证据政策 |
| 把二手解读材料（幻灯片、科普图、短视频文案）当出处 | 只能当阅读辅助 |
| 一条知识挂多个互相冲突的结论 | 冲突要写清楚，不能糊在一起 |
| 给化验指标写死参考区间 | 区间因实验室而异，以顾客报告为准 |
| 给药物或剂量 | 越界 |
| 条目没有出处 | 校验直接报错 |
