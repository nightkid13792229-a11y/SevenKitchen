## 二、出处锚定：1,250 处

### 结果

| 置信度 | 出处数 | 含义 |
|---|---:|---|
| **高**（≥0.5 相似度） | 292 | 能指到具体段落 |
| **中**（0.3–0.5） | 76 | 指到段落，但匹配较弱 |
| **低**（文档已定位，段落未定） | 783 | 只到"这份文档" |
| **无** | 99 | 15 条内部笔记/外部文献（本就无原文）+ 84 条匹配不到 |

按**条目**看（387 条有出处的）：

| 状态 | 条目数 | 占比 |
|---|---:|---:|
| 至少一处锚到段落 | **223** | **57%** |
| 仅到章节级 | 157 | 41% |
| 完全锚不上 | 7 | 2% |

### 为什么只有 57%

**根本原因是跨语言**：知识条目是中文，原文是英文。逐字比对完全对不上。

实际用的办法是：**从条目的英文关键词（如 `calcium oxalate`、`hypercalciuria`）去匹配英文段落**。
所以——

- 关键词里带英文术语的条目，锚得住（223 条）
- 关键词全是中文的条目（如"限钙""复发率"），就锚不住，只能到章节级

**这是方法的边界，不是数据的问题。**

## 三、下一步怎么提高

| 办法 | 说明 |
|---|---|
| **表格锚定** | 出处里写了"表 12-5"的，直接对到已数字化的那张表（384 张已就绪），比文字匹配可靠 |
| **章节号锚定** | 写了"第 40 章"的，至少能对到该章的章节 id |
| **中文关键词补英文** | 给中文关键词补上对应英文术语（如"限钙→restricted calcium"），匹配率会明显上升 |
| **语义检索** | 用向量模型（需要额外接） |

第一条和第二条成本最低，建议先做。
