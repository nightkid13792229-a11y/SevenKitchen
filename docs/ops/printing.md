## 1. 设备与用途

| 项 | 说明 |
|---|---|
| 标签打印机 | 精臣 B3S（蓝牙） |
| SDK | JCING 小程序 SDK |
| 主要用途 | DIY 制作单（A4 竖版）、原料/成品标签、门店小票/标签 |

> 打印机型号/固件如果换了，先确认 SDK 是否仍兼容。

## 2. 小程序端初始化

关键点：

1. 编译平台/运行平台按 SDK 要求设置；
2. 初始化蓝牙监听；
3. 先申请蓝牙/位置权限，再搜索设备；
4. 连接前先清掉系统里旧的配对记录（换手机/换打印机后尤其重要）。

具体调用以 `miniapp/` 里的打印模块和 JCING SDK 文档为准。

---

## 3. 打印流程

### DIY 制作单（A4 竖版）

- 页面：员工端 DIY 制作单/打印预览；
- 内容：页头、狗狗信息、制作参数、食材清单、需补充营养、制作流程、重要提示、页脚；
- 版式规范见归档的 `PRINT_LAYOUT_DESIGN.md`；
- 打印前确认数据来自订单快照，不要用“当前食谱”。

### 标签

- 原料/成品标签按业务模板渲染；
- 标签尺寸、条码/二维码内容以模板为准；
- 打印后回读/抽检，避免空白标签或错位。

---

## 4. 故障排查

| 现象 | 先查 |
|---|---|
| 搜索不到打印机 | 打印机开机、蓝牙已开、权限已授权、距离/电量 |
| 连接失败 | 清除系统旧配对、重启打印机、重启小程序 |
| 打印空白/错位 | 纸张/标签尺寸、模板尺寸、SDK 初始化是否成功 |
| 只打一半 | 蓝牙信号、电量、缓冲区；重试并检查任务状态 |
| 换手机后不能用 | 旧配对残留、权限、SDK 平台配置 |
| 开发者工具正常、真机失败 | 蓝牙权限/真机能力，开发者工具不等于真机 |

处理顺序：**打印机状态 → 手机蓝牙/权限 → 旧配对 → SDK 初始化 → 模板/尺寸 → 代码**。
