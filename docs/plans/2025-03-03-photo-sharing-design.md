# 原料照片分享功能设计文档

**日期：** 2025-03-03
**功能：** 订单详情页原料照片分享
**目标：** 允许用户将原料照片通过微信分享给好友

---

## 一、功能概述

用户在订单详情页查看原料照片时，可以一键分享给微信好友。好友点击分享卡片后，进入独立的照片查看页面浏览所有原料照片。

### 核心特性
- 一键分享：点击按钮直接分享到微信
- 独立页面：好友在专用页面查看照片
- 权限控制：使用临时token保护隐私
- 网格布局：2列网格，点击放大全屏查看

---

## 二、整体流程设计

### 用户操作流程
1. 用户在订单详情页查看原料照片时，点击"分享照片"按钮
2. 系统生成一个临时访问token（有效期7天）
3. 弹出微信分享界面，显示小程序卡片：
   - 标题：`SevenKitchen原料照片`
   - 描述：`来自SevenKitchen的新鲜食材照片`
   - 封面：第一张原料照片的缩略图
4. 用户选择要分享的好友或群聊，发送卡片
5. 好友点击卡片后，进入独立的照片查看页面
6. 照片查看页面验证token有效性，展示所有原料照片

### 技术要点
- 使用微信小程序的 `button open-type="share"` 实现分享功能
- 后端生成临时token，与订单ID关联
- 照片查看页面通过URL参数接收token和订单ID
- 后端验证token有效性和订单是否存在

## 四、后端API设计

### 4.1 数据库设计
创建 `photo_share_tokens` 表：

```sql
CREATE TABLE photo_share_tokens (
  id VARCHAR(36) PRIMARY KEY,
  order_id VARCHAR(36) NOT NULL,
  token VARCHAR(32) NOT NULL UNIQUE,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  expires_at TIMESTAMP NOT NULL,
  created_by VARCHAR(36) NOT NULL,
  INDEX idx_token (token),
  INDEX idx_order_id (order_id)
);
```

### 4.2 API接口

#### 1. 生成分享token
**路径**：`POST /api/orders/:orderId/share-photos`

**功能**：为指定订单生成临时访问token

**返回**：
```json
{
  "code": 0,
  "data": {
    "token": "abc123def456",
    "expiresAt": "2025-03-10T17:00:00Z"
  }
}
```

**业务逻辑**：
- 验证用户是否有权限分享该订单（订单所有者或管理员）
- 生成随机token（32位字符串）
- 设置7天有效期
- 将token与订单ID关联存储

#### 2. 获取分享照片
**路径**：`GET /api/shared-photos/:token`

**功能**：通过token获取订单的原料照片

**返回**：
```json
{
  "code": 0,
  "data": {
    "photos": ["url1", "url2", "url3"],
    "uploadedAt": "2025-03-03T15:30:00Z"
  }
}
```

**业务逻辑**：
- 验证token有效性（未过期）
- 验证关联的订单是否存在且有原料照片
- 返回照片URL列表

## 五、错误处理与边界情况

### 5.1 前端错误处理

**分享失败场景**：
- 用户无权限分享：显示提示"您没有权限分享此订单的照片"
- 订单无原料照片：隐藏"分享照片"按钮或显示为禁用状态
- 网络请求失败：显示"分享失败，请稍后重试"

**照片查看页错误处理**：
- Token无效或过期：显示"链接已失效，请联系分享者重新获取"
- 订单不存在：显示"照片不存在或已被删除"
- 网络加载失败：显示"加载失败，请检查网络连接"
- 照片加载失败：显示占位图，允许重试

### 5.2 后端错误处理

**权限验证**：
- 验证用户是否为订单所有者或管理员
- 验证订单是否存在
- 验证订单是否有原料照片

**Token验证**：
- 验证token格式是否正确
- 验证token是否存在且未过期
- 验证token关联的订单是否存在

### 5.3 边界情况
- 同一订单多次分享：每次生成新的token（旧token仍有效）
- Token过期后访问：返回401错误，前端显示友好提示
- 分享链接被多次转发：任何获得链接的人都可以查看（符合预期）

## 八、安全考虑

1. **Token安全**：使用32位随机字符串，避免可预测性
2. **有效期限制**：7天有效期，自动过期
3. **权限验证**：只有订单所有者和管理员可以生成分享链接
4. **隐私保护**：分享卡片不显示订单号等敏感信息
