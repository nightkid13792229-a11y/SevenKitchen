# 食谱设计功能 - 产品设计文档

**版本：** 1.0
**日期：** 2026-03-08
**状态：** 已确认

---

## 1. 功能概述

### 1.1 功能定位

"食谱设计"是一个专业的宠物营养配方工具，帮助营养师科学地创建符合FEDIAF标准的狗狗鲜食食谱。系统支持两种创建方式：手动设计和AI辅助生成。

### 1.2 用户角色与权限

| 角色 | 权限 | 使用端 |
|------|------|--------|
| 营养师（内部） | 完整功能：创建、编辑、导出食谱 | Web管理后台 |
| 普通客户（C端） | 查看推荐食谱、生成个性化配方建议 | 小程序（第三期开放） |
| 管理员 | 管理原料库、营养标准配置 | Web管理后台 |

### 1.3 核心工作流程

```
选择创建方式（手动/AI）
       ↓
输入配方信息
       ↓
实时查看营养计算和达标状态
       ↓
调整优化配方
       ↓
保存并生成营养分析报告
```

## 2. 手动配方设计功能

### 2.1 界面布局

页面分为三个区域：

**左侧 - 原料选择区**
- 原料分类筛选（肉类、蔬菜、内脏、补剂等）
- 搜索功能
- 支持新增自定义原料
- 支持从USDA数据库导入

**中间 - 配方编辑区**
- 已选原料列表
- 每个原料显示：名称、配比百分比、重量（克）
- 可调整配比或重量
- 显示补剂添加建议（如钙粉、鱼油等）

**右侧 - 实时计算区**
- 能量密度（kcal/kg）
- 营养成分表（蛋白质、脂肪、纤维、灰分、水分、碳水）
- 达标状态指示灯
  - 绿色 = 达标
  - 黄色 = 接近标准
  - 红色 = 不足/超标
- FEDIAF标准对比

### 2.2 实时计算逻辑

当营养师调整任何原料的配比时，系统会：
1. 重新计算所有营养成分占比
2. 自动对比FEDIAF标准
3. 高亮显示不达标的营养素
4. 提示建议调整方向

## 3. AI辅助配方生成

### 3.1 AI生成流程

```
用户提交需求 → AI生成初稿 → 营养计算 → 达标检查
                                           ↓
                    ┌──────────────────────┴──────────────────────┐
                    ↓                                             ↓
               全部达标                                      未达标
                    ↓                                             ↓
              输出合格配方                              AI自动调整（循环）
                                                                  ↓
                                                    ┌──────────────┴──────────────┐
                                                    ↓                             ↓
                                              调整后达标                    达到调整上限
                                                    ↓                             ↓
                                              输出合格配方              输出配方+差距报告
```

### 3.2 AI输入信息表单

**1. 狗狗基本信息**
- 选择已有狗狗档案 或 手动输入
- 年龄、体重、品种、活动量、绝育状态

**2. 健康需求**（可多选）
- 健康体态
- 挑食怪
- 玻璃胃（肠胃敏感）
- 胰腺呵护
- 低脂需求
- 美毛护肤
- 其他（自由输入）

**3. 口味偏好**
- 喜欢的肉类（牛肉、鸡肉、羊肉等）
- 不喜欢的食材（排除列表）

**4. 原料限制**
- 过敏原排除（系统自动关联狗狗档案中的过敏信息）
- 可选原料范围限制
- 特殊要求备注

### 3.3 自动调整机制

**调整策略**
1. 优先调整原料配比
2. 其次建议添加补剂（如钙粉、维生素等）
3. 最后考虑替换原料

**调整次数上限**
- 默认上限：10次
- 每次调整后重新计算所有营养素
- 达到上限后停止尝试

**调整日志**
- 记录每次调整的内容
- 显示营养素变化趋势

### 3.4 最终输出结果

**情况一：成功达标**
- 输出配方详情
- 显示"完全符合FEDIAF标准"徽章
- 展示所有营养素达标情况

**情况二：未能完全达标**
- 输出当前最优配方
- 差距报告包含：
  - 未达标营养素清单
  - 每项的差距数值（当前值 vs 标准值）
  - 差距百分比
  - 建议的人工调整方向
- 标记为"需人工优化"

### 3.5 营养师后续操作

- 达标配方：直接使用或微调
- 未达标配方：
  - 参考差距报告手动调整
  - 或放宽部分输入限制重新生成

## 4. 原料库管理

### 4.1 数据架构

采用独立营养数据库方案，与现有采购库分离：

```
┌─────────────────────┐         ┌─────────────────────┐
│   采购原料库         │         │   营养原料库         │
│   (Ingredient)      │         │   (NutritionFood)   │
├─────────────────────┤         ├─────────────────────┤
│ • 采购信息           │         │ • 完整营养数据       │
│ • 价格成本           │   映射   │ • 多数据来源         │
│ • 库存管理           │ ←─────→ │ • 版本管理          │
│ • 出肉率等          │         │ • FEDIAF对标        │
└─────────────────────┘         └─────────────────────┘
```

### 4.2 营养原料库表结构 (NutritionFood)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| name | String | 食材名称 |
| category | Enum | 分类（肉类/蔬菜/内脏/谷物等） |
| data_source | String | 数据来源（USDA/自测/文献等） |
| version | Int | 版本号 |
| status | Enum | 状态（PENDING/VERIFIED） |
| nutrition_data | JSON | 完整营养数据 |
| created_at | DateTime | 创建时间 |
| updated_at | DateTime | 更新时间 |

### 4.5 原料数据来源

**1. 自定义新增**
- 营养师手动录入新原料
- 需填写完整营养数据
- 新增后状态为"待验证"

**2. USDA数据库导入**
- 输入食材名称搜索USDA数据库
- 显示匹配结果列表
- 选择后自动填充营养数据
- 支持单位转换

### 4.6 原料审核机制

| 状态 | 说明 | 使用限制 |
|------|------|----------|
| PENDING（待验证） | 新录入，数据需确认 | 可用于测试配方，不可用于正式发布 |
| VERIFIED（已验证） | 管理员审核通过 | 可用于正式配方 |

## 5. 食谱版本管理

### 5.1 自动版本机制

| 场景 | 系统行为 |
|------|----------|
| 新建食谱 | 创建 v1 版本 |
| 修改已有食谱 | 自动创建新版本（v2, v3...） |
| 查看历史 | 可查看所有历史版本，但不可修改 |

### 5.2 版本记录内容

每个版本保存完整快照：
- 配方信息（原料及配比）
- 营养计算结果
- 达标状态
- 创建时间和操作人
- 修改备注（可选）

### 5.3 版本对比功能

营养师可对比任意两个版本：
- 原料配比变化
- 营养素变化
- 达标状态变化

### 5.4 版本使用规则

- 订单关联特定版本（下单时锁定）
- 生产使用订单中锁定的版本
- 新版本不影响已有订单

## 6. 营养分析报告

### 6.1 报告生成时机

- 配方保存后可随时导出
- 支持导出当前版本或任意历史版本

### 6.2 报告内容结构

**1. 基本信息**
- 食谱名称、版本号
- 创建日期、创建人
- 能量密度

**2. 原料构成**
- 原料清单及配比
- 每100g配方中各原料含量

**3. 营养成分表**
- 按FEDIAF标准分类展示
- 每项显示：
  - 营养素名称
  - 当前含量
  - FEDIAF标准值（最小/最大）
  - 达标状态（✓达标 / ⚠接近 / ✗未达标）

**4. 达标汇总**
- 达标项数量 / 总项数量
- 整体达标率百分比

**5. 钙磷比专项**
- 钙含量
- 磷含量
- 钙磷比数值
- 是否在标准范围内（1:1 至 2:1）

### 6.3 导出格式

- PDF格式 - 适合存档和分享
- 导出文件命名：`食谱名称_版本号_日期.pdf`

## 7. 开发优先级与分阶段计划

### 7.1 MVP阶段（第一期）

核心功能，满足营养师基本使用：

| 模块 | 功能 | 优先级 |
|------|------|--------|
| 手动配方设计 | 原料选择、配比调整、实时计算 | 高 |
| 营养计算 | FEDIAF标准对比、达标状态显示 | 高 |
| 营养原料库 | 基础数据录入、USDA导入 | 高 |
| 版本管理 | 自动版本、历史查看 | 高 |
| 报告导出 | 营养分析报告PDF | 中 |

### 7.2 第二期扩展

| 模块 | 功能 | 优先级 |
|------|------|--------|
| AI辅助生成 | 需求输入、配方生成、自动优化 | 高 |
| 配方优化 | 调整建议、差距报告 | 高 |
| 原料映射 | 营养库与采购库关联 | 中 |

### 7.3 第三期（C端开放）

| 模块 | 功能 | 优先级 |
|------|------|--------|
| 客户端入口 | 简化版配方推荐 | 中 |
| 个性化生成 | 基于狗狗档案自动推荐 | 中 |
| DIY导出 | 家庭制作指南 | 低 |

## 8. 技术要点

### 8.1 营养标准

- 采用 FEDIAF 2024 版标准
- 系统需内置完整的营养素要求表
- 支持后续标准更新

### 8.2 计算精度

- 营养素计算保留2位小数
- 配比百分比保留1位小数
- 能量值取整

### 8.3 性能考虑

- 实时计算使用前端缓存
- 大量营养素计算考虑Web Worker
- USDA导入考虑接口限流
