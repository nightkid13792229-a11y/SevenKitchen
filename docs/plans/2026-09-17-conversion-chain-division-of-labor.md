# 三页转化链路分工表（草案）

> 覆盖：**食谱详情页 → 订购成品页 → 确认订单页**
> 承接 `2026-09-17-recipe-order-page-ux-assessment.md`（v3 评估）与 `2026-09-17-recipe-order-page-conversion-plan.md`（转化方案）
> 本文是设计对齐文档，用于从链路整体视角解决「哪一页讲什么、哪些内容重复、哪些信息掉了」。

## 一、本轮确认的链路决策

| # | 决策项 | 结论 |
|---|--------|------|
| 1 | 订购成品页定位 | 做成**自洽的完整商品详情页** |
| 2 | 分流（自己做 ↔ 买成品） | **暂不打通**，保持现状（单向） |
| 3 | 确认订单页 | **纳入本轮**，一起改 |
| 4 | 详情页参考价条 | **删除**。理由：详情页兼做 DIY 分流，展示价格会让用户误以为"自己做"也要花这个钱；而 DIY 链路几乎不收费（仅在生成的制作清单里有补剂/商品推广链接） |
| 5 | 价格重心 | **归口到订购成品页重点展示** |
| 6 | 售后保障 | 破损变质：无理由仅退款、不退货、全额退款。不爱吃：不承诺，用试吃装承接 |
| 7 | 评论 | 按来源拆分：购买评论 → 订购页；DIY 评论 → 详情页 |
| 8 | 优惠 / 复购 / 连带推荐 | 本轮做（方案见转化方案文档） |
| 9 | 产品优势呈现 | 下一轮 |

## 二、链路总览与角色

```
食谱详情页  ──「买成品」──▶  订购成品页  ──「确认订单」──▶  确认订单页
   ▲    │                                                      │
   └────┘                                                （支付后）
   （收藏 / 自己做 → DIY 链路）
```

| 页面 | 角色 | 回答的核心问题 | 禁忌 |
|------|------|----------------|------|
| **食谱详情页** | 种草 + **分流** | 这是什么？为什么好？**自己做还是买成品？** | 不展示价格（会污染 DIY 分流）<br>不做成品配置 |
| **订购成品页** | 说服 + **配置** | 为什么买成品？适合我家狗吗？买多少？**凭什么信你？** | 不重播食谱故事<br>不做地址/日期（属结算页） |
| **确认订单页** | 承诺 + **核对** | 哪天到？多少钱？保障是什么？确认支付 | 不做说服（说服已在上游完成） |

### 核心洞察：订购页的种草基调与详情页不同

详情页分流后，两类买家动机完全不同：

- **「自己做」** 要：掌控感、省钱、动手乐趣
- **「买成品」** 要：**省事、专业、确定性**

因此订购页的种草**不是详情页种草的重播**，而是**成品专属价值主张**：
> 「你不用自己做 —— 专业营养配比、分量精确可控、冷链到家、省时省心。」

## 三、分工原则

**原则一：自洽 ≠ 重复。**
订购页要自洽的是「**买成品这个决策**」，不是「这个食谱的介绍」。

**原则二：同一信息只在「决策真正发生的那一页」完整呈现**，其他页只做摘要 + 跳转入口。

**原则三：上游已建立的信息，下游只做「复述一次」用于安心**，不重新论证。

## 五、各页板块顺序

### 5.1 食谱详情页（调整点）

**定位修正（2026-09-17）**：详情页应**尽量简单**——本质是「对该食谱做一个大致介绍」+「自己做 / 买成品」的分流。
因此它不是"内容最全的一页"，而是**判断页**，不是资料页。

**精简原则：保留「好不好」的判断信息，移走「怎么做」的操作信息。**

| 动作 | 内容 |
|------|------|
| **删除** | 底部参考价条 |
| **替换** | 价格提示文案改为**无数值的价值/流程说明**，例如「成品订购按狗狗体重精确计算份量与价格 · 已含冷链配送」 |
| **保留（定位）** | 狗狗选择器 + 生命阶段版本：定位为「**提前配置档案 + 适配提示**」，为下游价格与原料计算做准备 |
| **保留（判断）** | 封面 / 食谱名 / 卖点 / 食谱说明 / 原料概要 / 营养要点 / 评价 |
| **考虑精简** | 完整原料配比 → 由 **DIY 制作清单**承载；完整营养全表 → 由**产品标签 / 订购页营养要点**承载 |
| **底部栏** | 收藏 + 自己做 + 买成品（去掉参考价条后更干净） |
| **可选** | 相关食谱推荐位；试吃装引流入口 |

> ⚠️ **需权衡的风险**：详情页同时是**种草页**。若精简过头，「买成品」的说服会全部压到订购页，
> 而订购页的基调是「省事、专业、确定性」，缺少「这个食谱好在哪」的情感铺垫。
> 建议的精简边界：**移走操作信息（配比、做法、储存、烹饪），保留判断信息（好吃吗、适合谁、别人怎么说）**。

## 五之二、核心卖点体系（新增，2026-09-17）

用户提出需展开核心卖点。经核实，部分卖点**不是"待策划"，而是"素材已在系统里"**。

### 已有素材（成本极低）

| 卖点 | 现状核实 |
|------|----------|
| **每单配餐实拍** | 订单 `productionPhotos`（原料照片）**已存在**，订单详情已展示；`PhotoShareToken` 分享机制**线上已产生 411 次分享** → 素材与机制齐备 |
| **一线商超采购** | 原料明细已含品牌 / 采购渠道字段（山姆、盒马、沃尔玛）→ 与「原料明细保留品牌」的决定天然吻合，**品牌本身就是卖点** |
| **营养配比** | FEDIAF 标准背书已上线，营养数据完备 |
| **定制而非批量** | 订单为按狗定制的分装模式，结构上就是定制品 |

### 建议的卖点分层与归位

| 层 | 卖点 | 归位 |
|----|------|------|
| 1 · 食材 | 一线商超采购（山姆 / 盒马 / 沃尔玛） | 订购页「里面是什么」+ 详情页简介 |
| 2 · 配方 | 按体重 / 生命阶段 / 活动量精算，非通用配方 | 订购页「适合我家狗吗」+「怎么买」 |
| 3 · 制作 | 小批量现做，非工业化库存 | 订购页「凭什么信你」 |
| 4 · 过程透明 | **每单配餐实拍**（竞品无法复制的信任资产） | 订购页「凭什么信你」 ← 把「待素材」变成「素材已有」 |
| 5 · 交付 | 急冻锁鲜 + 顺丰冷链 + **破损变质全额仅退款** | 订购页「凭什么信你」+ 结算页复述 |
| 6 · 省事 | 你不用自己做 | 订购页整体基调 |

### ⚠️ 合规边界（必须遵守）

- **禁止疾病预防 / 治疗声称**（已做过合规清理）。
- **功能声称需有依据并标注添加量**。
- **「鲜食比狗粮好」这类比较性表述要谨慎**：建议改为**正面自述**（「我们每单现做」），
  而非贬低竞品（「干粮是工业品」）——后者有《广告法》贬低同行风险，且难以自证。
- 营养配比 / 标准相关声称需有依据（FEDIAF 背书可讲）。

## 六、决策 3 衍生的连带影响（重要）

> ⚠️ **修正记录（2026-09-17）**：本节初稿曾判断"详情页撤价会造成价格预期缺失、订购页价格冲击"。
> 经核实**该判断不成立**：① 订购页价格位于**底部固定栏，常驻可见**，选狗后立即出数；
> ② 用户从**首页/食谱橱窗**进入，首页已展示「**成品参考价 约¥X/100g 起**」，价格预期在上游就已建立。
> 以下为修正后的真实影响。

**① 真正要处理的不是"价格冲击"，而是"价格单位跳跃"。**

| 位置 | 价格口径 |
|------|----------|
| 首页（食谱橱窗） | 约 **¥X / 100g 起**（小单位，显得低） |
| 详情页 | 撤掉（本轮决定） |
| 订购页 | **整单总价** + ¥X/袋 |
| 结算页 | 总价构成 |

用户从「¥X/100g」直接跳到「整单 ¥XXX」，**中间缺一次换算**。
→ 因此「**每天成本 / 每餐成本**」的真正作用不是"补缺失的预期"，而是**把首页的低单位价翻译成用户能感知的总价感受**，让"贵不贵"这一步有落点。

**② 详情页的狗狗选择器是"预配置"，应保留。**
它在详情页完成选狗，使**订购页的价格计算与原料计算直接就绪**，减少下游摩擦；
同时对「买成品」这条链路本身就是价值（提前建档 + 生命阶段匹配）。
→ **保留**，定位为「**提前配置 + 适配提示**」，不改目的、不删除。

**③ 需要统一的"三页价格叙事"。**
删除参考价条后，价格叙事变为：

| 页面 | 价格角色 |
|------|----------|
| 详情页 | **不给数字**（只说明"按体重计算 · 含冷链配送"） |
| 订购页 | **吸引 + 锚定**（总价 / 每袋 / **每天成本** / 首单立减） |
| 结算页 | **确认**（构成明细 + 无隐藏费用） |

**④ DIY 链路的商业化不受影响。**
DIY 链路的收入来自制作清单里的补剂/商品推广，与成品价格无关。删除详情页价格条**恰好消除了两条链路的定价混淆**，是净收益。

## 八、实施分期建议

**设计一次做完，实施分阶段**（同改三页 = 三套回归测试 + 跨页跳转全部重测，风险过高）。

| 期 | 范围 | 内容 |
|----|------|------|
| 一期 | 订购页 | 零成本速赢（卖点 / 可吃天数 / 每天成本 / 回详情页入口 / 交付节奏）+ 售后保障板块 |
| 二期 | 详情页 + 结算页 | 删参考价条、改价格文案、狗狗选择器换目的；结算页加强核对与保障复述 |
| 三期 | 订购页 | 连带推荐（同系列 → 相似食谱）+ 修评价生产闭环 |
| 四期 | 订购页 | 新客首单立减 + 复购提醒 |
| 五期 | 独立立项 | 试吃装（新产品定义） |
