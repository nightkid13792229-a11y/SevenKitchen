## 设计决定（为什么这么写）

| # | 决定 | 理由 |
|---|---|---|
| 1 | **四档画进同一张图** | 没有参考图了，「四只狗是同一只」只能靠单次生成内部自洽。分四次画必然四只不一样。 |
| 2 | **图里不放文字** | 标签必须与问卷选项**逐字一致**（「明显往上收」「轻微往上收」「平直」「往下垂」），不能交给模型碰运气；文字统一用脚本叠加。 |
| 3 | **腹部线条写成「相对胸底的位置」** | 上一批最大问题是四档差异说不清。改成可对照的量：腹线**高于／略高于／齐平／低于**胸底，一眼能比。 |
| 4 | **明确写死「骨架不变、只有腰部宽度变」** | 防止模型把瘦狗整体缩小、胖狗整体放大 —— 那样比不出体况。 |
| 5 | **一次只画一个动作** | 上一批实测：一张图塞两个视角／两个场景，模型注意力被分掉，质量明显下降。 |

## 提示词 1：四档侧视对照图（主图）

**尺寸**：1728×960（16:9 横排）

```
宠物健康科普用的医学插画，纯白背景，画面中没有任何文字。

画面横向并排 4 只完全相同的短毛中型犬（拉布拉多体型），全部四脚站立、头朝左、大小相同、脚底对齐在同一条水平线上。4 只狗只有体况胖瘦不同，品种、毛色、头型、耳朵、尾巴形状、站姿必须完全一致。米色短毛，深棕色描边，扁平写实风格，轮廓清晰。

从左到右四只狗的腹部线条依次变化（这是本图重点）：

第1只 偏瘦：肋骨轮廓隐约可见，腹部从肋骨后方开始明显向上收，腹线显著高于胸底，腰部很细。

第2只 理想：肋骨不可见但轮廓匀称，腹部柔和地向上收，腹线略高于胸底，腰线自然。

第3只 偏胖：看不到腰部收窄，腹部线条几乎水平，腹线与胸底基本齐平，身体中段饱满。

第4只 肥胖：腹部明显向下垂、低于胸底，呈圆润下垂的弧线，颈部和肩部明显变厚变圆，整体横向变宽。

注意：4 只狗的肩高、腿长、头部大小必须完全相同（骨架不变），只有腹部线条和身体厚度依次变化。

没有项圈、没有牵引绳、没有文字、没有数字、没有标注线、没有箭头、没有背景装饰、没有阴影，4 只狗之间留出均匀的白色间隔。
```

**用途**：裁剪出 4 只狗 → 用脚本竖排 + 叠加标签 → 作为「侧视四档对照图」上线

## 审核要点（请重点看这几处）

1. **犬种**：写的是「短毛中型犬（拉布拉多体型）」。要不要换成具体犬种（金毛／柯基／中华田园犬）？
2. **画风**：写的是「扁平写实风格」。要不要更写实（接近照片）、或更简洁（接近线稿）？
3. **四档的腹部描述**：`高于 / 略高于 / 齐平 / 低于 胸底` —— 这个梯度对不对？
4. **提示词 4 俯视图**：要不要试？（0.1 元）
