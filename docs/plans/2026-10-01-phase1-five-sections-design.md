## 二、合并后的记录表单（**这是要你确认的重点**）

一张表单，顶部一个「类型」选择（就诊 / 体检），字段按类型自动对应到两张表：

### 主字段（一眼能看到）

| 字段 | 必填 | 选「就诊」时 | 选「体检」时 |
|---|---|---|---|
| **日期** | ✓ | 就诊日期 | 体检日期 |
| **类型** | ✓ | 就诊 / 体检 | 就诊 / 体检 |
| **诊断结果** | ✓ | 诊断结果 | 检查结论 |
| **处理或建议** | | 处理方式 | 医生建议 |
| **兽医** | | 接诊兽医 | 接诊兽医 |
| **附件** | | 报告照片 / PDF | 报告照片 / PDF |

### 收进「更多」（默认收起）

| 字段 | 选「就诊」时 | 选「体检」时 |
|---|---|---|
| 症状或疾病描述 | ✓ | — |
| 体检类型 | — | 默认「常规体检」 |
| 用药 | ✓ | — |
| 状态（待确认／治疗中／已康复…） | ✓ | — |
| 复查日期 | ✓ | — |
| 备注 | ✓ | ✓ |

**三个要点：**

1. **「诊断结果」是唯一的必填内容字段** —— 这是你第 3 条的要求（"病史可以只保留一个诊断结果"）
2. **体检没有"诊断"，所以这一栏在体检时叫「检查结论」**，避免让家长以为体检也能下诊断
3. **体检类型默认「常规体检」**，收进更多也不会卡住保存

## 三、列表怎么显示

**一个列表装两类记录**，按日期从新到旧排。每行：

```
[就诊] 2026-09-12   慢性胃炎，已开胃药              展开 / 删除
[体检] 2026-08-30   血常规、生化，未见明显异常        展开 / 删除
```

- 左侧方括号里是**类型徽标**（就诊 / 体检），颜色区分
- 中间是**日期 + 诊断结果摘要**
- 未保存的草稿有醒目标记

## 五、外壳统一规范（六个板块都按这一套）

| 部件 | 统一为 |
|---|---|
| 板块标题 | 加粗、跟随板块色 |
| 说明文字 | 小字灰色，最多一行 |
| 计数 | 右上角「N 条」 |
| 空态 | 居中：**「还没有XX记录」+ 一句引导 + 主操作按钮** |
| 列表行 | 同一套卡片：序号/徽标 · 标题 · 摘要 · 右侧「展开／删除」 |
| **主操作按钮** | **统一放在列表底部、整行宽**（现在有的在顶部、有的在底部、有的在行内） |
| 卡片间距 | 统一 |
| **日期格式** | 一律 `YYYY-MM-DD` |
| 状态文案 | 统一为：已保存 / 未保存 / 保存中 |

**空态示例**（现在六个板块各写各的）：

```
        还没有病历记录
   带狗看过病、做过体检查，记一条，下次就诊用得上
        [ 新增病历 ]
```
