# 疫苗板块 · 定位与方案（v3）

**日期**：2026-10-04
**定位**：记录（打过什么）→ 计划（接下来怎么打）→ **提醒（什么时候、打什么产品）**

---

## 一、「提醒做完善了，还需要计划吗？」

**我的答案：计划不是提醒的替代品 —— 计划算出来的东西，就是提醒的内容本身。**

```
免疫程序表  ──算──→  该打什么、什么时候  ──展示──→  提醒
（要审核的东西）        （这就是"计划"）
```

所以拆成两半看：

| | 能不能省 |
|---|---|
| **计划的计算**（按免疫程序 + 记录，算出该打什么） | ❌ **不能省** —— 提醒说的每个字都从这儿来 |
| **"计划"作为一个独立板块**（现在疫苗标签最上面那一大块：下一步卡 + 冲突提示 + 完整列表 + 决策按钮） | ✅ **可以省，而且应该省** |

**具体怎么省**：把它从"一块内容"降级成"**一行 + 一个展开**"。

```
疫苗标签打开
┌────────────────────────────────────┐
│ 下一步：狂犬疫苗 第 3 次               │  ← 就一行
│ 2026-11-16 ~ 2027-03-16   [看全部 ▾] │
└────────────────────────────────────┘
（下面是顾客自己的接种记录）
```

点「看全部」展开：完整的接种计划、还差几针、你的记录与建议不一致的地方、以及"接受/推迟/不做"那几个选择。

**这样它就不再是一个需要单独存在的功能，而是提醒的"详情页"。**

> ⚠️ 但有一点要说清楚：**审核还是得做。**
> 提醒里说的"什么时候打什么"，字字都来自免疫程序表。
> 程序表没过审，提醒就是在给顾客未经验证的建议——
> 而且你第三章要加**产品推荐**，那比"什么时候打"更需要专业背书。

---

## 二、时间窗 —— 按你说的，不改

我原方案里"把窗口收窄成某一天"**撤回**。你的理由比我充分：

- 兽医排班、疫苗到货、狗当天的身体状态都会影响实际哪天去
- 给一个死日子，错过了反而让人焦虑
- **指南给的全是窗口**（6~8 周、每 2~4 周、≥16 周），窗口本来就是这套体系的语言

提醒保持窗口形态：

```
狂犬疫苗 第 3 次
时间：2026-11-16 ~ 2027-03-16
```

## 三、A 层 + 推荐具体品牌 —— 同意，但要有个来源

方向我同意：**按疫苗种类提醒，同时给出常见产品**。国内大厂就那几家，列得出来。

**但"推荐哪个产品"这件事，我建议按这个顺序落地：**

### 3.1 先有一份产品清单，字段是这些

| 字段 | 例 |
|---|---|
| 产品名 | 卫佳伍 |
| 厂商 | 硕腾 |
| 防哪些病 | 犬瘟热、腺病毒2型、副流感、细小病毒 |
| **适用周龄** | 决定它能不能顶上某一步 |
| 是否含狂犬 | 决定它是核心苗还是狂犬苗 |

### 3.2 来源必须是权威的，**不能凭印象写**

我自己搜了一轮，网上能搜到的基本是电商页和论坛，不足以作为依据。建议按这个优先级取：

1. **国家兽药基础数据库**（中国兽医药品监察所）—— 批准文号与产品名，这是官方登记
2. **厂商说明书** —— 适用周龄、防什么病（这两项只有说明书能定）
3. **顾客疫苗本识别出来的产品名** —— 真实在用的东西（现在 0 条，等有数据）

> 那支"幼犬保"（4 周龄起打）就是典型：**只有看说明书才知道它 4 周起能用**，
> 光看名字推不出来。所以这份清单必须逐条对着说明书核，不能靠常识。

### 3.3 措辞要克制

| 说 | 不说 |
|---|---|
| "常见的有：卫佳伍、英特威四联" | "建议打卫佳伍" |

两个原因：
- **各医院进的货不一样**，推荐了顾客也未必买得到
- "建议打哪个商品"比"什么时候打"更靠近诊疗，这不是我们该拍板的

### 3.4 这一块比程序表更需要兽医过一眼

程序表是"什么时候打"，产品清单是"**打哪个商品**"。
后者已经挨着推荐用药了 —— 我建议清单做完**和程序表一起送审**。

## 四、改完之后，提醒长这样

```
下一步
狂犬疫苗 第 3 次
时间：2026-11-16 ~ 2027-03-16
常见产品：卫佳伍（硕腾）、英特威（默沙东）    ← 待核实，仅示意
依据：国内狂犬属强制免疫，通常每年一次
```

**加上入口角标**：健康管理入口显示"有 1 针该打了"，不用顾客自己找到疫苗标签里。

## 五、记录侧（你上一条说的"先完成录入"）

现状没变：功能已建好，全库 4575 只狗 0 条 —— 根子是**记完没回报**（计划关着）。

现在能做的两处小修：

1. **一点即选的标签改成"产品名 + 病名"混合**
   现在是纯病名（犬瘟热、犬细小病毒…），而顾客本子上写的是产品名（卫佳伍、犬四联）。
   两边对不上，顾客要么找不到、要么乱点。
2. **「状态」砍掉"已逾期"**
   三个值全是顾客手选的；"逾期"是今天 vs 到期日的事实，不该让顾客自己选，
   而且和我们刚定的"没有记录就不说已过期"冲突。

## 六、顺序

| 顺序 | 事项 | 卡在哪 |
|---|---|---|
| **1** | 免疫程序表审核 | 卡在你和兽医（审阅稿已给） |
| **2** | 建疫苗产品清单（3.2 的三个来源） | 研发起草 → **和程序表一起送审** |
| **3** | 提醒：入口角标 + 计划降级成一行 | 等 1、2 |
| **4** | 记录：标签改产品名、砍掉"已逾期" | **现在就能做** |
