## 二、改后的第一步长什么样

```
[ 体况评分 + 我们的建议 ]      ← 狗狗一选定就显示
   按它目前的体况评分 5/9（理想），我们建议：维持。
[ 想帮它减重、维持，还是增重？ ]
   （ 减重 ）（ 维持 ）（ 增重 ）   ← 三选一，未选不能提交
[ 去制定体重管理计划 ]          ← 选维持或未选时置灰，下面写明原因
```

- 选**维持** → 计划按钮置灰，下面写「选「维持」就不需要制定增减重计划了。」
- 选**减重 / 增重** → 按钮点亮，点它带着方向进计划页
  （`direction=LOSS|GAIN` → 计划页 → 后端 `resolveSuggestedPlan.forcedDirection`）
- 未选 → 按钮也是灰的，下面写「先在上面选一个方向（减重 / 维持 / 增重）。」
- **已经有进行中的计划** → 不问三选一：显示「查看体重管理计划」，
  方向以计划为准（避免顾客选出与计划相反的方向，两个值都交给营养师）

## 三、我加的一条约束（老板没要求，但不加会出事）

**偏胖的狗不给选「增重」，偏瘦的狗不给选「减重」。**

原因：这个方向会**原样交给营养师**，而给偏胖的狗出增重食谱、
给偏瘦的狗出减重食谱都是反的。被挡的那一项在界面上是灰的，
点它会有 toast 说明（「它现在的体况偏胖，增重这一项先不给选；想增重请先咨询兽医。」），
不静默失败。「维持」永远可选 —— 不想增减重是顾客的自由。

这条与计划页后端那条边界是同一套口径：**只在系统本来没有建议时才听顾客的**。

> 如果老板希望三个方向完全放开（不加这道挡），说一声即可改回。

## 四、第 1 条的一个配套

四个板块收起后，**多只狗**的家长进来会只看到一张 Banner（本页只在"只有一只狗"时
自动选中）。所以补了一句引导卡片：

> 先选一下要给哪只狗狗定制
> 点上面的头像可以切换；选好之后，体重管理、过敏信息这些就会出来。

提交按钮也一并收起（没有狗可提交，留着只会点出一句"请选择狗狗"）。
