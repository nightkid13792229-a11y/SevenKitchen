## 零、先说清楚：推翻什么，保留什么

### 0.1 推翻

**上一版按「头牌蛋白」划分主货架（牛肉线/猪肉线/鸡肉线…）——这是纯粹的供给端思维。**

它的推理链是：先看生产库里有什么 → 按占比归类 → 得出货架。所以才会得出"牛 9 道、猪 8 道，所以牛线和猪线最充实"这种结论。

**这个逻辑的荒谬之处**：如果库里全是牛肉菜，那货架上就只有牛肉线。**产品线变成了"我们做过什么"的账本，而不是"顾客要什么"的答案。**

### 0.2 保留

| 保留项 | 为什么 |
|--------|--------|
| **每道菜覆盖 5 个生命阶段** | 这是你定的产品原则，也是真实的杠杆（一个 SKU 服务全部客群） |
| **法规约束** | 不是"数据"，是经营前提 |
| **犬营养科学（FEDIAF）** | 同上 |

## 一、我发现的第一个结构性矛盾（必须先解决）

**「每道菜覆盖 5 个生命阶段」与「按生命阶段划产品线」是互斥的。**

想清楚这件事：

- 如果每个产品线都覆盖全部 5 个阶段 → 那 4 条产品线在"阶段"这个维度上**完全重叠**，阶段不能用来区分产品线
- 如果按阶段划产品线（幼犬线/成犬线/老年犬线）→ 那每道菜就必须**只属于一个阶段**，与你的原则冲突

**这个矛盾逼出一个结论：产品线只能在「阶段」以外的维度上划分。** 而阶段本身，变成**每道菜都必须做全的"及格线"**，不是划分依据。

这也解释了你为什么直觉上觉得"按生命阶段分不对"——你的直觉是对的。

**那剩下的维度只有两个：购买动机 和 配方特性。**
**购买动机是需求端，配方特性是产品端。产品线必须按购买动机划。**

## 二、需求端推导：顾客到底在买什么

### 2.1 先明确一件事：鲜食的竞争对手不是别的鲜食

一个家长给狗买鲜食时，他实际在**放弃**这些东西：

| 他放弃的 | 他为什么愿意放弃 |
|----------|------------------|
| 膨化粮的便利（开袋即食、常温储存、便宜） | 他觉得"那不够好" |
| 自制（自己买肉煮） | 他没时间 / **怕自己配错营养** |
| 什么都不做（继续喂现在的） | 他有了某个触发点 |

**所以鲜食真正的价值主张不是"更健康"（这个太空），而是：**

> **让一个不懂营养的家长，能安心地给狗吃上"像自己做饭一样好"的东西。**

这里有两个词是关键：**安心** 和 **像自己做饭**。前者对应"我怕配错"，后者对应"我要新鲜、要看得见"。

### 2.2 四个购买动机（需求端的真实分野）

我从"家长为什么掏出这笔钱"出发，拆出四个互不重叠的动机：

| # | 购买动机 | 顾客心里的话 | 他怕什么 |
|---|----------|--------------|----------|
| **1** | **省心托付** | "我不想研究营养，你配好就行，别让我操心" | 怕配错、怕漏了营养、怕麻烦 |
| **2** | **怕它吃腻 / 想给它换换** | "它吃了半年一样的了，会不会腻" | 怕狗不吃、怕单一、怕自己不够用心 |
| **3** | **给它最好的** | "我要给它我能给的最好的" | 怕自己亏待了它 |
| **4** | **它现在有点状况** | "它最近有点胖 / 拉得不好 / 毛不好" | 怕选错、怕耽误、怕不能喂 |

**这四个动机互不重叠，且覆盖了绝大多数购买决策。这就是产品线的四个归宿。**

### 2.3 四个动机的合规可行性评估

这是产品经理必须做的一步——**不是所有需求都能用产品承接，有些只能用品类教育或服务承接。**

| 动机 | 需求强度 | 合规表达空间 | 能不能做产品线 |
|------|----------|--------------|----------------|
| 1 · 省心托付 | 最高（是鲜食的基本盘） | ✅ 宽：成分事实、标准背书、工艺特性 | ✅ **能做** |
| 2 · 换换口味 | 高 | ✅ 宽：成分事实、蛋白种类、风味 | ✅ **能做** |
| 3 · 给它最好的 | 高（是溢价来源） | ✅ 宽：稀有食材、工艺、标准 | ✅ **能做** |
| 4 · 有点状况 | **很高** | ⚠️ **窄**：只能走"配方特性"（低脂肪/低能量），不能用疾病或功效语言 | ⚠️ **能做，但天花板低** |

**动机 4 是最值得说的一个。**

顾客的需求是真实且强烈的（"我家狗有点胖"是所有家长都会有的焦虑）。但法规**不允许**我们按疾病或功效来组织货架。合法的路只有一条：

> **把"状况"翻译成"配方特性"。**
> 不说"体重管理"，说 **低脂肪 / 低能量**（有法定门槛，达得到就能标）。
> 不说"肠胃敏感"，说 **单一动物蛋白 / 易消化**（成分事实）。
> 不说"皮肤差"，说 **含 Omega-3**（成分事实）。

**这不是妥协，反而更可信**——因为每一项都有法定门槛兜底，是可验证的。

**但必须承认：动机 4 这条路，产品线的"说服力天花板"比其他三条低。** 顾客看到"低脂肪"不会像看到"体重管理"那样立刻心动，需要靠详情页的科普内容把这两者连起来。这是运营成本，不是产品设计能解决的。

## 三、产品线架构：四条线

按四个购买动机，一一对应。

```
                          【成品鲜食】
                               │
        ┌──────────┬───────────┼───────────┬──────────┐
        │          │           │           │          │
   ① 日常安心   ② 换换口味   ③ 珍稀臻选   ④ 轻负担
     「托付」    「轮换」     「最好的」   「有状况」
        │          │           │           │
   营养全面     蛋白多样化    稀有食材     配方特性
   标准背书     单一蛋白      人食级       低脂肪/低能量
   不用操心     换肉不换配方  高成本       单一动物蛋白
```

**每个产品线内部，每道菜都覆盖全部 5 个生命阶段**（这是及格线，不是划分依据）。

---

### 产品线 ① · 日常安心线

**服务动机：** 省心托付——"我不想研究，你配好就行"

**定位一句话：** 不懂营养也能放心每天喂的主食。

**顾客的决策问题：** "我该买哪一款？" → 答案应该是"哪款都行，看狗爱吃哪个"。

**产品线特征：**

| 维度 | 设计 |
|------|------|
| 核心承诺 | 符合 FEDIAF 全价营养标准；鲜肉现制、低温蒸煮、冷链到家 |
| 产品逻辑 | **不要求顾客做任何判断**——每款都是全价主食，选口味即可 |
| 蛋白质构成 | 常规蛋白（鸡/鸭/猪/牛），配方稳定、供应稳定 |
| 命名逻辑 | 「{主料}{辅料}」式，看名字就知道里面是什么，比如「鸡胸南瓜燕麦」 |
| 价格带 | 主力款，走量 |
| 主要卖点标签 | 符合 FEDIAF 2025 · 鲜肉现制 · 全价主食 |

**这条线是整个生意的基本盘。** 目标是让一个新客第一次就能闭眼下单，不复购的唯一原因是狗不爱吃。

**为什么这条线必须存在：** 因为鲜食最大的流失点不是价格，是**决策疲劳**——面对一堆看不懂的配方名词，家长会退缩回膨化粮。这条线的任务就是消除这个疲劳。

---

### 产品线 ② · 换换口味线（单一动物蛋白）

**服务动机：** 怕它吃腻 / 想给它换换

**定位一句话：** 只含一种肉，换肉不换配方。

**顾客的决策问题：** "它总吃鸡，给它换个别的肉试试" → 直接按肉的种类挑。

**产品线特征：**

| 维度 | 设计 |
|------|------|
| 核心承诺 | **整份只有一种动物蛋白**——干净、纯粹、味道集中 |
| 产品逻辑 | 一个蛋白一款，顾客按"要哪种肉"选；想轮换就轮着买 |
| 蛋白质构成 | **覆盖尽可能多的肉种**（鸡/鸭/猪/牛/兔/羊/火鸡/鹿…） |
| 命名逻辑 | 让"只有一种肉"这件事一眼可见 |
| 价格带 | 与日常线持平或略高 |
| 主要卖点标签 | 单一动物蛋白 · 不含其他肉类 · 含 XX |

**⚠️ 这条线的定位边界（极其重要）：**

| 可以做 | 绝对不能做 |
|--------|-----------|
| "换换口味"、"只含一种肉"、"不含鸡肉" | "低敏"、"抗过敏"、"适合过敏犬"、"排查"、"不耐受" |

**理由：** 法规附录 5 第八条「降低原料和营养素不耐受」是**处方专属**声称，我们不满足处方粮条件（需兽医指导 + 科学试验数据）。一旦暗示"适合过敏排查"，直接违规。

**这条线的真实需求来源**（不是"过敏"，而是两件更普遍的事）：
1. **轮换需求**：长期只吃一种肉，狗会腻、家长会不安心
2. **排除需求**：家长怀疑狗对某种肉不耐受，想先避开试试——这是**家长自己的判断**，我们只提供"不含XX"这个事实，不替他下结论

**"只有一种肉"本身就是价值。** 不需要借"低敏"来卖。

---

### 产品线 ③ · 珍稀臻选线

**服务动机：** 给它最好的

**定位一句话：** 用平时吃不到的肉，给它一顿特别的。

**顾客的决策问题：** "我想给它点好的" → 稀有蛋白 + 高级食材的组合。

**产品线特征：**

| 维度 | 设计 |
|------|------|
| 核心承诺 | 稀有肉源 + 高级辅料（羊肚菌、芦笋、蓝莓、树莓、巴西坚果等） |
| 产品逻辑 | **款数少、每款独立**，不追求覆盖，追求"每款都值得记住" |
| 蛋白质构成 | 鹿肉、兔肉、鹌鹑、鸽肉等稀缺肉源（**按原料可得性和稳定性调整**） |
| 命名逻辑 | 突出稀缺食材，名字本身要有画面感 |
| 价格带 | 明显高于日常线，承担溢价 |
| 主要卖点标签 | 含 XX（稀有食材，需达 4% 添加量门槛） |

**这条线的商业作用不是走量，是两件事：**
1. **拉高品牌天花板**——顾客判断一个品牌好不好，看的是它最贵的那款
2. **给日常线一个理由**——"他们家连鹿肉都做，日常款应该也不差"

**风险提示：** 稀有肉源的供应稳定性是这条线的命门。款数必须少，且每款要有可替代的备选配方。

---

### 产品线 ④ · 轻负担线

**服务动机：** 它现在有点状况

**定位一句话：** 配方做减法——脂肪更低、能量更低、成分更简单。

**顾客的决策问题：** "它最近有点胖/吃得太油" → 按配方特性筛。

**产品线特征：**

| 维度 | 设计 |
|------|------|
| 核心承诺 | **有法定门槛可验证的配方特性**：低脂肪 / 低能量 / 单一动物蛋白 |
| 产品逻辑 | 不做"治什么"，做"配方上做了什么减法" |
| 蛋白质构成 | 优先低脂部位（禽胸肉、兔里脊、羊里脊、鱼） |
| 命名逻辑 | 特性要进名字，让顾客一眼识别 |
| 价格带 | 与日常线持平 |
| 主要卖点标签 | **低脂肪**（犬用湿粮：水分>65% → 脂肪≤4%）· **低能量**（≤376 kJ ME/100g）· 单一动物蛋白 |

**⚠️ 这条线的天花板，必须说清楚：**

| 门槛 | 具体数值（犬用） | 难度 |
|------|------------------|------|
| **低脂肪** | 水分 >65% → 湿基脂肪 **≤4%**；20–65% → ≤7%；<20% → ≤9% | 中等——**脂肪主要来自添加的油脂，控油就能达标** |
| **低能量** | 水分 >65% → **≤376 kJ ME/100g（≈898 kcal/kg）**；20–65% → ≤1045；<20% → ≤1296 | **较高**——鲜食天然能量密度偏高，需要专门调结构 |

**这两个门槛是"产品定义"级别的约束，必须在设计配方时就当作目标，不能事后挂标签。**

**合规红线（不可越）：** 不能出现 体重管理、减肥、改善超重、肠胃敏感、软便、皮肤问题、关节、肾、肝、胰…… 全部属疾病或处方范畴。

## 四、货架与决策路径

四条线不是并列摆在首页让顾客自己选。**顾客的心智路径是分步的**，货架要跟着走。

### 4.1 首页：先问一个问题，不要摆四个货架

```
        你家狗狗现在多大？
   ┌──────────┬──────────┬──────────┐
   │  幼犬期   │  成年期   │  老年期   │
   └──────────┴──────────┴──────────┘
```
（生命阶段是**最大公约数的入口**——每个家长都知道自己狗多大，不需要任何专业知识）

### 4.2 第二步：在这个阶段下，按"你想怎么喂"分流

```
   日常口粮   ·   换换口味   ·   偶尔加餐   ·   想清淡点
   （① 安心）    （② 轮换）    （③ 臻选）    （④ 轻负担）
```

### 4.3 第三步：进入产品线，按蛋白 / 特性选具体款

```
   ② 换换口味线  →  鸡肉 / 鸭肉 / 猪肉 / 牛肉 / 兔肉 / 羊肉 / 火鸡肉 / 鹿肉
   ④ 轻负担线    →  低脂肪 / 低能量 / 单一动物蛋白
   ① 安心线      →  按口味浏览
   ③ 臻选线      →  按稀有食材浏览
```

### 4.4 生命阶段在这里的作用

顾客在第一步选了"幼犬期"，那么他看到的是：**四条产品线里，每一条都能喂幼犬**（因为每道菜都做了 5 个阶段）。

**差别只在饲喂量**——系统按犬的年龄和体重自动算每日克数。

**这就是「每道菜覆盖 5 个阶段」带来的最大商业价值：一个 SKU 服务全部客群，库存和生产的复杂度降到最低，顾客永远不会"买错阶段"。**

## 五、筛选器（辅助决策，不承担分流）

| 筛选器 | 选项 | 法规依据 |
|--------|------|----------|
| **动物蛋白种类** | 鸡 / 鸭 / 猪 / 牛 / 兔 / 羊 / 火鸡 / 鹿 | 第二十条（三）：≥4% 才可标示 |
| **单一动物蛋白** | 是 / 否 | 成分事实（配方只有 1 种动物源） |
| **不含** | 不含鸡肉 / 不含牛肉 / 不含谷物… | 第二十条（三）7：「无XX」「不含XX」 |
| **脂肪水平** | 低脂肪 | 第二十条（四）4：有法定门槛 |
| **能量水平** | 低能量 | 第二十条（四）5：有法定门槛 |
| **生命阶段** | 幼年期 / ≥14周幼年期 / 成年期 / 妊娠期 / 哺乳期 | 第五条（一）：法规明文列举 |

**「不含XX」这一项特别重要**——它是"低敏"的合法替身，而且比"低敏"更可信：顾客自己会判断"我家狗对鸡过敏，这个不含鸡，可以买"。

## 六、应季推荐位

**机制：系统按当前日期判断季节 → 首页推荐当下应季食材做的菜 → 换季自动切换。**

**关键设计决定：应季不新建产品线，只做推荐位。**

理由：应季食材本质是**同一道菜的原料替换**，不是新产品。做成独立产品线会让 SKU 数量翻四倍，且每年有三个月卖不动。

**应季推荐位的选取逻辑：**
- 从四条线里挑出**当季食材占比高**的现有款
- 换季时自动切换推荐集合
- 需要在原料库补一个"应季"字段（当前没有，这是一个待建的数据结构）

---

## 七、产品线之间的边界规则（防止自我蚕食）

四条线最容易出的问题是**互相抢客**。定三条硬规则：

| 规则 | 说明 |
|------|------|
| **① 安心线不做稀有食材** | 鹿肉、羊肚菌这些只出现在臻选线。否则安心线会吃掉臻选线的溢价 |
| **② 换口味线不做配方减法** | 低脂肪/低能量只属于轻负担线。换口味线的卖点是"一种肉"，不是"更健康" |
| **③ 臻选线不做单一蛋白主张** | 它的卖点是"稀有组合"，不是"干净"。两条线的价值主张不能重叠 |

**四条线的核心词各占一个，不许串：**
```
① 安心 = 全价 · ② 换口味 = 一种肉 · ③ 臻选 = 稀有 · ④ 轻负担 = 减法
```

---

## 八、SKU 结构的标准形状

每条产品线里的每一款，都是一个**「菜」**，标准形状：

```
一款菜（= 一个系列）
   ├─ 幼年期配方      ┐
   ├─ ≥14周幼年期配方  │
   ├─ 成年期配方      ├─ 5 个配方，共用同一主料与工艺
   ├─ 妊娠期配方      │  只调比例，不换主料
   └─ 哺乳期配方      ┘
```

**硬规则：5 个阶段必须共用同一种主料。** 换主料就是另一道菜，不是同一个系列。

**这条规则的意义：** 品牌资产（名字、认知）绑定在"菜"上，顾客认的是"鸡胸南瓜燕麦"这道菜，不是某个阶段的配方。

## 九、这套架构与之前几版的区别

| | 上一版（供给端） | 本版（需求端） |
|---|---|---|
| 划分依据 | 头牌蛋白占比 | **购买动机** |
| 推理方向 | 库里有什么 → 归成线 | 顾客要什么 → 定义线 |
| 生命阶段的角色 | 分类维度 | **及格线**（每道菜必须做全） |
| 蛋白质的作用 | 货架分类 | **产品线内部的选项** |
| 单一蛋白的定位 | 一条独立产品线 | **换口味线的核心主张** |
| 低脂/低能量的定位 | 筛选器 | **一条独立产品线（轻负担线）的核心** |
| 珍稀蛋白的定位 | 和常规蛋白并列 | **单独一条线（臻选线）** |
| 无法承接的需求 | 没处理 | **明确标注**（疾病/功效类，只能用品类教育承接） |
