# 生命阶段到底该怎么用（需求端重构）

> 日期：2026-10-05
> 缘起：上一版把「每道菜覆盖 5 个生命阶段」当作产品原则，然后把生命阶段降级成"及格线"。
> 这份文档**抛开那条原则**，只从顾客需求和营养科学出发重新推一遍。
> 结论会修正 `2026-10-05-产品线规划-需求端版.md` 的第三节。

---

## 一、先说结论

**生命阶段不是"及格线"，它是产品线的第一层结构。**

我上一版错了。错因是：我把「每道菜覆盖 5 个阶段」当成了不可动摇的前提，然后为了迁就它，把生命阶段降级了。但那条原则本身是**供给端的效率设计**（一个 SKU 服务全部客群），不是需求端的事实。

**抛开它之后，营养学给出的答案很硬。**

---

## 二、营养学事实：三个阶段根本不是一回事

我核了知识库里 FEDIAF 和《小动物临床营养学（第 5 版）》的条目，四个阶段的配方级差异是：

| 营养项 | 成犬维持 | **幼犬生长** | **妊娠/哺乳** | 老年犬（健康） |
|--------|----------|--------------|---------------|----------------|
| **能量密度** | 基准 | **2–3× RER**（随生长递减） | **≥4.0 kcal ME/g**（高于成犬） | 与成犬**相同** |
| **钙**（干物质） | 0.5–1.0% | **0.7–1.7%**（小型/中型）<br>**0.7–1.2%**（大型/巨型） | **1.0–1.7%** | 与成犬**相同** |
| **粗脂肪** | ≥5.5% | **8.5–25%** | **≥20%** | 与成犬**相同** |
| **粗蛋白** | 15–30% | 需求更高、质量优先 | **25–35%** | 15–23%（**不需限蛋白**） |
| **DHA** | — | 必需（神经/视网膜发育） | **≥0.02% DM** | — |

**三条关键事实：**

**① 幼犬粮和成犬粮不能互换——知识库原话是：「成犬粮不应喂幼犬」。**

理由不只是热量。**钙磷比、能量密度、宏量结构都无法通过调整喂食量解决。** 而且：

> 「约 10 月龄后幼犬对钙的吸收才逐渐受到更严格的调控，此前过量钙的风险更高。」
> 「过量钙（粮中或补充剂）是发育性骨科病（DOD，如髋关节发育不良）的风险因素，大型/巨型犬尤甚。」

**这是安全问题，不是偏好问题。** 给幼犬喂成犬配方，可能导致不可逆的骨骼发育问题。家长花的钱里，有一部分就是在买"我不会喂错"。

**② 繁殖/哺乳期是成年犬中营养需求最高的阶段——「甚至高于生长」。**

哺乳期食物要求能量密度 ≥4.0 kcal/g、粗脂肪 ≥20%、钙 1.0–1.7%。而哺乳母犬的产奶量在第 3–4 周可达体重的 8%。这跟成犬维持完全不是一个配方。

**③ 老年犬没有配方级的差异化营养标准。**

这一点很反直觉。知识库原文：

> 「'老年'不等于'疾病'。成熟犬群体的健康状况个体差异极大，**营养方案必须逐只评估，而不是按年龄段统一处理**。」
> 「健康老年犬通常**不需要限制蛋白**。」
> 「一旦确诊慢性肾病，蛋白与磷的调整必须依据兽医分期进行。」

**换句话说：健康的老年犬吃成犬配方就是对的。** 老年犬真正的营养问题几乎都出现在**生病之后**——而那是处方粮领域，我们做不了（法规附录 5）。

## 三、但顾客端完全是另一幅画面

营养学上"老年犬 = 成犬"，顾客端**不等于**。

| 家长 | 他在焦虑什么 | 他的购买周期 | 他需要你帮他什么 |
|------|--------------|--------------|------------------|
| **幼犬家长** | 长得对不对、软便、吃多少、几顿 | **12–18 个月的临时关系** | 告诉我怎么喂、喂多少；我什么都不懂 |
| **成犬家长** | 它爱吃吗、营养够吗、能不能一直吃 | **多年长期关系** | 别让我操心，稳定就好 |
| **老年犬家长** | 它老了、瘦了、吃得少了、牙齿不行 | 长期关系，但**开始有健康焦虑** | 告诉我该注意什么 |
| **繁殖者** | 母犬和小狗的营养、产奶量、窝仔存活 | **按生理周期**，专业采购 | 给我工具和数据，别跟我讲情怀 |

**三件事从这个表里跳出来：**

**① 幼犬家长是"新手客户"，不是"小份客户"。** 他需要的是**喂养指导**，不只是产品。而且他只待 12–18 个月——**这是最大的流失口，也是最大的获客口**。

**② 老年犬家长有焦虑，但我们的产品解决不了。** 他真正想要的是"帮我照顾好它的晚年"，这本质上是**服务需求**（健康管理、定期随访），不是配方需求。产品能承接的只有"好嚼、好吃、低脂"这类表层需求。

**③ 繁殖者是另一个客群，不是另一个产品。** 他的决策逻辑（看数据、按周期采购、一次性买多只狗的量）跟普通家长完全不同。

## 四、修正后的架构

**生命阶段做第一层，但它只在"营养有硬差异"的地方切开。**

```
                        【成品鲜食】
                             │
        ┌────────────────────┴────────────────────┐
        │                                         │
   【专用配方区】                            【通用配方区】
   营养有硬约束，不可共用                     营养可共用
        │                                         │
   ┌────┴────┐                    ┌────────┬───────┼───────┬────────┐
 幼犬线   繁殖哺乳线            日常安心  换换口味  珍稀臻选  轻负担
（生长）  （母犬）               「托付」  「轮换」  「最好的」 「减法」
        │         │                  │        │        │        │
   每道菜带     每道菜带          成犬配方 + 老年配方（同配方，不同卖法与喂食建议）
   幼犬配方     繁殖配方
```

### 为什么是这个形状

| 设计决定 | 依据 |
|----------|------|
| **幼犬独立成线** | 营养硬约束（钙磷比、能量密度无法靠喂食量解决）+ 安全风险（DOD）+ 客群独立（新手、临时关系） |
| **繁殖/哺乳独立成线** | 营养需求"甚至高于生长"（能量密度≥4.0、脂肪≥20%、钙1.0-1.7%）+ 客群独立（繁殖者） |
| **老年犬不独立成线** | 健康老年犬的营养标准 = 成犬。独立成线会造成 SKU 爆炸，且没有营养依据 |
| **老年犬用"卖法"承接** | 在通用区的每条线下，同一配方提供成犬版和老年版两种卖法（喂食建议、质地、沟通口径不同） |
| **四条动机线放在通用区** | 换口味 / 臻选 / 轻负担 / 安心 这四个动机，幼犬和成犬家长都有，但**配方不同**——所以它们跨越两个配方区 |

### 一个反直觉但重要的推论

**「换换口味」「珍稀臻选」「轻负担」这三个动机，幼犬家长同样有。** 一个养幼犬的家长也会想"给它换换肉""给它点好的"。

所以这四个动机**不是产品线，是横切的分层维度**。真正的产品线是上面那六条。

## 五、幼犬线是整个生意的枢纽

这是这份分析里商业价值最高的一条。

**因为幼犬家长必然变成成犬家长。** 一个在幼犬期建立的信任关系，可以自然地延续 10 年以上。

| 如果幼犬期体验好 | 如果幼犬期体验差 |
|------------------|------------------|
| 12–18 个月后自然过渡到成犬线 | 狗一岁就流失，且**再也不会回来** |
| 家长已经学会怎么喂、信任品牌 | 家长带着"鲜食太麻烦/太贵"的印象离开 |
| 获得一个 10 年 LTV 客户 | 只赚了 12 个月的钱 |

**所以幼犬线的 KPI 不该是利润率，是「过渡到成犬线的转化率」。**

配套要做的事：
1. 幼犬线必须**附带喂养指导**（喂多少、几顿、什么时候换段）——这是新手家长真正在买的
2. 系统要**按生日自动提醒"该换成年配方了"**（犬档案里有生日）
3. 幼犬线的定价可以低一些，因为它的作用是获客

## 六、这对「每道菜覆盖 5 个阶段」意味着什么

**这条原则需要重新定义，不是放弃。**

| 原表述 | 问题 | 建议改为 |
|--------|------|----------|
| 每道菜覆盖全部 5 个生命阶段 | 营养上做不到（幼犬/繁殖期必须独立配方） | **每条产品线的每道菜，覆盖该产品线服务客群的全部阶段** |

具体的配方矩阵：

| 产品线 | 配方版本 |
|--------|----------|
| 日常安心线 | 成犬版 + 老年版（**同一配方**，不同喂食建议与卖法） |
| 换换口味线 | 成犬版 + 老年版 |
| 珍稀臻选线 | 成犬版 + 老年版 |
| 轻负担线 | 成犬版 + 老年版 |
| **幼犬线** | **幼犬版（独立配方）** |
| **繁殖哺乳线** | **繁殖版（独立配方）** |

**实际配方种类：通用区 1 套 + 幼犬 1 套 + 繁殖 1 套 = 3 套。** 不是 5 套。

---

## 七、老年犬这件事，值得单独说一下

**营养上：老年犬不需要独立配方。** 这一点在行业里常被误用——很多品牌做"老年犬粮"，本质是营销区分，不是营养区分。

**但顾客端有真实焦虑**，而且我们**不能用产品去接**（一旦说"关节""肾""心脏"就是疾病声称，违规）。

**所以老年犬只能这样接：**
- 在通用区的每条线下，提供**老年犬买法**（配方相同，沟通口径不同：更软、更易嚼、喂食量调整）
- 把真正的老年犬需求导向**服务**（健康管理、定期随访、定制），而不是硬做成产品

**这恰好和你们已有的「食谱定制 ¥300」对得上**——老年犬家长是最愿意为定制付钱的客群。

## 八、修正后的完整结构

```
【第一层：配方区】（由营养硬约束决定）
  ├─ 通用配方区 —— 成犬 / 老年犬共用
  └─ 专用配方区 —— 幼犬、繁殖哺乳（各自独立配方）

【第二层：产品线】（由购买动机决定）
  ├─ 日常安心线
  ├─ 换换口味线（单一动物蛋白）
  ├─ 珍稀臻选线
  └─ 轻负担线（低脂肪 / 低能量）
  ※ 这四条线跨越两个配方区：通用区有成犬版，专用区有幼犬版 / 繁殖版

【第三层：菜】
  └─ 一道菜 = 一个系列 = 在所属配方区内覆盖全部适用阶段
```

**货架入口保持不变**（顾客第一问还是"你家狗多大"），但进去之后的逻辑修正了：

- 选**幼犬期** → 进入幼犬配方区 → 看到四条线各自的幼犬版
- 选**成年期 / 老年期** → 进入通用配方区 → 看到四条线的成犬版（老年犬家长看到的是同一批菜，加上喂食建议）
- 繁殖者走**独立入口**（不混在普通货架里）

## 九、这份修正推翻/保留了什么

| 项 | 处理 |
|----|------|
| ❌ 「每道菜覆盖 5 个生命阶段」 | 修正为「覆盖该产品线服务客群的全部阶段」 |
| ❌ 「生命阶段是及格线，不是划分依据」 | **推翻**。生命阶段是第一层结构（配方区） |
| ❌ 「按头牌蛋白划分主货架」 | 仍然推翻（那是供给端） |
| ✅ 四个购买动机 | **保留**，但降级为第二层（跨配方区的产品线） |
| ✅ 单一动物蛋白 = 换换口味线的主张 | 保留 |
| ✅ 轻负担线（低脂肪/低能量） | 保留 |
| ✅ 应季推荐位 | 保留 |
| ✅ 防蚕食的三条边界规则 | 保留 |
| 🆕 **幼犬线作为获客枢纽** | 新增，且优先级最高 |
| 🆕 **繁殖/哺乳线作为独立客群** | 新增 |
