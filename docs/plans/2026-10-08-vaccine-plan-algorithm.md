## 一、这套算法负责什么

| 负责 | 不负责 |
|---|---|
| 顾客看到的「接种计划」与「下一针」 | 微信推送（**没做**，老板定"提醒只在小程序内"） |
| 每一步的窗口期、状态、提醒文案 | 判断"该打哪个牌子"（只列常见进口苗，措辞是"常见的有"，不是"建议打"） |
| 记录与建议不一致时的冲突提示 | 诊疗决策（一律"以执业兽医的意见为准"） |

**顾客能看到的提醒有四处**（口径必须一致，本次审计的重点之一）：

1. 疫苗页顶部提醒条 —— **系统按程序推算的"下一针"**（2026-10-07 起）
2. 每条记录卡片上的到期文案 —— **疫苗本上写的**那个日期，文案里明确标明来源
3. 接种计划卡片 —— 每一类的下一针 + 窗口期 + 依据
4. 分享给医生的健康页 —— 记录里的「下次到期日」

## 二、程序表（每一类怎么排）

| 类别 | 怎么排 | 依据 |
|---|---|---|
| 核心疫苗 | 幼犬首免（见第三节）→ 26 周补强 → **每 3 年**一次 | WSAVA 2024 |
| 狂犬 | 12 周龄首针 → **每年一次**，窗口从**周年当天**起算 | 国内强制免疫（《狂犬病防治技术规范》）；**12 周不是指南规定**，是说明书常见写法 |
| 钩端螺旋体 | 8 周龄起 2 针（间隔 2~4 周）→ 每年一次 | 大陆属常见地区（WSAVA 对高风险地区"强烈建议"）+ 产品说明书 |
| 早期核心苗（宠必威幼犬保那支） | 4 周龄起 **1 针**，之后仍要走正常首免，不重复 | WSAVA Table 1 |

- **默认排给每只狗的是：核心 + 狂犬 + 钩端**（老板 2026-10-06 定：大陆钩端很常见，
  默认排出来让家长拿去和兽医讨论）。其余非核心苗（犬窝咳、冠状…）**有记录才排**。
- 窗口宽度：幼犬首免 2~4 周；狂犬/钩端每年一次 90 天；成年加强 90 天。
- 犬冠状病毒疫苗**不推荐**（证据不足）—— 不在程序表里。

## 三、首免针数怎么算（2026-10-07 改成"相对模型"）

**规则**：起点 = 这只狗**实际打第一针**的那天（还没打过 → 现在；没到 6 周龄的从 6~8 周起）；
从起点起每 **2~4 周**一针，**直到有一针落在 ≥16 周龄**；**针次从它自己的第一针开始编号**。

| 情形 | 排出来的计划 |
|---|---|
| 6 周龄开始 | 第 1~4 针 + 26 周补强（固定四针程序表） |
| 10 周龄开始 | 第 1 针（现在）→ 第 2 针 → 第 3 针（≥16 周）+ 补强 |
| 12 / 15 周龄开始 | 第 1 针（现在）→ 第 2 针（≥16 周）+ 补强 |
| **15 周龄才打第一针** | **第 1 针 · 已完成（那针就是第 1 针）** → 第 2 针（≥16 周） |
| ≥16 周龄才开始 | **一针**即完成 |
| ≥26 周龄才开始 | 一针，**连 26 周补强都不用补** |
| 8/12/16 周三针 | 第 1/2/3 针完成（≥16 周那针就是完成针），不再催第 4 针 |
| 6/10/14 周三针 | 前三针完成，**还差一针**（≥16 周那一针） |

- **按时（≤8 周龄）开始**的狗继续用固定四针程序表；有完成针（≥16 周龄那一针）时按实际针数裁剪。
- 一针都没打过的狗：那一针显示成「**该打了**」，窗口从**今天**开始（不是"已逾期"）。

## 四、记录怎么对上步骤（"第 N 针 = 第 N 剂"）

一类之内，把**记录和步骤按时间配成一对一的顺序匹配**：

1. 顺序不许倒挂（后打的针不能顶前面的步骤）；
2. 时间上要说得过去：离那一步的窗口**超过一年**就不配；
3. 满足 1、2 的配法里，选**配上的条数最多**的；同样多时优先"**刚好落在窗口里**"的。

- 一条记录在同一类里只能顶一步；**组合苗**（卫佳捌 = 核心 + 钩端）可以同时顶不同类。
- 顶不上的记录**不参与**（犬二联、卫佳细不顶核心首免）。

**日期合理性**（2026-10-07 加）：

- 接种日**晚于今天** → 录入直接拒（「接种日期不能晚于今天」），并且已有的这类记录不参与计划；
- 接种日**早于生日** → 允许保存（生日可能是估的），但窗口不会被拖到出生前，并提示
  「这一针的接种日期比狗狗生日还早，请核对疫苗本上的日期」。

## 五、窗口怎么跟着实际接种日走

**每一步的窗口 = 程序表里的位置 + 平移量**，平移量来自**最近一次实际接种**：

| 步骤 | 锚点 |
|---|---|
| 首免那几针 | 实际第一针的日期（相对模型，见第三节） |
| 26 周补强 | 首免完成后按程序推；**窗口不早于 26 周龄**（地板）；**任何一针落在 ≥26 周龄的核心苗都算补过了** |
| 成年加强 第 N 次 | **上一次实际接种 + 3 年**（窗口从周年当天起算） |
| 狂犬 / 钩端 每年一次 | **上一针 + 1 年**（窗口从周年当天起算，往后 3 个月） |

## 六、状态与显示（2026-10-07 老板定的口径）

**每一类只显示"下一针"** = 这一类第一个还没完成的步骤。已完成的历史保留在列表底部。

| 那一针的窗口 | 显示 |
|---|---|
| 还没到 | 待安排 |
| 正在进行 | 该打了 |
| **已经过去** | **该补了**（不说"已逾期"，也不一次列好几条） |
| 这一类一针都没打过 | 该打了（窗口从今天开始） |
| 顾客点过"不做" | **不显示**，这一类的下一针顺位往后挪 |
| 已完成 | 已完成（历史） |
| 点过"推迟" | 位置不变，标一句「（你已推迟）」 |

- **没有时间框**：原来"过期一年以上不显示""18 个月以后不显示"已去掉 —— 一个类别最多出一条，
  程序表再长也不会刷屏；那两个框只会误伤（例如漏打三年、下一针早就过期的狗，
  以前整个狂犬疫苗会从计划里消失）。
- 跳过"**开始打这一类之前就已经结束**"的档位（例：赛文 2024 年才开始打钩端，
  不该被催 2023 年那两针幼犬初免）。
- 顶部「下一针」按**时间**取：先"该补了"，再"该打了"，再"待安排"，同状态里取窗口最早的。
- 事实优先：**打了针就是已完成**，即使之前点过"不做"。

## 七、冲突提示（记录与建议不一致时）

| 提示 | 判据 |
|---|---|
| 打在 4 周龄之前 | 核心苗，**生日 + 4 周**为红线（不是按首免窗口推） |
| 接种日比生日还早 | 单独提示"请核对疫苗本上的日期（最常见的错法是把年份写错）" |
| 接种日在未来 | 录入时拦住；已有记录不参与计划，并提示核对 |
| 狂犬间隔不足一年 | 相邻两针狂犬 **< 12 个月**（与"窗口从周年起算"同一口径） |
| 下次到期日与建议不符 | 记录里填的「下次到期日」离最近的建议窗口 **> 180 天**（阈值故意放宽：各家医院习惯不同） |
| 不同类别同一天打 | 窗口重叠且都还没做时提示「不同类的疫苗不要同一天打，前后错开 2~3 天」——**这是我们自己的建议**，文案里不假借"指南要求" |

## 八、顾客的决定（按建议 / 推迟 / 不做）

- **不做（SKIP）**：这一步不再显示；这一类的下一针往后顺位。
- **推迟（DEFER）**：位置、状态、窗口都不变，只标一句「你已推迟」。
  （界面上目前只有「记录接种信息」和「忽略」两个按钮，推迟通过接口可用。）
- **事实优先**：有记录顶上就是"已完成"，"不做"只是意图。

## 九、这次审计改掉的口径（追溯用）

| 日期 | 改了什么 | 起因 |
|---|---|---|
| 10-07 | 「首免（一针）」永远显示 → 后改为**窗口从今天开始、状态"该打了"** | 老板："显示成现在就该打" |
| 10-07 | 从没打过核心苗的狗，那一针不再被"过期太久"的过滤器收起来 | 面包实测：计划里完全没提核心疫苗 |
| 10-07 | **≥16 周龄那一针即完成针**（不再催第 4 针） | 8/12/16 那种最标准的打法被多催一针 |
| 10-07 | 提醒口气**按类**判断（原来按整只狗） | 只记过狂犬的狗，钩端那两针被说成"已逾期" |
| 10-07 | 接种日期合理性（未来拦住 / 早于生日提示） | 填错年份会把"还没打的针"算成已打过 |
| 10-07 | 每年一次的窗口**从周年当天起算** | 一边提前一个月邀请、一边提示"间隔不足一年" |
| 10-07 | 26 周补强**不早于 26 周龄** | 打早了的狗被拉到 21~25 周龄就催 |
| 10-07 | 成年加强 = **上一次实际接种 + 3 年** | 老板："优先级更高的相关性是上一次的接种日期" |
| 10-07 | 匹配改成**顺序一对一配对** | 6/8/10 周三针出现"第 2 针是 10 周、第 3 针是 8 周"的倒挂 |
| 10-07 | 首免改成**按这只狗自己的第一针**排 | 老板："15 周才开始的话……这是他狗狗的第一针呀" |
| 10-07 | **每一类只显示下一针**；去掉两个时间框 | 老板："只给顾客看到下一针待接种的疫苗就可以了" |
| 10-07 | 窗口过去的叫「**该补了**」 | 老板："已逾期的，我们不显示出来，也不告诉用户" |
| 10-07 | 顶部"下一针"按时间取 | 赛文那条会先报 2029 年的成年加强 |
| 10-07 | 跳过"开始打之前就结束"的档位 | 赛文被催 2023 年那两针幼犬初免 |
| 10-07 | 4 周龄红线改用生日推；早于生日单独提示；狂犬间隔对齐 12 个月 | 审计第 7 块实测 |
| 10-07 | 顶部"到期提醒"改用**系统推算**的下一针 | 老板早就定的："系统按程序自动算、与接种计划保持一致" |
