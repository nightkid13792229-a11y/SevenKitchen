## 零、一页纸

**一句话**：把 DIY 食谱里“这顿饭缺的那部分补剂”，按用量分装成小袋，跟着食谱一起买、单独发货。顾客买的不是一瓶补剂，是“这顿饭的营养补齐 + 不用自己算”。

| 项 | 当前结论 | 状态 |

## 一、产品到底是什么

### 1.1 是

- **DIY 食谱的配套增值服务**：顾客在制作单里看到“这顿缺什么”，一键买齐。
- **按用量卖，不按瓶卖**：每种补剂按本次食谱的用量分装成小袋。
- **一个补剂一袋**：不混装；加量则同一补剂多袋。
- **每袋配干燥剂 + 标签**：40×60mm 竖版标签，有品名、分装量、分装日期、有效期、储存条件、原品、分装者、用法、干燥剂提示。
- **独立发货**：不和鲜食一起发；补剂是常温，鲜食是冷链。

### 1.2 不是

- ❌ 不是独立补剂商城：顾客不能随时进来买任意补剂。
- ❌ 不是“整瓶代购”：我们不卖整瓶，只卖本次用量。
- ❌ 不是品牌/规格自选：顾客不能指定换成另一个牌子。
- ❌ 不是加购平台：本轮不能加购食谱之外的补剂。
- ❌ 不是“单价最低”：它是利润品；顾客省钱来自“不用买整瓶”，不是我们每克更便宜。
- ❌ 不是订阅制：本轮不做按月自动配送。

### 1.3 为什么顾客不自己买整瓶

| 顾客的麻烦 | 我们的解决 |
|---|---|
| 不知道每种补剂该买哪个品牌、什么规格 | 我们按食谱推荐，直接分装 |
| 不知道一只狗每天该吃多少 | 按食谱用量算好，一袋就是一次/一段时间的量 |
| 一瓶吃不完、过期浪费 | 只买本次用量，不浪费 |
| 买回来还要自己称、自己分 | 我们称好、分好、贴好标签 |
| 怕买错、怕过量 | 标签写清分装量、效期、储存条件 |

> **核心是“省事 + 不浪费 + 配得准”。**
> “省钱”是结果：顾客不用为一次食谱买整瓶，整单支出更省；但我们不承诺“单价最低”。

## 二、顾客与价值主张

### 2.1 顾客是谁

| 类型 | 特征 | 他真正要的 |
|---|---|---|
| **A 怕麻烦型** | 已经在做 DIY，但不想研究补剂 | 一键买齐，别让我算 |
| **B 怕浪费型** | 买过整瓶，放过期 | 只买这次用量 |
| **C 怕买错型** | 不知道品牌/剂量，怕过量 | 有人替我配好、写清楚 |
| **D 尝试型** | 想试新补剂，不想买一整瓶 | 低门槛小份试 |
| **E 信任型** | 在意标签、效期、分装卫生 | 看得见的规范 |

> 这五类人都来自 DIY 制作单，不需要额外获客；本轮不投广告、不做独立商城。

### 2.2 价值主张的层级

| 层级 | 主张 | 用在哪 |
|---|---|---|
| **核心** | 按食谱精确配量，不用自己算 | 标题、入口第一句 |
| **核心** | 不用买整瓶，不浪费 | 价格解释、对比整瓶 |
| **辅助** | 一次买齐，省事 | 一键购买按钮 |
| **辅助** | 标签/效期/分装可信 | 详情页、标签、售后 |
| **辅助** | 低门槛尝试 | 7 天小份 |
| **结果证明** | 整单更省 | 用“不用买整瓶”解释，不说“单价最低/全网最低” |

### 2.3 对外一句话（已确认方向：不浪费 + 整单更省）

- **主标题**：不用买整瓶，按食谱用量分装。
- **副文案**：用多少买多少，不浪费；整单更省。
- **按钮**：一键买齐本次补剂。
- **证明点**：按用量分装 / 一袋一用 / 标签写清分装量、分装日期、有效期、储存条件。
- **不说**：单价最低、全网最低、比整瓶便宜。

> 顾客的“省”来自“不用为一次食谱买整瓶”，不是我们每克更便宜。

### 2.4 部分补剂暂时不可买

- **决定**：允许买可买的，缺的标灰并说明原因；顾客可只买一部分。
- **原因**：不因为一个补剂缺货，把整单卡死；但必须让顾客知道少了什么、为什么。
- **边界**：如果全部不可买，不显示购买入口/不允许下单。

### 2.3 “利润品”和“顾客省钱”为什么不冲突

一开始我把这两件事当成矛盾，是把“顾客省钱”理解成了“我们单价更低”。正确的口径是：

| 视角 | 事实 |
|---|---|
| 顾客 | 为了做一次食谱，不用买 8 瓶补剂；只买这次用量，**整单支出更省** |
| 我们 | 按用量分装，有服务费和加价；**单位克价可以比整瓶高**，但顾客不需要买整瓶 |
| 结果 | 顾客省的是“总支出/浪费”，我们赚的是“分装服务 + 商品加价”，两者同时成立 |

所以：

- 对外可以说“**按用量买，整单更省；不用买整瓶**”。
- 不可以说“单价最低/全网最低/比整瓶便宜”——整瓶的克价一定比我们低。
- 顾客的省钱来自“按需购买”，不是“我们贴钱”。

> 这也是为什么定价可以用“商品明细 + 服务费”：顾客看得见自己只买了这次用量，整体仍然比买整瓶划算。

## 四、定价建议（重点）

> 下面给的是**结构和起点**，不是最终数字。具体数字要按你的实际进货价、人工、运费算。

### 4.1 先定三条原则

**原则 1：按“这次要花多少钱”卖，不按“每克多少钱”卖。**

顾客关心的是“这单多少钱、能吃多久、比买整瓶划不划算”，不是每克单价。页面要给他：

- 这单总价
- 每天成本
- 覆盖多少天
- 对比“买整瓶用不完”的浪费

**原则 2：服务费按“单”收，不按“袋”收。**

为什么：

- 顾客的痛点是“一键买齐”；按袋收服务费会让“多买几种”变贵，反而抑制一键买齐。
- 我们的固定劳动在“开单、称装、贴标、打包”，不是每袋线性增加。
- 按单收，顾客更容易接受；按袋收，8 种补剂会被收 8 次，观感差。

**原则 3：用免服务费/包邮门槛鼓励买齐；不设硬性最低消费。**

老板已确认：**不设最低商品金额**，不挡小单。这样顾客体验最好，但小单贡献率低，必须监控。

- **免服务费门槛**（商品满 ¥99）：鼓励买齐、买长周期。
- **包邮门槛**（商品满 ¥129）：把运费压力转成加购动力。
- **小单不拦，但要看得见**：后台订单中心给“小单”打标，按周看小单占比和贡献率；如果小单拖垮整体，再考虑小单服务费或最低消费。

> 小单的真实成本：补剂成本 ¥5、7 天、只买 1 种，实付约 ¥28.5，单均贡献约 ¥8.2（28.9%）；一单售后就可能吃掉全部贡献。

### 4.2 推荐的价格结构

顾客在下单页看到**三行**：

```
商品小计        ¥XX.XX   （每种补剂一行，可逐项取消）
分装服务费      ¥10.00   （每单固定；满 ¥99 免）
运费            ¥8.00    （一口价；满 ¥129 免）
────────────────────
合计            ¥XX.XX
每天约          ¥X.XX    （合计 ÷ 覆盖天数）
```

为什么不是“一口价套餐”：

- 顾客可以**逐项取消**，一口价套餐会让“取消一项退多少钱”说不清。
- 商品明细 + 服务费 + 运费，顾客知道钱花在哪，售后也好解释。
- 一口价可以作为**展示摘要**（“7 天补剂包，约 ¥XX/天”），但**计价基础仍是明细**。

### 4.3 一个示例（仅演示算法，不是最终定价）

假设：

- 7 天、8 种补剂，补剂成本合计 ¥10.36
- 加价倍率 2.0 → 商品小计 ¥20.72
- 服务费 ¥10，运费 ¥8 → 合计 ¥38.72
- 每天约 ¥5.53

成本侧（示例）：

| 项 | 金额 |
|---|---|
| 补剂成本 | ¥10.36 |
| 包材（8 袋 + 8 干燥剂 + 8 标签） | 约 ¥1.8 |
| 人工（15 分钟） | 约 ¥7.5 |
| 运费 | 约 ¥5.0 |
| 支付手续费（0.6%） | 约 ¥0.23 |
| 售后预留（3%） | 约 ¥1.16 |
| **合计成本** | **约 ¥26.05** |
| **单均贡献** | **约 ¥12.67（32.7%）** |

> 如果人工按 10 分钟、运费按 ¥4 算，贡献会到 40% 左右。
> 如果服务费免掉、运费也免掉，这单只剩 ¥20.72 商品收入，扣成本后可能不到 ¥5，甚至亏。

**结论**：

- 服务费和运费不能轻易全免；免的前提是商品金额足够高。
- 目标单均贡献建议 **35%–45%**；低于 30% 就要调价/调门槛/调倍率。
- 7 天小单可以存在，但要用**最低商品金额 + 服务费**兜住。

### 4.4 长周期要不要便宜

建议**给长周期一点甜头，但不要打折打穿**：

| 周期 | 策略 |
|---|---|
| 7 天（尝试） | 标准价；不促销；用“低门槛试”做卖点 |
| 30 天（复购） | 免服务费，或商品 95 折；但受效期上限约束（总天数 ≤ 90 天） |
| 加量（多份） | 不按袋加服务费；可给“多份免运费” |

原因：

- 长周期摊薄人工/运费，单均贡献更高，值得让一点。
- 但补剂分装效期有限（粉剂 6 个月、片剂/胶囊 9 个月），不能无限卖长周期。
- 加量不应再收一次服务费，否则顾客觉得“多买反而被惩罚”。

### 4.5 售后成本要预留

你选的是“无理由退款/补发，不要求寄回”。这是很强的承诺，也是成本。

建议：

- 在定价里预留 **3%–5% 的售后损耗**。
- 设售后窗口（建议发货后 7 天），避免无限期。
- 破损/发错要求照片（选填但提示），不是不信任，是方便追责。
- 监控售后率：超过 5% 要复盘是分装/物流/预期问题，不是继续硬扛。

### 4.6 什么时候调价

不要一次定死。建议：

1. 先按“成本 × 2.0 + 服务费 ¥10 + 运费 ¥8 + 门槛”跑 30–50 单。
2. 记录每单：商品成本、包材、人工分钟、运费、支付费、售后。
3. 看三个数：
   - 单均贡献率（目标 35%–45%）
   - 补剂渗透率（有多少 DIY 用户买了补剂）
   - 售后率（目标 <5%）
4. 再决定：调倍率、调服务费、调门槛、还是调选品。

### 4.7 不建议做的事

| 不做 | 原因 |
|---|---|
| 用“全网最低”做主打 | 整瓶单价一定比我们低；会陷入比价 |
| 免服务费 + 免运费做默认 | 小单直接亏；除非商品金额足够高 |
| 按袋收服务费 | 惩罚“一键买齐”，与卖法冲突 |
| 一口价套餐但允许逐项取消 | 退款金额算不清，售后纠纷 |
| 用复杂折扣/优惠券 | 利润品，先把基础价格和门槛跑通 |
| 把售后成本当“不会发生” | 无理由退/补一定会发生，必须预留 |

### 4.8 用你的数字算一遍（2026-10-19 确认）

你给的成本口径：

| 项 | 你给的口径 | 测算假设 |
|---|---|---|
| 补剂成本 | 种类/用量差异大，估不出一个平均值 | 用单均补剂成本 C = ¥5 / 10 / 20 / 30 / 50 五档做敏感性测算 |
| 分装人工 | 约 10 分钟/单；人工 300 元/天 | 按 8 小时/天 → 37.5 元/小时 → **6.25 元/单**（保守；10 小时则为 5 元） |
| 快递 | 6 元/单 | 按 6 元/单 |
| 包材 | 未给 | 按 **2 元/单** 保守估（袋 + 干燥剂 + 标签） |
| 支付手续费 | 未给 | 0.6% |
| 售后预留 | 未给 | 3% |
| 目标毛利 | 至少 60% | **先区分“商品毛利”和“单均贡献”** |

#### 两种“毛利 60%”差很多

**口径 A：商品毛利 60%**

```
商品毛利 =（商品售价 − 补剂成本）÷ 商品售价
```

- 倍率 2.0 → 50%
- 倍率 2.5 → 60%
- 倍率 3.0 → 66.7%

**口径 B：单均贡献 60%**

```
单均贡献 =（实付 − 补剂成本 − 包材 − 人工 − 快递 − 支付费 − 售后预留）÷ 实付
```

按上面的成本，要做到 60% 贡献，需要的倍率大致是：

| 单均补剂成本 | 做到 60% 贡献所需倍率 |
|---|---|
| ¥5 | 约 7.4 倍 |
| ¥10 | 约 5.1 倍 |
| ¥20 | 约 3.9 倍 |
| ¥30 | 约 3.5 倍 |
| ¥50 | 约 3.2 倍 |

> 这个倍率大概率会伤害转化。**不建议把“60% 单均贡献”作为首发目标。**

#### 推荐：商品毛利 60% + 单均贡献 35%–45%

按 **倍率 2.5（商品毛利 60%）**、服务费 ¥10/单、运费 ¥6、包材 ¥2、人工 ¥6.25、支付 0.6%、售后预留 3% 测算：

| 单均补剂成本 | 商品价 | 实付（含服务费+运费） | 商品毛利率 | 单均贡献 | 贡献率 |
|---|---|---|---|---|---|
| ¥5 | ¥12.5 | ¥28.5 | 60% | ¥8.2 | 28.9% |
| ¥10 | ¥25 | ¥41 | 60% | ¥15.3 | 37.3% |
| ¥20 | ¥50 | ¥66 | 60% | ¥29.4 | 44.5% |
| ¥30 | ¥75 | ¥91 | 60% | ¥43.5 | 47.8% |
| ¥50 | ¥125 | ¥141 | 60% | ¥71.7 | 50.8% |

结论：

- 补剂成本越低的单，固定成本占比越高，贡献率越低。
- **必须有最低商品金额**，否则 ¥5 成本的小单只有 29% 贡献，一单售后就吃掉。
- 成本 ¥10 以上、商品金额 ¥29 以上的单，贡献率可以稳定在 **37%–50%**。

#### 推荐的首发数字（起点，不是终局）

> 老板已确认：不设最低商品金额；小单允许下，但后台要监控贡献率。
>
> **“单均贡献 35%–45%”是按周/按月平均的目标，不是每一单都保证。**
> 小单（商品 <¥29）允许低于此；如果小单占比高，第二批再加小单服务费/最低金额。

| 项 | 建议起点 | 理由 |
|---|---|---|
| 加价倍率 | **2.5 倍** | 商品毛利 60%，符合你的目标 |
| 分装服务费 | **¥10/单** | 覆盖人工 6.25 + 包材 2 + 支付/售后约 1.5，略有结余 |
| 运费 | **¥6/单** | 按你给的快递价，平进平出 |
| 免服务费门槛 | 商品满 **¥99** | 此时贡献率约 45%，让利换客单 |
| 包邮门槛 | 商品满 **¥129** | 服务费+运费都免，贡献率仍约 45% |
| 目标单均贡献 | **35%–45%（平均）** | 现实可达；60% 需要 3–7 倍倍率，不建议首发 |
| 售后预留 | 3% | 无理由退/补的成本 |
| 最低商品金额 | **不设** | 老板确认：不挡小单；但小单贡献率低，需监控 |

> 如果实际包材/人工/快递比上面高，按同口径上调服务费或门槛；如果实际更低，可以把服务费降到 ¥8 或把包邮门槛降到 ¥99。

## 五、交付承诺

你的口径是：**按营业日给顾客一个确定的发货日期，不给模糊承诺。**

建议这样落地：

1. 顾客在下单页看到**一个确定日期**，不是“尽快发货”。
2. 日期由系统按“营业日历 + 截单时间 + 付款时间”算：
   - **截单前付款 + 今天是营业日 → 当天分装、当天发**
   - **否则 → 下一个营业日**
   - 若下一个营业日也停发，继续顺延到下一个营业日
3. 顾客**不自选更晚日期**；下单页只显示系统算出的最早发货日。
4. 如果算出的日期因停发/异常变化，主动通知顾客，并给出新日期。
5. 顾客侧只说“预计发货日期”，不说“分装日”。

**已确认**：截单前当天发，之后次日；顾客不自选更晚日期。

**仍需确认**：

- 具体用哪家经济快递（¥6/单 是假设；签约价待定）。
- 当天实际做不出来时，默认顺延到下一个营业日并通知；是否允许临时提前截单，运营可配。

### 5.1 标签规格（已确认：40×60mm 竖版）

老板现有标签纸是 **40×60mm 竖版**，不换纸。现有后端标签图是 60×40、打印机传的是 70×100，三处不一致，必须统一改成 **40×60**。

**40×60 的约束**：

- 宽度只有 40mm，品名/原品/提示会换行更多。
- 高度 60mm，比原来 40mm 多 20mm，可以多放“用法/储存”两行。
- 标签必须贴得下 6×8cm 小袋，40mm 宽度正好。

**建议标签字段（按优先级）**：

| 优先级 | 字段 | 说明 |
|---|---|---|
| 必印 | 品名 | 最大字号 |
| 必印 | 每袋分装量 + 第几袋/共几袋 | 加量时区分 |
| 必印 | 分装日期 | 实际分装日 |
| 必印 | 有效期至 | 加粗 |
| 必印 | 储存条件 | 避光、密封、阴凉干燥 |
| 必印 | 原品（品牌·规格） | 可换行 |
| 必印 | 分装者/品牌 | 赛文的食堂 |
| 必印 | “分装小样，非直接食用” | 合规 |
| 必印 | “内含干燥剂，请勿食用” | 安全 |
| 建议 | 用法 | “按本次食谱用量添加；开封后密封防潮” |
| 可选 | 批号/订单号 | 追溯用，字号可小 |

> 40×60 放全部字段会比较挤；如果实测放不下，优先删“批号/订单号”（后台仍可查），不要删“效期/干燥剂/分装者”。

### 5.2 每日产能（已确认：30 单/天，可配置）

- 计数口径：**按订单数**，不是袋数；补发单也算一单。
- 超过 30 单：自动顺延到下一个营业日。
- Web 可配置这个数字。
- 管理员手动改期可以超排，但系统标红并记录原因/操作人。
- 如果管理员把上限从 30 调到 20，已经排了 30 单的那天**不自动挪**，标红让管理员处理。

## 六、售后承诺

你选的是：**缺货/发错/破损/量不对 → 退款或免费补发，不要求寄回。**

建议明确：

| 项 | 建议 |
|---|---|
| 窗口 | 发货后 7 天（可配置） |
| 凭证 | 选填；破损/发错提示上传照片 |
| 退款 | 支持全额/部分；累计不超过实付 |
| 补发 | 每个售后记录最多一张补发单；不同售后记录可再次补发 |
| 退回 | 不要求寄回（食品类退回也不能再卖） |
| 滥用 | 同一用户高频售后人工复核；不对外承诺“无限次” |
| 成本 | 定价预留 3%–5% |

## 七、渠道与入口

本轮确认：

- **只在 DIY 制作单页卖**。
- 不做首页补剂入口、不做独立商城、不做“我的”补剂商城。
- 食谱详情页可以加一句“自己做会带补剂清单”，但**不直接卖**。
- 复购：**第一批就做“再次购买”**，放在补剂订单详情。
  - 按上一单的补剂清单/份数重新报价、重新下单。
  - 价格、可售性以本次为准；缺货标灰。
  - 地址重新选；发货日按新单算。
  - **不要求有当前 DIY 制作单**；页面不额外弹“价格可能变化”的提示（结算页本身会显示本次价格）。
  - 生成新订单，不复制支付/售后记录。

### 7.1 再次购买（第一批就做）

- 入口：顾客补剂订单详情 → “再次购买”。
- 行为：按上一单的补剂清单/份数，重新报价、重新下单。
- 价格/可售性以本次为准；缺货标灰，可只买可买的。
- 地址重新选；发货日按新单算；产能按新单占。
- **不要求有当前 DIY 制作单**；页面不额外弹“价格可能变化”的提示，结算页本身显示本次价格。
- 生成新订单，不复制支付/售后记录；后台可追溯“从哪张单再来”。

### 7.2 顾客自助改地址（已确认）

- 顾客在补剂订单详情可自己改收货地址，不需要联系客服。
- **已发货（SHIPPED）不能改**；未发货（PENDING_PAYMENT / PAID / PACKED）可以改。
- 改地址只改订单的收货快照，不改用户默认地址；用户可以选择“同时设为默认地址”（可选）。
- 后台记录：原地址、新地址、操作人、时间；客服可查。
- 如果已经打包/打印面单，改地址后需要重新打印/重新生成面单；系统给提示，不静默。
- 已发货后要改地址，只能联系快递改派/客服，系统不提供自助。

### 7.3 通知：正常发货也要发（已确认）

- 排期确认：站内消息 + 微信订阅消息。
- **正常发货**：站内消息 + 微信订阅消息（不只是延迟才发）。
- 延迟发货：站内消息 + 微信订阅消息。
- 售后受理/完成/驳回/退款到账/补发发货：站内消息 + 微信订阅消息。
- 订阅消息模板 ID 走环境变量；未授权时站内消息兜底。
- 小程序在提交订单/申请售后时请求订阅授权；正常发货模板也要在授权列表里。

### 7.3.1 资金到账 vs 订单完成

- **微信支付成功即完成收款**，货款按微信结算周期进入商户账户；不是等顾客确认收货/订单自动完成才到账。
- **自动完成（发货后 10 天）只是订单生命周期关闭**，不是收款条件，也不触发打款。
- 退款仍按售后窗口（发货后 7 天）从商户账户/待结算资金原路退回；与订单是否 `COMPLETED` 无关。
- 只有未来改用“平台担保交易/确认收货后结算”，才需要等确认；当前直连商户模式不适用。
- 财务对账：收款看支付成功/结算单；收入确认可按发货/完成；两个口径不要混。

### 7.4 DIY 制作单快照（方向已确认）

**要解决的问题**：食谱改版后，补剂种类/用量可能变化；顾客之前生成的制作单和已买过的补剂应该还能按原样制作/购买。

**建议规则**：

- 顾客**第一次为这张制作单下单补剂**时，系统把制作单冻结成快照。
- 快照内容至少包括：
  - 食谱：id、版本、名称、食材清单与用量、补剂清单与用量、营养目标/制作步骤。
  - 狗狗：id、名字、体重/餐次等参与计算的字段。
  - 制作单：周期天数、每餐克数、每日摄入、分装计划、采购清单。
  - 生成时间、食谱版本。
- 冻结后：
  - 制作单页面展示快照，不随食谱改版变化。
  - “再次购买”按快照的补剂清单/用量重新报价，价格/可售性以本次为准。
  - 顾客想要最新食谱，重新生成一张新制作单；旧单保留。
- 如果第一次下单前食谱已经改版，快照以**下单时**看到的版本为准（这是顾客实际购买的那一版）。
- 快照不复制支付/售后记录；只冻结“这次要做什么、买什么”。

**已确认**：

- 快照时点：**首次下单补剂时冻结**（不为“生成了但没买”的制作单占存储）。
- 快照范围：**整张制作单**（食谱+食材+补剂+狗狗+周期+每餐克数+分装计划+采购清单+制作步骤）。
- 冻结后不随食谱改版；想要最新食谱，重新生成新制作单。
- 必须同时修复：补剂订单目前没有把 `diySheetId` 传下去，订单和制作单是断的。
