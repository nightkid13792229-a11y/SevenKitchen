## 零、一页纸

**一句话**：把 DIY 食谱里“这顿饭缺的那部分补剂”，按用量分装成小袋，跟着食谱一起买、单独发货。顾客买的不是一瓶补剂，是“这顿饭的营养补齐 + 不用自己算”。

| 项 | 当前结论 | 状态 |
|---|---|---|
| 产品范围 | 只卖本次 DIY 食谱推荐的补剂，不做独立补剂商城 | ✅ 已确认 |
| 顾客 | 已经在用 DIY 食谱自制狗饭的狗主人 | ✅ 已确认 |
| 核心价值 | 精确配量、不用自己算；不用买整瓶、不浪费 | ✅ 已确认 |
| 辅助价值 | 一次买齐省事、标签/效期可信、低门槛尝试 | ✅ 已确认 |
| 省钱口径 | 顾客整单更省（不用买整瓶）；**不说“单价最低”** | ✅ 已确认 |
| 不作为主张 | 独立商城、品牌/规格自选、加购其他补剂 | ✅ 本轮排除 |
| 卖法 | 一键买齐全部推荐，顾客可逐项取消 | ✅ 已确认 |
| 产品角色 | **利润品**，要承担毛利 | ✅ 已确认 |
| 收费结构 | 商品明细 + 每单服务费 + 运费 + 三个门槛 | ✅ 结构确认，数字待定 |
| 交付承诺 | 按营业日/截单时间，给顾客一个**确定的发货日期**；顾客不自选更晚日期 | ✅ 已确认 |
| 售后承诺 | 缺货/发错/破损/量不对 → 退款或免费补发，不要求寄回 | ✅ 已确认 |
| 售后窗口 | 发货后 7 天，后台可改 | ✅ 已确认 |
| 入口 | 只在 DIY 制作单页卖；不做首页/独立商城入口 | ✅ 已确认（本轮） |

**一句话生意逻辑**：

> 顾客为了“省事 + 不浪费 + 配得准”付一点溢价；我们靠商品加价 + 分装服务费赚钱；顾客整单支出比买整瓶更省；交付按营业日给确定日期；出问题无理由退/补，不折腾顾客。

## 一、产品到底是什么

### 1.1 是

- **DIY 食谱的配套增值服务**：顾客在制作单里看到“这顿缺什么”，一键买齐。
- **按用量卖，不按瓶卖**：每种补剂按本次食谱的用量分装成小袋。
- **一个补剂一袋**：不混装；加量则同一补剂多袋。
- **每袋配干燥剂 + 标签**：标签有品名、分装量、分装日期、有效期、储存条件、分装者。
- **独立发货**：不和鲜食一起发；补剂是常温，鲜食是冷链。

### 1.2 不是

- ❌ 不是独立补剂商城：顾客不能随时进来买任意补剂。
- ❌ 不是“整瓶代购”：我们不卖整瓶，只卖本次用量。
- ❌ 不是品牌/规格自选：顾客不能指定换成另一个牌子。
- ❌ 不是加购平台：本轮不能加购食谱之外的补剂。
- ❌ 不是“单价最低”：它是利润品；顾客省钱来自“不用买整瓶”，不是我们每克更便宜。
- ❌ 不是订阅制：本轮不做按月自动配送。

### 1.3 为什么顾客不自己买整瓶

| 顾客的麻烦 | 我们的解决 |
|---|---|
| 不知道每种补剂该买哪个品牌、什么规格 | 我们按食谱推荐，直接分装 |
| 不知道一只狗每天该吃多少 | 按食谱用量算好，一袋就是一次/一段时间的量 |
| 一瓶吃不完、过期浪费 | 只买本次用量，不浪费 |
| 买回来还要自己称、自己分 | 我们称好、分好、贴好标签 |
| 怕买错、怕过量 | 标签写清分装量、效期、储存条件 |

> **核心是“省事 + 不浪费 + 配得准”。**
> “省钱”是结果：顾客不用为一次食谱买整瓶，整单支出更省；但我们不承诺“单价最低”。

## 二、顾客与价值主张

### 2.1 顾客是谁

| 类型 | 特征 | 他真正要的 |
|---|---|---|
| **A 怕麻烦型** | 已经在做 DIY，但不想研究补剂 | 一键买齐，别让我算 |
| **B 怕浪费型** | 买过整瓶，放过期 | 只买这次用量 |
| **C 怕买错型** | 不知道品牌/剂量，怕过量 | 有人替我配好、写清楚 |
| **D 尝试型** | 想试新补剂，不想买一整瓶 | 低门槛小份试 |
| **E 信任型** | 在意标签、效期、分装卫生 | 看得见的规范 |

> 这五类人都来自 DIY 制作单，不需要额外获客；本轮不投广告、不做独立商城。

### 2.2 价值主张的层级

| 层级 | 主张 | 用在哪 |
|---|---|---|
| **核心** | 按食谱精确配量，不用自己算 | 标题、入口第一句 |
| **核心** | 不用买整瓶，不浪费 | 价格解释、对比整瓶 |
| **辅助** | 一次买齐，省事 | 一键购买按钮 |
| **辅助** | 标签/效期/分装可信 | 详情页、标签、售后 |
| **辅助** | 低门槛尝试 | 7 天小份 |
| **结果证明** | 整单更省 | 用“不用买整瓶”解释，不说“单价最低/全网最低” |

### 2.3 “利润品”和“顾客省钱”为什么不冲突

一开始我把这两件事当成矛盾，是把“顾客省钱”理解成了“我们单价更低”。正确的口径是：

| 视角 | 事实 |
|---|---|
| 顾客 | 为了做一次食谱，不用买 8 瓶补剂；只买这次用量，**整单支出更省** |
| 我们 | 按用量分装，有服务费和加价；**单位克价可以比整瓶高**，但顾客不需要买整瓶 |
| 结果 | 顾客省的是“总支出/浪费”，我们赚的是“分装服务 + 商品加价”，两者同时成立 |

所以：

- 对外可以说“**按用量买，整单更省；不用买整瓶**”。
- 不可以说“单价最低/全网最低/比整瓶便宜”——整瓶的克价一定比我们低。
- 顾客的省钱来自“按需购买”，不是“我们贴钱”。

> 这也是为什么定价可以用“商品明细 + 服务费”：顾客看得见自己只买了这次用量，整体仍然比买整瓶划算。

## 四、定价建议（重点）

> 下面给的是**结构和起点**，不是最终数字。具体数字要按你的实际进货价、人工、运费算。

### 4.1 先定三条原则

**原则 1：按“这次要花多少钱”卖，不按“每克多少钱”卖。**

顾客关心的是“这单多少钱、能吃多久、比买整瓶划不划算”，不是每克单价。页面要给他：

- 这单总价
- 每天成本
- 覆盖多少天
- 对比“买整瓶用不完”的浪费

**原则 2：服务费按“单”收，不按“袋”收。**

为什么：

- 顾客的痛点是“一键买齐”；按袋收服务费会让“多买几种”变贵，反而抑制一键买齐。
- 我们的固定劳动在“开单、称装、贴标、打包”，不是每袋线性增加。
- 按单收，顾客更容易接受；按袋收，8 种补剂会被收 8 次，观感差。

**原则 3：设最低消费/免服务费门槛，保护单均毛利。**

小单是利润杀手：一单只买 1 种补剂、7 天量，商品毛利可能只有几块钱，一单售后就吃掉。

建议至少设一层：

- **最低商品金额**（例如 ¥29/¥39）：低于此不能下单，或收固定小单服务费。
- **免服务费门槛**（例如商品满 ¥99）：鼓励买齐、买长周期。
- **包邮门槛**（例如商品满 ¥99/¥129）：把运费压力转成加购动力。

> 三个门槛不要设得太近，否则顾客只记得“还差一点”，体验差。建议：
> 最低商品 ¥29 → 免服务费 ¥99 → 包邮 ¥129（示例，待核算）。

### 4.2 推荐的价格结构

顾客在下单页看到**三行**：

```
商品小计        ¥XX.XX   （每种补剂一行，可逐项取消）
分装服务费      ¥10.00   （每单固定；满 ¥99 免）
运费            ¥8.00    （一口价；满 ¥129 免）
────────────────────
合计            ¥XX.XX
每天约          ¥X.XX    （合计 ÷ 覆盖天数）
```

为什么不是“一口价套餐”：

- 顾客可以**逐项取消**，一口价套餐会让“取消一项退多少钱”说不清。
- 商品明细 + 服务费 + 运费，顾客知道钱花在哪，售后也好解释。
- 一口价可以作为**展示摘要**（“7 天补剂包，约 ¥XX/天”），但**计价基础仍是明细**。

### 4.3 一个示例（仅演示算法，不是最终定价）

假设：

- 7 天、8 种补剂，补剂成本合计 ¥10.36
- 加价倍率 2.0 → 商品小计 ¥20.72
- 服务费 ¥10，运费 ¥8 → 合计 ¥38.72
- 每天约 ¥5.53

成本侧（示例）：

| 项 | 金额 |
|---|---|
| 补剂成本 | ¥10.36 |
| 包材（8 袋 + 8 干燥剂 + 8 标签） | 约 ¥1.8 |
| 人工（15 分钟） | 约 ¥7.5 |
| 运费 | 约 ¥5.0 |
| 支付手续费（0.6%） | 约 ¥0.23 |
| 售后预留（3%） | 约 ¥1.16 |
| **合计成本** | **约 ¥26.05** |
| **单均贡献** | **约 ¥12.67（32.7%）** |

> 如果人工按 10 分钟、运费按 ¥4 算，贡献会到 40% 左右。
> 如果服务费免掉、运费也免掉，这单只剩 ¥20.72 商品收入，扣成本后可能不到 ¥5，甚至亏。

**结论**：

- 服务费和运费不能轻易全免；免的前提是商品金额足够高。
- 目标单均贡献建议 **35%–45%**；低于 30% 就要调价/调门槛/调倍率。
- 7 天小单可以存在，但要用**最低商品金额 + 服务费**兜住。

### 4.4 长周期要不要便宜

建议**给长周期一点甜头，但不要打折打穿**：

| 周期 | 策略 |
|---|---|
| 7 天（尝试） | 标准价；不促销；用“低门槛试”做卖点 |
| 30 天（复购） | 免服务费，或商品 95 折；但受效期上限约束（总天数 ≤ 90 天） |
| 加量（多份） | 不按袋加服务费；可给“多份免运费” |

原因：

- 长周期摊薄人工/运费，单均贡献更高，值得让一点。
- 但补剂分装效期有限（粉剂 6 个月、片剂/胶囊 9 个月），不能无限卖长周期。
- 加量不应再收一次服务费，否则顾客觉得“多买反而被惩罚”。

### 4.5 售后成本要预留

你选的是“无理由退款/补发，不要求寄回”。这是很强的承诺，也是成本。

建议：

- 在定价里预留 **3%–5% 的售后损耗**。
- 设售后窗口（建议发货后 7 天），避免无限期。
- 破损/发错要求照片（选填但提示），不是不信任，是方便追责。
- 监控售后率：超过 5% 要复盘是分装/物流/预期问题，不是继续硬扛。

### 4.6 什么时候调价

不要一次定死。建议：

1. 先按“成本 × 2.0 + 服务费 ¥10 + 运费 ¥8 + 门槛”跑 30–50 单。
2. 记录每单：商品成本、包材、人工分钟、运费、支付费、售后。
3. 看三个数：
   - 单均贡献率（目标 35%–45%）
   - 补剂渗透率（有多少 DIY 用户买了补剂）
   - 售后率（目标 <5%）
4. 再决定：调倍率、调服务费、调门槛、还是调选品。

### 4.7 不建议做的事

| 不做 | 原因 |
|---|---|
| 用“全网最低”做主打 | 整瓶单价一定比我们低；会陷入比价 |
| 免服务费 + 免运费做默认 | 小单直接亏；除非商品金额足够高 |
| 按袋收服务费 | 惩罚“一键买齐”，与卖法冲突 |
| 一口价套餐但允许逐项取消 | 退款金额算不清，售后纠纷 |
| 用复杂折扣/优惠券 | 利润品，先把基础价格和门槛跑通 |
| 把售后成本当“不会发生” | 无理由退/补一定会发生，必须预留 |

## 五、交付承诺

你的口径是：**按营业日给顾客一个确定的发货日期，不给模糊承诺。**

建议这样落地：

1. 顾客在下单页看到**一个确定日期**，不是“尽快发货”。
2. 日期由系统按“营业日历 + 截单时间 + 付款时间”算：
   - 截单前付款 + 今天是营业日 → 今天
   - 否则 → 下一个营业日
3. 顾客**不自选更晚日期**；下单页只显示系统算出的最早发货日。
4. 如果算出的日期因停发/异常变化，主动通知顾客，并给出新日期。
5. 顾客侧只说“预计发货日期”，不说“分装日”。

**待确认**：

- 当天发货的截单时间具体几点（可配置，默认 17:00）？
- 如果当天做不出来，是顺延到下一个营业日，还是提前截单？
- 快递用哪家/什么时效？这直接影响运费成本和售后率。

## 六、售后承诺

你选的是：**缺货/发错/破损/量不对 → 退款或免费补发，不要求寄回。**

建议明确：

| 项 | 建议 |
|---|---|
| 窗口 | 发货后 7 天（可配置） |
| 凭证 | 选填；破损/发错提示上传照片 |
| 退款 | 支持全额/部分；累计不超过实付 |
| 补发 | 每个售后记录最多一张补发单；不同售后记录可再次补发 |
| 退回 | 不要求寄回（食品类退回也不能再卖） |
| 滥用 | 同一用户高频售后人工复核；不对外承诺“无限次” |
| 成本 | 定价预留 3%–5% |

本轮确认：

- **只在 DIY 制作单页卖**。

- 复购：本轮不做“再次购买”按钮；顾客回到制作单再买（后续再优化）。

## 九、这对技术需求意味着什么

在生意模型确认后，技术需求要做这些调整：

| 原需求 | 调整 |
|---|---|
| 独立补剂商城/加购/换品牌 | **不做**（本轮明确排除） |
| 一口价套餐 | 不做计价基础；只做展示摘要 |
| 按袋服务费 | 改为**按单服务费** |
| 顾客自选 30 天日期 | **不做**；只给系统算出的最早发货日 |
| 售后无理由 | 保留；补窗口/凭证/成本预留 |
| 订单中心/排产/库存 | 保留，但等定价和交付承诺定后再细化 |
| 追加“更便宜”文案 | 不作为主打；只在“比整瓶不浪费”时出现 |
