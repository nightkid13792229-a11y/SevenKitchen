# 原料标签字段改造方案（简单版）

> 日期：2026-10-30
> 目标：让「原料组成」和「添加剂组成」不再由原料类型（食材/补剂）决定，而由合规分类决定。
> 范围：只解决标签上的原料/添加剂归类与名称问题，不动营养计算、采购、库存。

## 一、要解决的问题

| # | 问题 | 后果 |
|---|---|---|
| 1 | 标签按 `type = SUPPLEMENT` 决定「哪些算添加剂」 | 海藻粉、鸡蛋壳粉、骨粉、鱼油这 4 样其实是**饲料原料**，被错放进添加剂组成 |
| 2 | 标签名直接用原料名称 | 名称里带剂型（「维生素E胶囊」「葡萄糖酸锌片」），不是合规写法 |
| 3 | 一个原料可能对应多个标签名 | B族维生素胶囊含 6 种营养素，标签上必须逐个列 |
| 4 | 新增原料时没人问「它在标签上算什么」 | 每加一个新原料就多一个隐患，靠事后修排版修不完 |

## 二、方案：加两个字段，改三处逻辑

### 2.1 字段设计

在原料（Ingredient）上新增：

| 字段（业务名） | 建议技术名 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| 标签分类 | `labelCategory` | 枚举 | 是 | `FEED_MATERIAL` 饲料原料 / `FEED_ADDITIVE` 饲料添加剂 / `NON_FEED` 非饲料（包材、耗材） |
| 标签名称 | `labelNames` | 文本 | 是 | 合规写法，**允许多个**，用顿号分隔 |
| 名称依据 | `labelNameSource` | 文本 | 否 | 例如「饲料添加剂品种目录 2023 版」 |

**为什么「标签名称」是一组而不是一个：**
B族维生素胶囊的有效成分是 B1/B2/B3/B6/B9/B12，标签上必须逐个列出。单值字段会让这个 SKU 永远填不对。存成一组字符串，既能覆盖绝大多数「一对一」的情况，也不用为将来建子表。

**为什么不用现有的 `type` 字段：**
`type` 表达的是采购与生产视角（食材/补剂/包材），标签合规是另一个维度。同一个 `type=SUPPLEMENT` 的原料，在标签上可能是原料也可能是添加剂。两个维度必须分开，否则以后每加一类视角就要改一次 `type`。

### 2.2 三个取值怎么判断

| 取值 | 判断标准 | 标签上 |
|---|---|---|
| 饲料原料 | 出现在《饲料原料目录》里的物质：肉、内脏、谷物、蔬果、骨粉、海藻粉、鱼油 | 写进「原料组成」，按加入量降序 |
| 饲料添加剂 | 出现在《饲料添加剂品种目录》里的物质：氨基酸、维生素、矿物质、胆碱 | 写进「添加剂组成」，只列名称 |
| 非饲料 | 包材、耗材、清洗用品 | 不上标签 |

判断拿不准时的默认规则：**先查原料目录；查不到再查添加剂目录；两个都查不到，就不该拿来做产品**。

## 三、改哪三处逻辑

### 3.1 标签生成（后端）

现在：
```
食材(FOOD) → 原料表带占比
补剂(SUPPLEMENT) → 原料表带本单克数
```

改成：
```
按 labelCategory 分组
  FEED_MATERIAL → 原料组成，按占比降序，显示「名称 占比%」
  FEED_ADDITIVE → 添加剂组成，只显示名称
  NON_FEED      → 不输出
```

**占比从哪来：** 食材本来就有 ratio；骨粉/海藻粉这类从补剂转成原料的，用「该原料重量 ÷ 配方总重 × 100」算。
**算不出来怎么办：** 《标签规定》第六条只要求原料按加入量**降序**，**不强制标占比**。所以算不出占比时，允许只写名称不写百分比，不影响合规。

### 3.2 打印校验（关键）

打标签前做一次校验：本单用到的所有原料，`labelCategory` 和 `labelNames` 都必须有值（`NON_FEED` 除外）。

- 缺任何一个 → **拒绝打印**，弹出具体缺哪几个原料，并给一个跳转到原料后台的入口
- 这是整套方案里唯一真正「拦得住」的地方。只做新增门禁，存量没补的照样会打出错标签

### 3.3 新增/编辑门禁

保存原料时：`labelCategory` 必填；`labelNames` 必填（`NON_FEED` 除外）。不满足不允许保存。

**顺序要求：先补存量，再开门禁。** 反过来的话，开发期加个测试原料都会被自己拦住。

## 六、边界情况

| 情况 | 处理 |
|---|---|
| 老订单补打标签 | 订单快照里没有标签字段，打印时回查原料主数据取 `labelNames`；取不到就按缺失处理（拦下） |
| 一个原料需多个标签名 | `labelNames` 存一组，标签上按录入顺序展开 |
| 同一原料有多种规格（骨粉 KAL / NOW） | 各自填同一个标签名称即可 |
| 标签名改了 | 建议记录变更历史；标签是「对外承诺」，变更需可追溯 |
| 添加剂是否要标添加量 | 一般不用。仅当对某个添加剂做成分声称时才需标示添加量 |

## 七、验收标准

1. 打印任意一单，原料组成里**只有** `FEED_MATERIAL`，添加剂组成里**只有** `FEED_ADDITIVE`，包材不出现
2. 原料组成按占比降序；添加剂无顺序要求但同一食谱每次打印顺序一致
3. 删掉某个原料的标签名称后，该食谱的标签**打印被拒绝**并指出是哪个原料
4. 新建原料不填标签分类保存失败；包材类保存成功
5. 输出的标签文字与第四节的对照表一致
