## 一、本会话完成的改动

### 1. 分装备料入口与角标

- 员工工作台「分装备料」角标接上补剂待处理数量（待确认收款 / 待分装 / 待发货）。
- 分装备料页从“只有汇总”变成“当天订单 + 汇总”：
  - 当天订单可点进补剂订单详情；
  - 订单清单不再放“打印标签 / 去发货”按钮，这两个动作统一收在订单详情页。
- 页面标题统一叫「分装备料」。

### 2. 员工端取消分装工单

- 补剂订单详情删除整块“分装工单”：不再填批号、不再选原瓶到期日、不再点“提交分装结果”。
- 已付款（PAID）即可直接**打印标签**和**发货**；旧单 PACKING/PACKED 继续兼容。
- 后端：
  - `shipOrder` 允许从 PAID 直接发货；
  - 首次打标签 / 首次发货时自动补分装日期与标签效期；
  - 库存扣减从“分装”挪到“发货”，旧单已扣过的靠 ledger 唯一键防重复。
- 状态文案：PAID / PACKING / PACKED 在员工和顾客侧都显示「待发货」；列表用 `TO_SHIP` 合并筛选。

### 3. 补剂标签改版

- 老板定版 9 个字段，自上而下：
  1. 赛文的食堂（品牌）
  2. 预分装补剂
  3. 分装日期
  4. 有效期
  5. 储存注意事项（字段名 + 内容分两行）
  6. 订单编号
  7. 原品名称
  8. 分装量/袋（本次新增）
  9. 分装小样食用提醒
- 版式优化：标题下 + 提醒前各一条细分隔线；有效期加粗；分装量/袋加粗；日期/订单/原品名称统一左对齐。
- 不再上标签：品名大字、每袋用量（原“23平勺”那行）、第几袋/共几袋、批号、原品品牌规格、用法、分装者。
- 日期规则：
  - 分装日期 = 第一次打印标签的当天；
  - 有效期 = 分装日期 + 该补剂固定保质期（粉剂 6 个月、片剂/胶囊 9 个月）；
  - 旧单若存在原瓶到期日，仍取「原瓶到期日」与规则值的较早者。
- 打样图：`docs/assets/2026-11-02-supplement-label.png`

### 4. 售后可见性

- 新售后**不改订单履约状态**（订单仍是已发货/已完成），改为在旁边挂派生标签：
  - 顾客订单详情：状态旁「售后中 / 退款中」；返回售后页后自动刷新。
  - 顾客订单列表：标题旁「售后中」；有未完结售后的单进「售后中」Tab。
  - 员工端补剂列表/详情：状态旁「售后中 / 退款中」。
  - 后台补剂订单列表：状态列显示「已发货 + 退款中」两个标签；「售后中」筛选改为“有未完结售后单”，数量也正确。
  - 工作台「订单中心」角标把管理员侧补剂未完结售后算进去。
- 订单中心原有「只看有售后」筛选和售后中心「补剂售后」页保持不变，继续可用。

### 5. 手机端管理员处理售后

- 补剂订单详情「售后记录」里，管理员（ADMIN）在**待受理**的售后单上可直接：
  - 退款类：同意退款 / 驳回
  - 补发类：同意补发 / 驳回
  - 其他问题：仅登记完成 / 驳回
- 退款弹窗默认带出申请金额，可改部分退款；驳回必须填原因。
- 员工（STAFF）角色看不到这些按钮；后端接口仍是 `AdminGuard`。
- 处理中 / 退款失败重试仍去后台电脑端「售后中心 → 补剂售后」。

### 6. 退款成功后的顾客展示

- 问题：已发货订单退款成功后，订单履约状态仍是 SHIPPED，顾客列表继续显示「已发货」。
- 修复：
  - 退款成功时把 `refundStatus / refundAmount / refundedAt` 写回订单；
  - 对已有“退款成功但订单字段为空”的老单，在订单接口读取时按售后单兜底补齐；
  - 顾客列表/详情显示「已退款 / 部分退款」，已退款单归到「已完成」，不再出现「申请售后」按钮；
  - 员工端补剂列表/详情、后台补剂订单列表也显示「已退款」标签。
- 说明：订单内部履约状态仍保留 SHIPPED（保留物流/完成记录），**顾客看到的是已退款**。
