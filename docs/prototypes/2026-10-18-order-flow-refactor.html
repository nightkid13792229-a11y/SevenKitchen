加三样：状态标签 / 交付日期 / 售后窗口剩余。

状态标签用的是跟订单详情同一套说法（待付款 / 已付款 / 已交付 / 售后中 / 已完成 / 已取消）—— 这样两页不会打架。

页面类型改什么说明

一个共用的东西
  • 状态标签在三个地方都要出现（详情的状态头、列表的徽章、售后页的状态）—— 所以它应该抽成一个组件：OrderStatusBadge，吃后端给的 { code, label, tone }。
  • 「售后窗口剩余几天 / 免费次数剩余几次」也是三处都要 （详情、售后页、列表）—— 同样该由后端算好下发，前端只显示。
