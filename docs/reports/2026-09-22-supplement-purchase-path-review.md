## 一、结论先行

1. **要看的不止 3 个页面，而是 6 个**。用户问的「DIY 食谱配置页 / DIY 制作单 / 一键购买补剂」是核心 3 页，但真正决定成交的还有上游的**食谱详情页**和下游的**补剂订单页、我的制作单页**。
2. **补剂有两条进店路，主路是免费的**：用已发布食谱「自己做」→ 生成制作单 → 买补剂。不需要定制食谱、不需要付 ¥299、不需要等人工。**所以瓶颈不在付费门槛，而在「食谱详情页 → DIY 配置页」这一段没有任何说明和补剂预期。**
3. **最大的问题不在页面里，在两个结构层**：
   - **入口结构**：全站补剂购买入口**只有 1 个**（DIY 制作单页中段），且它会**无声消失**；首页提及补剂 0 次。
   - **价格结构**：生产环境每单固定收 **¥9.9 服务费 + ¥18 运费**（¥18 已确认为顺丰非生鲜快递价），小额单光费用就是货款的好几倍。**定价口径已决定推迟，本轮不处理。**
4. **页面细节里最该改的是**：「用户不知道自己做能换来什么」+「按钮灰着却不给理由」+「支付失败/取消后被一句错话送走」。

## 二、回答「是不是只看那 3 个页面」

不是。完整路径实际是 6 个页面：

| # | 页面 | 在这条路径里的角色 |
|---|---|---|
| ① | 食谱详情页 | 上游。用户在这里决定「买成品」还是「自己做」 |
| ② | DIY 食谱配置页 | 用户选狗、选天数、生成制作单 |
| ③ | DIY 制作单页 | **补剂购买入口所在页**（全站唯一） |
| ④ | 补剂下单页 | 勾选补剂、选地址、提交、支付 |
| ⑤ | 我的补剂订单页 | 支付后、售后、复购 |
| ⑥ | 我的制作单列表页 | 复购（唯一能回到④的起点） |

**②③④ 是核心，①⑤⑥ 是连接件。** 只优化 ②③④ = 只打磨最后两米；①⑤⑥ 才是「有没有人走到这里」和「买完还回不回来」的关键。

### 进店有两条路（此前评审把主路说窄了，此处更正）

**路线一：用已发布食谱免费生成制作单（主路，无需付费、无需等人工）**

1. 首页 / 食谱橱窗挑一道已发布食谱
2. 食谱详情页点「自己做」
3. DIY 配置页选狗、选天数，生成制作单
4. 制作单页点「一键购买补剂」

**路线二：¥299 定制食谱**

1. 首页点「食谱定制」
2. 支付 ¥299（`custom-recipe.service.ts` 平台定价 299）
3. 等人工出配方（`PENDING_PAYMENT → IN_PROGRESS → DELIVERED`，人力交付、非自动）
4. 配方交付后进 DIY 配置页生成制作单
5. 制作单页点「一键购买补剂」

**结论修正**：补剂客群**不只**是定制食谱顾客 —— 任何用已发布食谱免费生成制作单的顾客都是潜在买家，而且这条免费主路的池子远大于定制路。所以真正的瓶颈不是「要先花 ¥299」，而是：

- 免费主路的**入口（食谱详情页「自己做」）没有说明它会带来什么**，用户不知道点它能拿到补剂清单；
- 补剂要约在**第 3、4 跳之后**才出现，且全程零价格；
- 首页和食谱橱窗（流量的起点）**完全没有补剂信息**（首页提及补剂 0 次）。

**这意味着「食谱详情页 → DIY 配置页」这一段是整条链路最值得优化的地方**：它既是免费主路的必经之路，又是转化损耗最大的一段。

## 三、结构问题（比页面细节重要）

### 结构问题 A：唯一入口藏得深、还会消失

1. **位置深**：入口在制作单页「制作清单」区块的末尾，前面隔着封面、信息区、提醒卡、制作信息、**食材表 + 补剂表两张表**，按样式推算需滚 **1.5–2.5 屏**，首屏绝对看不到，页面也没有「下面可买补剂」的提示。
2. **会无声消失**：入口显示条件是「商城开关已开 **且** 报价接口返回了补剂明细」。商城状态接口一抖动就静默置为关闭（`diy-sheet/index.vue:1005-1013` 注释明写「静默降级」），页面**不给任何说明**，用户只会以为功能不存在。
3. **入口长得像广告条**：蓝色渐变的配色确实跳（全页唯一蓝色，视觉上是加分项），但**无图标、无商品图、无价格**，标题比食谱名还小，不是按钮形态、无按压反馈；同一区域里「更像能点」的反而是表格里每行的「查看商品 〉」小徽章。
4. **复购路径断了**：从旧制作单再买一次要 **5 次页面/滚动操作**（制作单列表 → 详情 → 滚到中段 → 下单页 → 提交 → 支付）；补剂订单页**没有「再次购买」**（成品订单页有），下单成功后用 `redirectTo` 替换自己，连回程都没有。
5. **没有第二个曝光点**：首页、成品订单完成页、我的页都没有补剂推荐。补剂是**消耗品**，本该有复购提醒，现在完全没有。

### 结构问题 C：用户不知道「自己做」能换来什么

1. 食谱详情页把「买成品」**刻意做成主路径**（深绿渐变 + 金字 + 更大字号，代码注释直接写「主转化路径」），「自己做」是浅绿次级样式（注释写「次级路径」），按钮上只有三个字，**没有任何副标题说明产物**。
2. 全页面向用户的补剂信息只有配方表里的「营养补充剂 N 种」；**没有任何一句**把「自己做 → 制作单 → 一键购买补剂」串起来。
3. **DIY 全链路一个价格都没有**，而价格接口其实**已经在调**（制作单页调了计价预览，返回的金额从未渲染，只用来算采购量）。用户无法比较「自己做 vs 买成品」，也不知道补剂大概要花多少钱。
4. 制作单页**没有一句说明「生成制作单不产生订单、不扣款」**，配合上一条（无价格），很可能有用户**因为怕扣款而不敢点**。
