# 体况评分（BCS）官方教学素材调研

- 日期：2026-09-29
- 目的：为「体况分引导」（C3）寻找**现成的官方教学素材**，替代 AI 生成方案
- 结论：官方素材存在，且有比 AI 生成更优的路径 —— **中国国家标准 GB/T 47217-2026**

---

## 1. 一句话结论

体况评分的官方素材**找到了三类**，其中最合适的是 **中国国家标准 GB/T 47217-2026《犬猫体况评分技术规范》**：

- 2026-09-01 刚实施，**现行有效**
- **中文简体**（WSAVA 只提供繁体）
- 适用范围**明确包含「犬猫饲养者」**——就是我们的用户
- 内容含**评定方法 + 结果判定 + 处置建议**，正好对应我们要做的引导
- 农业农村部提出，中国农业大学 / 中国农大动物医院 / 中国兽医协会起草
- **31 元即可购买**，无需任何授权谈判

WSAVA 的官方图表和视频也存在，但对商业小程序有一道**三方授权**门槛，且视频在国内不可用。

## 3. 素材一：GB/T 47217-2026《犬猫体况评分技术规范》

### 3.1 标准信息

| 项目 | 内容 |
|---|---|
| 标准号 | GB/T 47217-2026 |
| 名称 | 犬猫体况评分技术规范 |
| 英文名 | Technical specification of canine and feline body condition score |
| 状态 | **现行** |
| 发布日期 | 2026-02-27 |
| 实施日期 | **2026-09-01** |
| 出版语种 | **中文简体** |
| 页数 / 字数 | 16 页 / 15 千字 |
| 提出部门 | 中华人民共和国农业农村部 |
| 归口单位 | 全国伴侣动物（宠物）标准化技术委员会（SAC/TC 541） |
| 发布部门 | 国家市场监督管理总局、国家标准化管理委员会 |
| 起草单位 | 中国农业大学、北京中农大动物医院有限公司、北京市动物疫病预防控制中心、中国兽医协会、北京小动物诊疗行业协会 |
| 起草人 | 李格宾、唐娜、陈丝雨、夏兆飞、胡宇声、田一男、陆梓杰、史婉婷、孙悦、郑瑞峰、刘秀丽、项茹雪 |
| 定价 | 36 元 / 折扣价 **31 元** |
| 引用标准 | GB/T 40450（犬保定操作技术规范，与营养无关） |

来源：[全国标准信息公共服务平台](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=29A40C6C3A58B990787D061B68B6A8F5)

### 3.2 适用范围（标准原文）

> 本文件规定了犬猫体况评分的基本要求、结果判定，描述了评定方法，提供了相应的处置建议。
> 本文件适用于**犬猫饲养者**、繁育者、动物诊疗机构医务人员等对犬猫个体体况状态进行监测和管理。

**这段原文对我们的价值**：标准自己写明适用于「饲养者」，也就是终端宠主——不是只给兽医看的专业文件。我们在小程序里引导用户自测体况，正好落在它的适用范围内。

### 3.3 对我们的三个用途

1. **文案依据**：BCS 引导页可以标注「依据 GB/T 47217-2026 犬猫体况评分技术规范」，比引 WSAVA 更贴近国内用户认知
2. **判据校准**：核对我们现有问卷的 4 道动作题（摸肋骨 / 俯视看腰线 / 侧视看腹褶 / 摸尾根）与国标判定是否一致
3. **处置建议对齐**：标准含「处置建议」，可与已批准的增减重计划目标衔接

### 3.4 一个额外机会

该标准**同时覆盖猫**。我们当前只做狗，将来扩猫时可直接复用。

## 4. 素材二：WSAVA 官方体况评分图表

### 4.1 素材本体

WSAVA 官网提供的是一种「三栏五剪影」图表：俯视 + 侧视的狗剪影，取 1 / 3 / 5 / 7 / 9 五档，分三栏（低于理想 / 理想 / 高于理想），配 1–9 分文字判据。

| 版本 | 说明 |
|---|---|
| 官方中文版（繁体） | `1-體態評分表-狗.pdf` |
| 2025-06 新版英文版 | 设计更干净，剪影造型与旧版相同 |
| 底注 | ©2013. All rights reserved. 引用 Same 2010 (AJVR)、Laflamme 1997 (Canine Pract) |

**本地文件核对**：`~/Documents/Seven/宠物学习资料/指南/体况评分表-狗.pdf` 与 WSAVA 官网中文版**字节数完全一致**（6,988,779 B），即同一份官方文件。猫版同理。

### 4.2 授权规则（SOP v4 原文要点）

WSAVA 官网表态：**欢迎转载**，但必须遵守 SOP 并提交申请。SOP 的硬性要求：

1. **必须整体使用、不得改动**——不允许添加其它 logo，也不允许自行翻译（翻译需走单独的审批流程）
2. **必须保留 WSAVA GNC 的 logo**
3. 必须标注来源声明："Global Nutrition Committee Toolkit provided courtesy of the World Small Animal Veterinary Association"
4. 所有申请须提交 **WSAVA GNC 主席**审批
5. **营利机构还须经 WSAVA 执行委员会批准**
6. ⚠️ **BCS 图表的版权人另有其人**：SOP 第 2 页 3.b 明确列出「BCS charts by Deborah Greco」→ **还须取得 Deborah Greco 本人批准**

来源：[SOP for use of the WSAVA GNC Toolkits and Guidelines v4](https://wsava.org/wp-content/uploads/2024/05/SOP-for-use-of-the-WSAVA-GNC-Toolkits-and-Guidelines-v4.pdf)

### 4.3 为什么不是首选

- **三方批准链**（GNC 主席 + 执委会 + Deborah Greco），周期以周计，结果不确定
- 官方中文版是**繁体**，直接放进简体小程序观感不佳；而转成简体属于「改动」，需另行批准
- 即使获批，也必须原样使用，无法做成我们自己的视觉风格

## 5. 素材三：WSAVA 官方教学视频

| 项目 | 内容 |
|---|---|
| 名称 | Body Condition Score Video |
| 位置 | YouTube（WSAVA 官网链接） |
| 版权 | SOP 明确：**BCS video by Zara Boland** |
| 语言 | 英文，无中文字幕 |
| 实测 | 本机直连 YouTube **不通**（curl 返回 http=000） |

**不可用的三个理由**：

1. **国内打不开**——本机实测直连失败，我们的用户同样打不开
2. **小程序播不了**——微信小程序 `<video>` 只能播放自有 CDN 上的 mp4，无法嵌入 YouTube
3. **版权独立**——版权属 Zara Boland，需单独取得授权；加中文字幕又构成「改动」

结论：**官方视频这条路走不通，视频方案整体放弃。**

## 6. 版权边界：哪些能用、哪些不能用

这是本次调研最关键的一条判断：

| | 是否受版权保护 | 我们能否用 |
|---|---|---|
| BCS 9 分制的**判据本身**（摸肋骨、俯视看腰线、侧视看腹褶、尾根脂肪） | ❌ 不受保护——这是公开发表的科学事实（Laflamme 1997），并已被 GB/T 47217-2026 采纳为国家标准 | ✅ **可以直接用** |
| **具体的图画法**（WSAVA / Greco 的剪影造型、排版、配色） | ✅ 受保护 | ⚠️ 需授权；**但自己重画不侵权** |
| 国家标准**正文文字** | ✅ 受保护（中国标准出版社出版） | 引用标准号与判据 ✅；整段照抄 ❌ |

**直接推论**：我们现有的 BCS 问卷文案（4 道动作题）本来就是基于判据写的，**不涉及侵权**。缺的只是**插图**，而插图**可以自己画**——画的是「肋骨可见度 / 腰线 / 腹褶」这些客观判据，不是 WSAVA 那张图的复制。

## 8. 建议路线

### 主路线：自绘剪影 + 引用国标（推荐）

1. 购买 GB/T 47217-2026（31 元），精读判定与处置建议章节
2. 用国标判据核对我们现有问卷的 4 道动作题
3. 委托设计画 **5 张狗剪影**（1 / 3 / 5 / 7 / 9，俯视 + 侧视），风格与小程序统一
4. 引导页标注「依据 GB/T 47217-2026 犬猫体况评分技术规范」
5. 视频不做，改为**图文三步自测**引导

**优点**：简体中文、合规无依赖、视觉统一、可标注国标背书
**周期**：设计出图 3–5 天

### 并行路线：提交 WSAVA 授权申请（可选）

申请免费、不与主路线冲突。若获批，可在「权威来源」页面额外展示官方原图（原样 + 保留 logo + 来源声明）。**不承诺、不等待**。

### 三条路线总对比

| | A. 自绘 + 引国标 | B. 授权 WSAVA 原图 | C. AI 生成 |
|---|---|---|---|
| 权威性 | 高 | 最高 | 低 |
| 简体中文 | ✅ | ❌（仅繁体） | ✅ |
| 合规 | ✅ 无依赖 | ⚠️ 三方批准 | ✅ |
| 周期 | 3–5 天 | 数周起，结果未知 | 1 天 |
| 成本 | 设计费 + 31 元 | 免费（若获批） | 生成费 |
| 主要风险 | 需设计到位 | 被拒 | **手部/比例画错，误导用户判断体况** |
