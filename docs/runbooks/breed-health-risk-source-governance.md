# 犬种健康关注项数据源分级与准入规范

最后更新：2026-05-17

本文档定义犬种健康关注项的来源分级、审核流程和准入规则。目标是避免以后每新增一个品种都临时到处查资料，而是按统一来源层级完成审核，再把通过审核的数据导入后端知识库。

小程序中的“重点关注 / 建议了解 / 补充了解”是产品阅读优先级，不是某个权威数据库提供的统一医学风险等级。

## 数据源分级

### Tier A：核心结构化来源

每个品种审核时优先查询这一层。

| 来源 | 主要用途 | 说明 |
| --- | --- | --- |
| OMIA | 遗传病、基因、变异、PubMed 关联文献 | 单基因或变异证据的第一优先来源。 |
| IPFD HGTD | 遗传检测、phene、遗传方式、品种适用性 | 判断某个遗传检测是否适用于某个犬种。 |
| OFA / CHIC | 品种特异健康筛查要求、OFA 疾病资料 | 筛查类关注项的第一优先来源；CHIC 不是完整疾病风险清单。 |
| IPFD HSDD | 犬业协会、犬种俱乐部、兽医组织等给出的品种健康策略 | 适合作为犬种健康策略的总览索引。 |

### Tier B：犬种权威来源

用于补充品种语境、犬种俱乐部建议和面向犬主的表达边界。

- 国家级父犬种俱乐部健康声明。
- 父犬种俱乐部健康委员会页面。
- AKC 犬种父俱乐部健康声明和健康测试要求页面。
- The Kennel Club、其他国家犬业协会或犬种俱乐部公开资料。

### Tier C：兽医与研究来源

当某个关注点对犬主很重要，但不完全属于遗传病或 CHIC 筛查项目时，用这一层补充。

- Merck Veterinary Manual 等兽医参考资料。
- 大学兽医学院、兽医遗传实验室。
- AKC Canine Health Foundation、Morris Animal Foundation 等兽医研究组织。
- PubMed、期刊网站或大学仓储中的同行评议论文。

典型例子：金毛的肿瘤相关关注、迷你雪纳瑞的胰腺炎/高脂血症、拉布拉多的体重管理倾向。

### Tier D：发现线索或背景资料

不能单独作为发布依据。

- 商业 DNA 检测公司的营销页面。
- 泛宠物健康媒体。
- 普通宠物医院博客。
- 没有引用来源的犬种爱好者页面。

Tier D 可以帮助发现候选主题，但最终发布项必须由 Tier A、Tier B 或 Tier C 支撑。

### 禁用来源

以下来源不得作为发布依据：

- 论坛、Reddit、社交媒体、短视频和评论区。
- 没有原始来源链接的 AI 生成内容。
- 主要目的为销售产品的商业页面。
- 无法公开访问、已失效或需要登录才能查看的 URL。

## 单个品种审核流程

1. 统一犬种中文名、英文名和常见别名。
2. 查询 Tier A：
   - OMIA：遗传病、基因、变异证据。
   - IPFD HGTD：遗传 phene、检测适用性。
   - OFA/CHIC：品种健康筛查要求。
   - IPFD HSDD：品种健康策略记录。
3. 查询 Tier B：父犬种俱乐部、犬业协会、犬种健康声明。
4. 查询 Tier C：兽医教材、大学兽医学院、研究机构、同行评议论文。
5. 先把候选关注项写入审核表，不直接改导入数据。
6. 每个候选项标记为：
   - 进入第一版。
   - 作为补充了解。
   - 后续再审。
   - 暂不收录。
7. 只有同时满足来源支撑、保守文案和明确展示分级后，才能进入后端导入数据。

## 准入规则

### 遗传病或单基因疾病

建议最低来源组合：

- 1 个 Tier A 遗传来源，优先 OMIA 或 IPFD HGTD。
- 如有可能，再加 1 个 Tier A、Tier B 或 Tier C 的品种语境来源。

如果内容主要用于遗传检测或繁育沟通，默认使用 `补充了解`。只有在该问题对普通犬主也有明确症状识别、就医或日常管理价值时，才升级为 `建议了解` 或 `重点关注`。

### 品种健康筛查项

建议最低来源组合：

- 1 个 OFA/CHIC 或父犬种俱乐部筛查要求。
- 1 个疾病或筛查解释来源，例如 OFA 疾病页或犬种俱乐部健康页。

如果筛查项是该犬种核心关注，且对犬主日常管理也有明显价值，可使用 `重点关注`，例如大型巡回猎犬的髋肘关节。若更偏繁育筛查，则使用 `建议了解`。

### 多因素或犬主日常管理关注

建议最低来源组合：

- 1 个 Tier C 兽医或同行评议来源。
- 1 个 Tier B 或 Tier C 的品种特异来源。

除非证据明确支持，否则不要称为“遗传病”。优先使用更保守的名称，例如 `肿瘤相关关注`、`体重管理关注`、`胰腺炎/高脂血症相关关注`、`泌尿结石相关关注`。

### 证据冲突时

采用更保守的解释。如果某个主题只有 1 个较弱或过旧来源支撑，不进入小程序发布数据，只保留在审核表中等待后续复核。

## 分级规则

后端字段为 `attentionPriority`，小程序展示为阅读优先级。

| 分级 | 使用条件 | 展示意图 |
| --- | --- | --- |
| `KEY_ATTENTION` / 重点关注 | 品种特异证据强，且对严重性、早期识别或日常管理有明确价值 | 用户应该优先阅读。 |
| `RECOMMENDED_AWARENESS` / 建议了解 | 来源明确、与该品种相关，但紧迫性较低或更偏筛查/繁育语境 | 用户需要更多背景时阅读。 |
| `SUPPLEMENTAL_AWARENESS` / 补充了解 | 较窄的遗传检测、繁育导向项目，或低频但证据明确的问题 | 保留资料，但不挤占主视图。 |

不得把这些分级表述为官方风险等级。推荐页面文案是“本品种健康关注项”，不是“本品种高危疾病诊断”。

## 必填来源字段

后端保存的每条来源必须包含：

- 来源类型。
- 来源名称。
- 发布方。
- 标题。
- 公开 URL。
- 访问日期。
- 简短说明：为什么该来源能支撑这个关注项。

审核时建议记录来源角色：

- `genetic_evidence`
- `screening_requirement`
- `breed_context`
- `veterinary_reference`
- `peer_reviewed_study`
- `owner_care_context`

当前 Prisma fixture 暂未单独存储 source role；在结构升级前，可先写入 source note。

## 小程序来源展示规则

1. 用户展开疾病卡片后，来源列表仍默认折叠。
2. 来源展示优先级：
   - Tier A 核心来源。
   - 犬种权威来源。
   - 兽医或研究来源。
3. 小程序每个关注项优先展示 2-3 条最有代表性的来源；后端可以保存更多来源用于审核。
4. 来源类型用中文标签：
   - `OFA/CHIC 健康筛查资料`
   - `犬种俱乐部资料`
   - `兽医/研究机构资料`
5. 页面必须保留免责声明：内容为科普资料，不替代兽医诊断。

## 审核表模板

新增或修改导入数据前，先使用此表完成审核。

| 品种 | 候选关注项 | 关注类型 | 当前状态 | 建议分级 | 是否进入第一版 | Tier A 来源 | Tier B 来源 | Tier C 来源 | 文案边界 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 示例 | 示例关注项 | genetic / screening / owner-management | 未收录 | 建议了解 | 是 | OMIA / OFA / IPFD | 犬种俱乐部 | 兽医/论文 | 不替代诊断；不暗示必然患病 |

## 复核节奏

- 每条来源都记录访问日期。
- 生产迁移前复核核心来源链接。
- 已发布犬种内容至少每年复核一次；来源页面更新时提前复核。
- 如果核心来源失效，必须先替换来源再发布新数据；已发布内容应标记为需要复核。

## 生产准入门槛

生产导入前必须满足：

1. 犬种审核表已确认。
2. 每个发布项都有公开来源，并满足对应来源组合要求。
3. `npm run validate:breed-health-risk-sources` 通过。
4. 本地接口验证返回项数、分级和来源数量符合预期。
5. 微信开发者工具手动验证默认折叠、分级标签颜色、来源披露和免责声明。
