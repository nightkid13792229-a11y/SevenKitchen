# 定制食谱 · 顾客自助单端到端验收

**日期：** 2026-10-21  
**环境：** 体验版 `2026.10.21.11`；生产后端；`multiRecipeEnabled=true`  
**目的：** 在不改代码的前提下，把顾客自助单从下单、设计、交付到售后走一遍。

## 测试前置

- 使用一只测试狗；
- 准备一笔可退款的测试订单；
- 2 份订单应付：原价 600，5% 优惠后 **570 元**；
- 5 份订单应付：原价 1500，12% 优惠后 **1320 元**；
- 2/5 份预计交付：**2 个工作日**；
- 测试完成后从后台补退款/取消退款。

## 验收记录

每项记录：订单号 / 页面 / 实际结果 / 截图 / 是否阻塞。

### A. 顾客填写与下单（2 份）

- [ ] 从首页进入「食谱定制」；
- [ ] 选择测试狗；
- [ ] 进入时没有空白重填，能恢复上次草稿（如有）；
- [ ] 选择 2 份；
- [ ] 主蛋白选择「营养师配」或「自己选 2 种」，数量不匹配时不能提交；
- [ ] 价格显示：原价 600、优惠 60、应付 570；
- [ ] 交期显示 2 个工作日；
- [ ] 点「确认订单」后，订单创建成功但未支付；
- [ ] 返回定制页，填写内容仍在，顶部有待付款单；
- [ ] 再次进入，草稿恢复；
- [ ] 完成微信支付。

### B. 后台订单

- [ ] 后台订单列表出现该订单，份数 2、金额 570；
- [ ] 订单详情显示份数、原价、优惠、应付、价格快照；
- [ ] 订单来源显示为顾客自助；
- [ ] 后台不能把该单误标为线下收款单；
- [ ] 设计器入口显示“共 2 份，已设计 0 份”。

### C. 设计

- [ ] 从订单进入设计器，显示“共 2 份 / 已设计 0 份”；
- [ ] 设计第 1 份并发布；
- [ ] 回订单页，显示“已设计 1 份”；
- [ ] 设计第 2 份并发布；
- [ ] 显示“已设计 2 份”；
- [ ] 后台批量交付按钮在未选满 2 份时不可点。

### D. 一次性交付

- [ ] 勾选恰好 2 份，点「一次性交付 2 份」；
- [ ] 后台提示交付成功；
- [ ] 订单状态变为已交付；
- [ ] 顾客只收到一条交付通知；
- [ ] 通知能打开订单/食谱。

### E. 顾客查看

- [ ] 顾客订单详情显示“本次共交付 2 份”；
- [ ] 显示两张食谱卡，名称/封面正确；
- [ ] 每张卡能进入自己的食谱详情；
- [ ] 每份食谱的采购与制作内容不串；
- [ ] 旧单份订单仍显示原来的单份卡。

### F. 确认收到

- [ ] 顾客点一次「确认收到」；
- [ ] 整单完成，不是只完成一份；
- [ ] 重复点击提示“已确认”，不重复写时间；
- [ ] 后台自动完成时间/状态正确。

### G. 按份售后

- [ ] 顾客对第 1 份点「继续调整」；
- [ ] 页面默认选中第 1 份；
- [ ] 可以再勾选第 2 份；
- [ ] 每份可以填不同诉求；
- [ ] 未选任何份不能提交；
- [ ] 一次提交只消耗 1 次免费调整；
- [ ] 后台售后单显示“涉及 2 份”及每份诉求。

### H. 重新交付

- [ ] 后台对第 1 份执行「按选中份重新交付」；
- [ ] 顾客看到 2 份仍在；
- [ ] 只有第 1 份内容更新；
- [ ] 第 2 份内容未被改动；
- [ ] 只发一次通知。

### I. 取消/退款

- [ ] 后台对测试订单取消；
- [ ] 已付款订单先退款再取消；
- [ ] 退款状态显示成功/处理中；
- [ ] 订单取消后释放 5 份产能（2 份订单释放 2 份）；
- [ ] 顾客侧状态显示已取消。

### J. 5 份回归

- [ ] 另建 5 份订单，金额 1320；
- [ ] 后台可以一次交付 5 份；
- [ ] 顾客看到 5 张卡；
- [ ] 5 份订单占 5 份产能；
- [ ] 不出现“名额已满”以外的异常。
