# 订单绑定食谱设计验收清单

日期：2026-10-22  
状态：实施完成，待真实账号完整验收

## 1. 订单工作台

- [ ] 从 Foxy 定制订单点「开始设计/继续设计」，进入 `/order-design/CR...`。
- [ ] 顶部显示订单号、Foxy、本单 2 份、已就绪 X/2。
- [ ] 参考爱犬锁定，无「更换参考爱犬」。
- [ ] 2 个槽位可分别新建、打开、移除。

## 2. 模板选择

- [ ] 工作台点「从已有食谱开始」，能搜索橱窗和定制食谱。
- [ ] 选择「十字花科全谷物三文鱼鸡肉」后生成新草稿。
- [ ] 原食谱不被修改。
- [ ] 模板阶段与 Foxy 不一致时只提示，仍可继续。
- [ ] 同一模板可用于第二份，不会被禁止。

## 3. 待提交

- [ ] 管理员在编辑页点「加入本单待提交」后，返回工作台显示 1/2。
- [ ] 顾客端看不到第一份，未收到通知。
- [ ] 员工不能加入待提交，只看到等待管理员提示。

## 4. 最终交付

- [ ] 第二份加入后显示 2/2。
- [ ] 管理员点「提交本单并交付」，订单变为已交付。
- [ ] 顾客收到一条通知。
- [ ] 顾客端看到两份不同名称的食谱。
- [ ] 重复提交不重复交付/通知。
- [ ] 新流程订单的订单页旧「一次性交付」入口被隐藏/拒绝。

## 5. 产品线模式

- [ ] 从食谱设计主入口新建系列，不要求订单/狗狗。
- [ ] 没有待提交仓库、订单进度和最终交付按钮。
- [ ] ORDER 系列不出现在产品线主列表。

## 6. 存量订单

- [ ] 无槽位进行中订单仍可用旧订单页交付。
- [ ] 有槽位的新流程订单不能绕过工作台直接交付。
