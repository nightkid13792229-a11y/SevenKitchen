# 定制订单顾客端验收（2026-10-23）

环境：本地后端 `127.0.0.1:3011` + 微信开发者工具模拟器 + 本地测试订单。

## 已走链路

1. 创建本地代客订单（1 份，已付款）；
2. 从模板创建订单设计；
3. 补齐封面、标题、制作步骤、补剂用量；
4. 加入本单待提交；
5. 整批最终交付；
6. 顾客订单列表 → 订单详情 → 专属食谱 → 采购与制作；
7. 顾客提交售后（调整食谱）；
8. 后台受理、重新打开设计、修改步骤、重新入仓；
9. 按选中份重新交付；
10. 售后完成；
11. 顾客查看第 3 版交付。

## 顾客端发现并修复的问题

- 订单列表三个按钮在窄屏溢出、重叠；
- 已交付订单仍显示不可用的「取消订单」；
- 订单详情进度节点说明文字互相挤压；
- 订单详情底部操作栏文字被压成多行；
- 交付页底部 CTA 遮住内容；
- 采购页「制备方法」列显示 UUID；
- 单份订单显示无意义的「共交付 1 份 / 当前第 1 份」；
- 售后页一进入就显示「请至少选择一份」红字；
- 单份售后还要手动勾选唯一一份食谱；
- 售后处理中提示重复出现；
- 附件标题在深色背景上对比度不足。

## 修复后效果

- 订单按钮主操作独占一行，其余按钮并排；
- 进度说明集中到时间轴下方一行；
- 单份订单不再显示份数选择；
- 采购页制备方法显示「去油 / 去壳 / 去皮 / 生重」等中文；
- 制作步骤显示在「怎么做」；
- 售后单份自动选中唯一食谱；
- 售后页不再提前报错。

## 仍需人工确认

- 微信真机订阅消息是否实际到达；
- 生产环境真实微信支付；
- 多份订单（2 份以上）的顾客端批量选择、逐份改稿和只重交选中份；
- 不同机型/字体大小下的截图回归。
