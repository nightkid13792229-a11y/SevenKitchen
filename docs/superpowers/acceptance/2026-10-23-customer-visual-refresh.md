# 食谱定制顾客端视觉统一与多份订单验收（2026-10-23）

环境：本地后端 + 微信开发者工具模拟器 + 本地测试订单。
方向：温暖私厨 —— 米白纸张底、深森林绿、黄铜金。

## 视觉统一

- 订单列表：品牌页头、衬线大标题、狗名主视觉、金色主操作；
- 订单详情：深绿状态卡、金色区块标识、浅色信息卡；
- 交付页：深绿封面卡 + 浅米色内容页，金色主操作；
- 采购与制作：深绿标题卡、浅色食材表、金色步骤序号；
- 售后：浅色页面、深绿配额条、金色提交按钮；
- 定制首页 / 确认页：同步米白底、深绿主色和衬线标题。

## 多份订单验收

测试订单：CR202610230224，3 份。

1. 后台整批交付 3 份；
2. 顾客端订单详情显示 3 张食谱卡，顺序为第 1/2/3 份；
3. 顾客提交售后，勾选第 1 份和第 3 份；
4. 后台只修改第 3 份并重新入仓；
5. 按选中份重新交付第 1、3 份；
6. 第 2 份不重新生成，保持原交付；
7. 售后完成。

修复：交付明细新增 `sort_order`，按设计槽位创建时间回填旧数据，解决「第 3/1/2 份」乱序。
