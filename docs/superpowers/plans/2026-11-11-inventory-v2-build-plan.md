## 二、关键设计决策：盘点"行 + 明细点"

### 2.1 不动的

- `InventoryStocktakeLine` 仍是"一个原料一行"，`@@unique([stocktakeId, ingredientId])` **保留**；
- 账面 `expectedQuantityG`、差异 `deltaG`、容差判断、入账流水**逻辑不变**；
- 现有盘点单、历史记录**全部可读**。

### 2.2 新增

新表 `InventoryStocktakePortion`（盘点明细点）：

| 字段 | 含义 |
|---|---|
| `id` | 主键 |
| `lineId` | 属于哪一行（原料） |
| `procurementSkuId` | 商品（食材才有；补剂/包材为空） |
| `locationLabel` | 位置/批次，自由文本（"冰柜 2"、"第二批"） |
| `countedQuantityG` | 该点实盘；空 = 未盘 |
| `createdAt` | 录入时间 |

规则：

- 开单时：**每个原料至少生成一个明细点**（食材按每个在用商品各一个；补剂/包材一个、商品为空）。
- 员工录入的是明细点；一行的 `countedQuantityG` = 该行所有非空明细点之和（由服务端计算，客户端不能直接写行）。
- 新增"再记一处"= 追加一个明细点（同商品或同原料、不同位置）。
- 未填写任何明细点的行 = 未盘，与现在一致。
- 旧草稿（没有明细点）仍可提交：回退到行级 `countedQuantityG`。

### 2.3 为什么这样做

- **迁移是加表，不是改表**：不需要重建历史数据，出问题可直接回退。
- 差异始终只有一个（原料级），不需要在核对页做二次合并，账不会重复。
- 商品"没有独立余额"这个事实不被破坏：明细点只记录盘点事实。

## 三、接口变更

| 接口 | 变更 |
|---|---|
| `GET /staff/inventory/stocktakes/draft` | 行内返回 `portions[]`（商品名、位置、实盘） |
| `PATCH .../stocktakes/:id/lines` | 改为提交明细点：`{ portions: [{ id?, lineId, countedQuantityG }], addPortions?: [{ lineId, locationLabel }] }`；兼容旧的 `lines[]`（行级） |
| `GET .../stocktakes/:id/preview` | 行内返回 `portions[]` 与 `countedTotalG`；每行判定依据（容差内/超容差） |
| 新增 `POST .../stocktakes/:id/portions` | 追加一个明细点（选位置/商品） |
| 新增 `DELETE .../stocktakes/:id/portions/:portionId` | 删除一个明细点（仅草稿） |
| 新增 `GET /staff/inventory/adjustments` | 员工查看自己的领用/报废记录（含复核状态、驳回原因） |
| 新增 `GET /staff/inventory/ingredients/:id` | 详情页聚合（余额、阈值、在途、近 30 天用量、最近 5 条流水） |

## 四、改动清单

### 后端

1. 迁移：新增 `inventory_stocktake_portion`。
2. `startStocktake`：按食材商品生成明细点；补剂/包材一个点。
3. `saveStocktakeLines` → 明细点写入 + 行汇总。
4. `previewStocktake` / `submitStocktake` / `reviewStocktake`：输出明细点；汇总值入账（仍是每原料一条流水）。
5. 新增明细点增删接口、员工领用记录、详情聚合。
6. 去掉 `usesInventoryForRequirement` 的类型判断（全部抵扣）；`includeDaily` 死分支清理；排序去掉策略。
7. 单测：汇总、容差、驳回冲回、日采抵扣、在途抵扣。

### 后台（admin-web）

8. 原料表单去掉采购类型；列表去掉标签；能力表去掉开关。
9. 库存列表排序改按状态。

### 小程序

10. 盘点页：按行展示明细点、加"再记一处"、自动保存、搜索/未盘筛选。
11. 核对页：全部差异 + 每行明细点 + 判定依据 + "此项不调" + 按钮改"提交盘点"。
12. 首页：一个主动作、合并状态、显式"记录"入口、去掉"设安全线"。
13. 领用/报废：改名、入口回卡片、记录页。
14. 补货：撤抽屉，补货页顶部"缺什么"。
