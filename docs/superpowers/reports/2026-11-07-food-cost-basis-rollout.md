# 食材成本口径归位 · 上线记录（2026-11-07）

对应设计：`docs/superpowers/specs/2026-11-07-food-cost-basis-and-ai-closing-design.md`
对应计划：`docs/superpowers/plans/2026-11-07-food-cost-basis-and-ai-closing.md`

## 一、这次改了什么（一句话）

食材的「每克多少钱」变成**一个数**，由采购结算写入；
采购口径（一件多少克、一件多少钱）整体回到采购商品；
新建食材必须补一条带价的采购商品，它的价用来初始化那个数。

## 二、代码改动

### 数据
- 新表 `ingredient_price_history`（成本流水）：来源四选一 ——
  建档初始化 / 报销回写 / 手工改价 / 口径迁移。
- 迁移 `20261107180000_food_cost_basis`：
  备份 `ingredient_food_cost_backup_20261107` → 建表 → 折算（旧成本 ÷ 旧换算，换算归 1）→ 留痕。

### 写入（三个入口，全部留痕）
| 入口 | 何时 | 规则 |
|---|---|---|
| 采购商品创建 | 建档 / 员工端新增 / 批量导入 | 成本为 0 且有价 → 用「价 ÷ 净含量」初始化；**只补空，不覆盖** |
| 采购报销 | 报销单提交 | 按实付覆盖；三道闸不变（0 元/5 倍/8%） |
| 库存页改成本 | 人工 | 直接写，留操作人 |

### 读（只有一个）
`Ingredient.getUnitCost()` = 成本 ÷ 换算（食材换算恒为 1，即「元/g」）。

### 采购
- 采购记录的数量折算改为**按采购商品的换算**（原来按原料档案，多规格时本来就错）。
- 没有采购商品时：退回基准单位并标记 `needsProcurementSku`，不再假装「买几袋」。

### 发布
- 产品线发布：0 成本食材**阻断**并点名。
- 订单「加入待提交」：同一情况只**提醒**。
- 老「食谱管理」的发布接口：同一道判断。

### 后台界面
- 原料页（食材）：只读「当前成本」卡 + 成本历史弹窗；保存时**不再下发**成本与换算。
- AI 添加原料：授权写入后出现「补一条采购商品」卡片（必填名称/单位/净含量/单价）。
- 原料列表：可筛「只看待补采购商品」，行上打标。
- 库存页：「改成本」，单位按基准单位显示、6 位精度。


## 四、上线后要盯的三件事

1. 生产库跑一次对账脚本，①②必须都是 0。
2. 「待补采购商品」的清单（③）交给运营补商品，这批原料在补之前不能发布到产品线。
3. 第一笔采购报销后，去原料页看成本历史是否出现「采购报销回写」一条。

## 五、复核修正（2026-11-07 晚）

一轮独立复核在合并前发现 3 个致命问题，已修：

1. **产品线发布门槛从不生效**：草稿里的原料是数据库行，没有 `getUnitCost()`，
   成本判断永远拿到空值而静默跳过 → 改为直接读价格与换算两列。
2. **整系列发布绕过成本闸**：真正的「发布产品线」按钮走的是另一条路，
   已补同一道成本检查。
3. **AI 收尾的保存按钮永远禁用**：状态判断里先要求「已有采购商品」，
   而这一屏本身就是新建 → 改为只看「净含量 + 这件多少钱」。

另外修了 7 处：采购折算改用员工实际选中的商品、有价食材补记来源、
对账脚本真正比对新旧、期初库存换算、后台提示文案、库存页 5 倍闸、建档换算校验。

## 五之二、第二轮回合（同日，独立复核后）

第二轮复核确认上一轮 7 条已修好，但指出一个更根本的问题：
**「食材换算 = 1」这个数被好几处当成了「一件多少克」**。
凡是「采购商品没填换算 → 退回原料换算」的地方，退回来的都是 1，
于是「2 盒」会被记成「2 克」，报销再把 19.95 元/g 写进档案，差 500 倍且不报错。

已修四处：

1. **兜底收紧**：选了商品但商品没填换算 → 直接报错，不再退回 1。
   只有「这行没有商品」或「商品已被删除」才退回原料换算。
2. **建/改采购商品强制带换算**：没填就拒绝保存（这是上面那类的根因）。
3. **订单截图导入**不再退回原料换算，只认商品自己的净含量。
4. **报销**遇到「老记录没有实际克数 + 食材换算=1」时不再猜，直接跳过这条调价。

对账脚本新增一项上线前体检：`[②c] 启用中但没填换算的采购商品`，必须为 0。

## 六、已知边界

- 库存列表不返回商品明细，所以「折回一件多少钱」的预览暂时缺失（食材换算恒为 1，本身也没有意义）。
- AI 收尾卡片暂未接「商品截图识别」（后端接口已通），需要时补一行调用。
- 成本拦截只在调用方显式传成本时生效：新入口若忘了传，拦截会静默失效。
