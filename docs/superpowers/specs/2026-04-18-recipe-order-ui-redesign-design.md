# 订购成品页 UI 与交互重构设计

## 背景

本次重构只覆盖小程序端 `pages/recipe-order/index` 订购成品页，不调整确认订单页、订单详情页、后台订单页和后端业务流程。

现有订购成品页已经具备选择狗狗、饭量参考、默认周期、自定义分装、原料采购方案、原料清单、产品介绍和底部价格栏等能力，但整体仍偏“功能堆叠”。本次目标是把它重构为一张顾客能顺畅完成购买决策的成品订购页。

## 目标

- 顾客进入页面后，先明确“我正在购买哪款成品鲜食”。
- 顾客能理解饭量只是喂食参考，购买总量由分装方案汇总决定。
- 顾客能快速采用 7 天、15 天、30 天默认分装，也能清楚知道可以自定义分装。
- 顾客能看到三档原料采购方案，并理解方案会影响原料清单和价格。
- 顾客能看到紧凑、清晰、突出采购渠道的原料清单。
- 产品说明图片重点解释加工方式、保存/烹饪、制作/发货节奏，并紧跟分装物流说明。
- 底部固定价格栏在用户调整分装或原料方案时持续反馈价格、袋均价、规格和袋数。

## 非目标

- 不在本阶段重构确认订单页。
- 不在本阶段改造订单、采购、生产、库存或结算后端逻辑。
- 不在订购页增加饭量快速调整功能。
- 不把管理员备注或特殊加料作为订购页入口。
- 不把产品说明区做成很长的营销页。

## 页面整体结构

采用“购买决策型”结构。

页面顺序：

1. 产品首屏
2. 饭量参考
3. 购买周期与分装
4. 原料采购方案
5. 原料清单
6. 产品说明图片
7. 分装及物流说明
8. 底部固定价格栏

### 1. 产品首屏

首屏用于建立购买上下文和信任感，而不是直接进入表单。

首屏展示：

- 食谱或产品图片
- 食谱名称
- 适用生命阶段或健康标签
- 食谱能量密度
- 选择狗狗入口
- 已选狗狗后的关键信息摘要
- 当前推荐饭量、默认周期和价格状态摘要

未选择狗狗时，首屏提示：

```text
请选择狗狗后查看饭量和价格
```

### 2. 饭量参考

模块标题使用：

```text
饭量参考
```

常显内容：

- 每日建议饭量
- 每日餐数
- 系统建议每餐参考量

提供可展开入口：

```text
查看计算过程
```

展开后以通俗步骤展示：

- 狗狗体重和体态
- 每日能量需求
- 零食热量扣除
- 鲜食热量
- 食谱热量密度
- 推算出的每日饭量

模块必须明确说明：

```text
饭量为喂食参考，实际购买总量由下方分装方案汇总决定。
```

### 3. 购买周期与分装

采用“默认周期优先，明细可编辑”的方案，并强化自定义入口。

默认周期：

- 7 天
- 15 天
- 30 天

用户选择周期后，系统按狗狗每日饭量和每日餐数生成默认分装方案。

分装区域必须展示：

- 当前分装明细
- 总净重
- 总袋数
- 预计可喂天数
- 是否满足最低 1000g 下单要求

文案规则：

```text
当前分装方案
系统已按 15 天生成，您可以按冷冻空间或每餐习惯修改规格。
```

入口按钮：

```text
修改分装方案
```

标签：

```text
可自定义
```

展开编辑器后，每行包含：

- 每袋克数
- 袋数
- 删除

新增按钮：

```text
+ 添加另一种规格
```

底部提示：

```text
订单总量由分装明细自动汇总，满 1000g 可下单。
```

### 4. 原料采购方案

采用三张方案卡片。

三档方案：

1. 尽量有机来源
2. 尽量山姆、盒马、沃集鲜
3. 生鲜批发商

默认选中：

```text
尽量山姆、盒马、沃集鲜
```

每张卡片展示：

- 方案名称
- 方案说明
- 当前预计订单价格
- 选中状态

三张卡片需要让用户明确理解：

- 不同方案代表不同采购来源。
- 方案会影响原料清单。
- 方案会影响订单价格。

如果当前测试库或业务数据导致三档价格暂时一样，不视为错误。

### 5. 原料清单

原料清单位于原料采购方案之后，随所选采购方案刷新。

默认展示摘要态，不完全展开。

摘要态展示：

- 当前采购方案
- 食材数量
- 补剂数量
- 食品净重
- 前 2 到 3 个主要食材预览

摘要示例：

```text
牛里脊、糙米、南瓜等 8 种食材
8种食材 · 3种补剂 · 净重 1.11kg
```

展开按钮：

```text
查看全部 11 种原料
```

展开态按组展示：

- 主要食材
- 营养补剂

列表采用紧凑四列：

```text
原料名称 → 规格 → 采购渠道 → 用量
```

视觉规则：

- 原料名称加粗。
- 规格使用普通辅助文字。
- 采购渠道使用醒目标签。
- 用量靠右展示。
- 食材渠道标签使用绿色系。
- 默认补剂渠道使用低饱和蓝灰色。

示例：

```text
牛里脊   冷鲜牛肉   山姆     458g
糙米     有机糙米   盒马     229g
南瓜     贝贝南瓜   沃集鲜   114g
```

若部分原料暂无替代来源，展示提示：

```text
当前部分原料暂无替代来源，系统已按可用来源匹配。
```

### 6. 产品说明图片

产品说明区位于原料清单之后。

不做泛泛的营销介绍，只解释顾客下单前最需要理解的制作、保存和发货规则。

建议支持三张主说明图：

1. 加工方式说明图
2. 保存方法、保质期和烹饪说明图
3. 当日采购当日制作，冷冻 24 小时后发货说明图

#### 加工方式说明

主题：

```text
为什么要把所有原料打碎？
```

说明点：

- 让不同原料充分混合。
- 减少挑食，避免只挑肉不吃菜或补剂。
- 让每袋营养更均匀。
- 更适合冷冻、解冻和复热后的状态稳定。

#### 保存方法、保质期和烹饪说明

说明点：

- 冷冻保存方式。
- 冷藏保存时限。
- 开袋后尽快食用。
- 喂食前如何解冻、复温或加热。
- 不建议反复冷冻解冻。

#### 当日采购当日制作

说明点：

- 根据目标制作日期采购。
- 当日制作。
- 制作完成后分装。
- 冷冻 24 小时。
- 再安排发货，保证运输稳定。

### 7. 分装及物流说明

产品说明图后紧跟分装及物流说明。

建议作为单独图片或说明卡：

- 按袋真空分装。
- 每袋贴标签。
- 支持自定义规格。
- 冷冻包材。
- 默认顺丰生鲜或冷链配送。
- 预计发货和到货逻辑。

### 8. 底部固定价格栏

底部价格栏固定悬浮。

价格和说明紧贴立即下单按钮左侧。

统一使用“袋”，不使用“餐”。

#### 单一规格

```text
¥204.55
¥22.73/袋 · 123g × 9袋
立即下单
```

#### 多规格

```text
¥356.20
均价 ¥17.81/袋 · 多规格共 20袋
立即下单
```

#### 未满 1000g

```text
未满 1000g
当前 860g，暂不可下单
立即下单
```

按钮禁用。

#### 价格计算中

```text
计算中
价格生成后可下单
立即下单
```

按钮禁用。

## 异常状态

### 未选择狗狗

首屏摘要显示：

```text
请选择狗狗后查看饭量和价格
```

底部按钮禁用：

```text
请选择狗狗
```

### 饭量或价格计算中

- 模块内显示轻量加载状态。
- 底部栏显示 `计算中`。
- 按钮禁用，避免用旧价格下单。

### 订单总量低于 1000g

分装模块显示：

```text
当前 860g，最低订购量为 1000g
```

底部栏显示：

```text
未满 1000g，暂不可下单
```

按钮禁用。

### 三档采购方案当前价格一样

- 不作为错误。
- 原料清单展示可用来源提示。
- 价格正常展示。

提示文案：

```text
当前部分原料暂无替代来源，系统已按可用来源匹配。
```

### 价格计算失败

底部栏显示：

```text
价格暂未生成
```

模块内提示：

```text
请稍后重试或切换分装/采购方案
```

按钮禁用。

### 没有原料清单

原料清单模块显示：

```text
当前食谱暂无可展示原料，请联系客服确认
```

如果价格能算出，仍可展示价格；如果价格不能算出，则进入价格失败状态。

### 生命阶段不匹配

保留提醒，文案调整为：

```text
该食谱可能不完全适合当前生命阶段，建议确认后再下单。
```

用户点击：

```text
我已知晓，继续订购
```

之后再展示完整购买配置。

## 数据与接口依赖

本阶段优先复用现有数据结构：

- 食谱详情
- 狗狗档案
- 饭量计算结果
- 价格预览结果
- 价格快照 ID
- 分装明细 `packagePlan`
- 原料采购方案 `ingredientSourcePlan`
- 原料成本明细 `ingredientDetails`
- 全局配置中的包装示例图和物流图

若后续需要让管理员上传产品说明图，建议在全局配置中新增图片 URL 配置：

- 加工方式说明图
- 保存/保质期/烹饪说明图
- 当日采购当日制作说明图
- 分装及物流说明图

没有配置图片时，小程序使用文字说明占位，不阻断下单。

## 测试与验收

需要覆盖的验收点：

- 未选择狗狗时不能下单。
- 选择狗狗后显示饭量参考。
- 饭量计算过程可展开。
- 默认 7/15/30 天能生成分装方案。
- 修改分装后总净重、总袋数、袋均价和底部价格栏同步刷新。
- 多规格分装时底部显示 `均价 ¥X/袋 · 多规格共 N袋`。
- 低于 1000g 时立即下单按钮禁用。
- 三张原料采购方案卡片可切换。
- 切换采购方案后价格预览和原料清单刷新。
- 原料清单默认摘要展示，展开后按四列紧凑展示。
- 原料清单中采购渠道标签突出。
- 产品说明区按确认的三类主题展示。
- 价格计算失败时不允许下单。

## 实施边界

实施时优先改造：

- `miniapp/src/pages/recipe-order/index.vue`
- `miniapp/src/pages/recipe-order.regression.spec.ts`
- 必要时补充小型展示 helper

不在本阶段主动修改：

- 确认订单页
- 订单详情页
- 后端订单、采购、生产、库存逻辑
- 管理后台
