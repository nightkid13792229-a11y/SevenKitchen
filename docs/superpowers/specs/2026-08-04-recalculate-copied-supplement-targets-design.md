# 复制食谱补剂目标重算设计

## 目标

修复复制食谱系列时补剂目标丢失的问题，并让现有“小满”草稿的补剂目标依据当前草稿重算，而不是沿用模板食谱的历史值。

## 范围与边界

- 目标草稿：`兔里脊大米土豆(小满)` 的低能量需求成年犬阶段草稿。
- 不修改食材、补剂品种、用量、营养档案、草稿状态或发布状态。
- 补剂目标可为多个营养素；不将多目标结果压缩成单个旧字段。
- 生产数据更新先使用同一评估逻辑生成只读预览；仅在目标草稿仍处于预期版本时写入。

## 数据流

1. 读取当前草稿、其标准营养目标和所有原料营养档案。
2. 计算完整草稿营养评估。
3. 对每个补剂分别移除后重算；仅保留移除后会造成营养不足、且该补剂对该营养素有正向贡献的目标。
4. 将贡献量按当前草稿总重量折算为每公斤目标值，并保留目标字段路径、标签、单位和值。
5. 正式食谱持久化 `supplementTargets` 使用此完整目标列表；设计草稿兼容字段仅保存主要目标，避免旧校验阻塞。

## 复制流程修复

从正式食谱复制为设计草稿时，读取 `RecipeItem.supplementTargets`。对于有目标的补剂行，选取第一个完整目标映射到设计草稿兼容字段；正式发布时仍基于当前草稿重新生成完整多目标数据，因而不会依赖模板的旧值。

## 验证

- 单元测试覆盖：新版 `supplementTargets` 复制后不为空；多目标补剂保留完整列表；当前草稿重算结果不改变原料或用量。
- 生产回填后重新读取目标草稿，确认每条补剂至少有兼容目标字段；重新运行评估，确认当前配方仍合规。
