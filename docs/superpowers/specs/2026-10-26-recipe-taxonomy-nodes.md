# 需求分类节点词典（第一版）

- 日期：2026-10-26
- 用途：`2026-10-26-product-line-and-recipe-naming-design.md` 第 4 节的节点全集
- 规则：**所有归属只挂叶子节点**；父节点只做汇总；每个节点必须有能用来判断的定义

## 一、主蛋白

判定口径：**配方中占比第一、且 ≥25% 的动物蛋白**（生重，不含补剂与包装）。同一道菜只能有一个主蛋白。

### 一级

| 节点 | 定义 |
|---|---|
| 畜类 | 占比第一的动物蛋白来自陆生哺乳类家畜 |
| 禽类 | 占比第一的动物蛋白来自禽类 |
| 鱼类 | 占比第一的动物蛋白来自鱼 |

### 畜类

| 节点 | 定义 |
|---|---|
| 猪 | 主蛋白是猪肉 |
| 牛 | 主蛋白是牛肉 |
| 羊 | 主蛋白是羊肉 |
| 兔 | 主蛋白是兔肉 |
| 鹿 | 主蛋白是鹿肉 |

### 禽类

| 节点 | 定义 |
|---|---|
| 鸡 | 主蛋白是鸡肉 |
| 鸭 | 主蛋白是鸭肉 |
| 火鸡 | 主蛋白是火鸡肉 |
| 鹅 | 主蛋白是鹅肉 |
| 鹌鹑 | 主蛋白是鹌鹑肉 |
| 鸽 | 主蛋白是鸽肉 |

### 鱼类

| 节点 | 定义 |
|---|---|
| 三文鱼 | 主蛋白是三文鱼 |
| 鳕鱼 | 主蛋白是鳕鱼 |
| 青花鱼 | 主蛋白是青花鱼（鲭鱼） |
| 鲈鱼 | 主蛋白是鲈鱼 |
| 沙丁鱼 | 主蛋白是沙丁鱼 |
| 龙利鱼 | 主蛋白是龙利鱼 |

> 虾、蟹、贝、生蚝等非鱼类水产**不进主蛋白分类**，只作辅料。

## 二、健康需求

叶子只能是**症状**或**疾病**。不放"支持""调理""恢复期"这类干预词或阶段词。一道菜可以没有健康需求。

### 消化

| 节点 | 定义 |
|---|---|
| 软便 | 主人反馈排便不成形、偏稀，但未确诊疾病 |
| 便秘 | 主人反馈排便间隔变长、粪便干硬 |
| 胀气 | 主人反馈腹部胀、排气多 |
| 呕吐 | 主人反馈进食后偶发呕吐，但未确诊疾病 |
| 胰腺炎 | 已确诊或既往发作过胰腺炎 |
| 食物不耐受 | 对特定食材出现不良反应，但未达到过敏诊断 |
| 肝病 | 已确诊肝脏相关疾病 |
| 挑食 | 主人反馈进食意愿低、需要拌食才吃 |

### 皮肤毛发

| 节点 | 定义 |
|---|---|
| 瘙痒 | 主人反馈频繁抓挠、啃咬自己 |
| 脱毛 | 主人反馈非换毛季的异常掉毛 |
| 皮屑 | 主人反馈皮肤干燥、有皮屑 |
| 皮炎 | 已确诊皮肤炎症 |

### 骨关节

| 节点 | 定义 |
|---|---|
| 关节炎 | 已确诊关节炎症 |
| 髋关节发育不良 | 已确诊髋关节发育不良 |
| 骨质疏松 | 已确诊骨密度偏低 |

### 体重体态

| 节点 | 定义 |
|---|---|
| 超重 | 体况评分偏高但未达肥胖 |
| 肥胖 | 已达肥胖标准 |
| 消瘦 | 体况评分偏低、需要增重 |

### 肾脏泌尿

| 节点 | 定义 |
|---|---|
| 慢性肾病 | 已确诊慢性肾病 |
| 尿石症 | 已确诊或既往有尿路结石 |
| 尿路感染 | 已确诊或反复发生尿路感染 |

### 心脏

| 节点 | 定义 |
|---|---|
| 心脏病 | 已确诊心脏疾病 |
| 心衰 | 已确诊心力衰竭 |

### 口腔

| 节点 | 定义 |
|---|---|
| 牙结石 | 已观察到明显牙结石 |
| 口臭 | 主人反馈持续口臭 |
| 牙龈炎 | 已确诊牙龈炎症 |

### 免疫过敏

| 节点 | 定义 |
|---|---|
| 食物过敏 | 已确诊或高度怀疑食物过敏 |
| 免疫低下 | 已确诊免疫功能偏低 |

### 内分泌

| 节点 | 定义 |
|---|---|
| 糖尿病 | 已确诊糖尿病 |
| 甲减 | 已确诊甲状腺功能减退 |
| 甲亢 | 已确诊甲状腺功能亢进 |
| 库欣 | 已确诊肾上腺皮质功能亢进 |

### 老年认知

| 节点 | 定义 |
|---|---|
| 认知障碍 | 已确诊或明显出现老年认知退化表现 |

### 肿瘤

直接作为一级节点（系统与疾病同名，不再重复一层）：已确诊肿瘤。

### 血液代谢

| 节点 | 定义 |
|---|---|
| 贫血 | 已确诊贫血 |
| 脱水 | 存在脱水风险或已出现脱水 |

## 三、场景

| 节点 | 定义 |
|---|---|
| 日常主食 | 可作为长期主食，有明确主蛋白，不限定使用时机 |
| 初次尝试 | 面向第一次购买、需要低门槛小份试用的场景 |
| 换粮过渡 | 从干粮或其它食物切换到鲜食的过渡期使用 |
| 出行 | 需要便携、耐储存或分装携带的场景 |

## 四、季节

| 节点 | 定义 |
|---|---|
| 春 | 主要食材在春季供应 |
| 夏 | 主要食材在夏季供应 |
| 秋 | 主要食材在秋季供应 |
| 冬 | 主要食材在冬季供应 |
| 应季 | 跟随当季食材变化，不固定归属某个季节 |
| 换季敏感期 | 季节交替期间用于皮肤或肠胃波动的场景 |

## 五、工艺形态

第一版只启用「蒸煮鲜食」一支，其余节点建好但空置。

| 节点 | 定义 |
|---|---|
| 蒸煮鲜食 | 低温蒸煮熟制后冷冻配送（当前唯一在产形态） |
| 生食 | 未经热处理的生鲜配方 |
| 冻干 | 冷冻干燥成型 |
| 风干 | 低温风干成型 |
| 烘焙 | 烘烤成型 |

## 六、维护规则

1. **新增节点**：必须同时写定义，否则不允许保存。
2. **停用节点**：已归类的菜保留归属，节点在树里收起，不再接受新归类。
3. **删除节点**：只允许无归属、无子节点时执行。
4. **改名**：随时可改，历史归属自动跟随。
