## 一、账户（支出与收入的出处）

### 1.1 五个账户

| code | 显示名 | 说明 |
|---|---|---|
| `MERCHANT` | 微信商户号 | 线上收款自动落这里；支出时也可选（老板要求保留） |
| `PERSONAL_WECHAT` | 我的微信 | 默认：补货、日常零花 |
| `PERSONAL_ALIPAY` | 我的支付宝 | |
| `PERSONAL_BANK` | 我的银行卡 | 默认：房租、社保这类走卡的 |
| `CASH` | 现金 | |

- 账户列表本期**固定这五个**，不做自建（老板确认够用）。
- 去掉 `payerType`（COMPANY/PERSONAL）这个概念：只记账户，不再算「谁垫的」——个体户不还自己，这个帽子没用。

### 1.2 哪些地方要记账户

| 场景 | 字段 | 默认 |
|---|---|---|
| 线上订单收款 | 不存字段，按 `MERCHANT` 推导 | — |
| 线下代客单收款 | `Order.offlinePaymentAccount` | 上次用的 |
| 补货/采购 | `PurchaseList.payerAccount` | 上次用的 |
| 固定费用模板 | `ExpenseTemplate.payerAccount` | `PERSONAL_BANK` |
| 固定费用账单 | `ExpenseBill.payerAccount`（从模板带，可改） | 模板值 |
| 账单付款 | `ExpenseBillPayment.payerAccount` | 账单值 |
| 手工记账 | `FinanceManualEntry.payerAccount` | 上次用的 |
| 线下退款 | `OrderOfflineRefund.payerAccount`（钱从哪退出去） | 上次用的 |

`SupplementOrder` / `CustomRecipeOrder` 的线下收款账户本期**不加**（量小，仍按渠道字段推导），记为已知限制。

## 二、类别字典（可编辑）

### 2.1 原则

- 新建表 `finance_category`，**所有支出类别都在这里**，不再用 Prisma 枚举写死。
- 记账时**输入即建**：打一个新名字保存，它就成为类别，下次出现在选项里。
- 输入框带**下拉提示已有类别**，打第一个字就筛，避免「设备 / 设备工具」这种同义重复。
- **改名影响历史**：记录按 `categoryId` 关联，改名后历史显示新名字。
- **删除 = 停用**：已被用过的类别不能删，只能停用或合并；合并时历史记录一起搬。
- **系统类别不可删**（可改名）：`食材`、`补剂`、`包材`、`快递`、`支付手续费`——补货、订单运费、手续费的钱必须有地方放。
- 不再有「其他」这个可选类别；报表里的「其他」是**显示层聚合**（前 7 类之外合并），不是记账选项。

### 2.2 初始种子

系统类别（`is_system = true`，不可删）：食材、补剂、包材、快递、支付手续费。
普通类别（可改可停）：房租、水电、宽带、工资、社保、税费、服务器/域名、设备工具、维修、工具、杂物、其它。

> 迁移时把现有枚举值全部种进去，并把历史 `ExpenseBill` / `ExpenseTemplate` / `FinanceManualEntry` 的枚举值回填成对应 `categoryId`。

### 2.3 关联改造

| 表 | 现在 | 改为 |
|---|---|---|
| `ExpenseBill` | `category FinanceExpenseCategory` | `categoryId`（保留旧列一版，读时兼容） |
| `ExpenseTemplate` | 同上 | `categoryId` |
| `FinanceManualEntry` | `category` / `incomeCategory` | 支出用 `categoryId`；收入仍用固定 `OTHER_INCOME` |
| 报销 `customFees` | `TOOLS/SUNDRIES/OTHER` | 映射到种子类别「工具 / 杂物 / 其它」 |

### 2.4 报表

- 支出汇总按 `categoryId` 分组，输出类别名（`label` 取类别当前名字）。
- 自动来源的分类映射：采购行类型 → 食材/补剂/包材；快递 → 快递；手续费 → 支付手续费；报销杂费 → 工具/杂物/其它。
- 显示前 7 类，其余合并为「其他」（仅显示层）。

## 三、页面要改的地方

1. **记一笔**：「这是什么」改成输入框 + 下拉提示 + 「新建『xxx』」；「谁付的钱」改成「从哪个账户出」五个账户。
2. **收支明细**：筛选项从「我垫的」改成「账户」；每行显示账户名；类别标签显示字典名。
3. **固定费用**：模板表单的类别改成同一个选择器（可新建）；账户选择；账单付款可改账户。
4. **代客下单**：线下收款选账户。
5. **订单详情**：登记线下退款选「退到哪个账户」。
6. **新增「费用类别」管理页**（放在固定费用页右上角入口）：列表、改名、合并、停用；系统类别标「系统」且不能删。

## 四、迁移与兼容

- 新增迁移：`finance_category` 表；`category_id` 列（3 张表）；`payer_account` 列（6 张表）。
- 回填：枚举 → `category_id`；老数据的 `payer_type` → `PERSONAL_WECHAT`（有则保留），`COMPANY` → `MERCHANT`。
- 旧枚举列**保留一版**，新写入不再使用，下一版删除。
- 线上老小程序不受影响（不调财务接口）；后台旧财务已下线。

## 五、验收要点

1. 记一笔时打「维修」，保存后下次选项里有「维修」。
2. 在类别管理里把「维修」改成「维修保养」，历史记录跟着变。
3. 把「维修保养」合并进「设备工具」，历史记录一起搬过去，报表合并。
4. 系统类别「食材」不能删，但能改名。
5. 五处账户选择都能记住上次用的值。
6. 明细能按单个账户筛，比如只看「我的支付宝」。
