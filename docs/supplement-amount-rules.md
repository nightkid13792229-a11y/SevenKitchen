# 补剂用量口径规则

本文档用于统一 SevenKitchen 中补剂类原料在 DIY 制作单、下单预览、订单详情、采购单、生产单中的计算和展示口径。

## 核心原则

补剂损耗只用于采购和备料，不用于放大用户或厨房实际添加到食谱里的补剂量。

简化成一句话：

- 实际添加量：不加补剂损耗。
- 采购/备料量：加补剂损耗。

## 数据来源

补剂浓度按以下顺序解析：

1. `Ingredient.nutritionProfile`
2. 迁移期兜底：`Ingredient.properties.active_nutrients`

食谱中的补剂营养目标来自食谱原料项：

- `nutrientTargetKey`
- `nutrientTargetValue`

展示单位来自原料字段：

- `displayUnit`
- `unit_display_label`
- `unitDisplayLabel`
- 兜底 `unit`

## 统一公式

```text
营养素总需求 = nutrientTargetValue × 基准重量kg
理论添加量 = 营养素总需求 ÷ 补剂浓度
采购/备料量 = 理论添加量 × 补剂损耗率
```

`理论添加量` 是用户或厨房真正应该添加的量。`采购/备料量` 只用于采购、库存预留和成本覆盖。

## 场景口径表

| 场景 | 基准重量 | 展示或使用的量 | 是否加补剂损耗 |
| --- | --- | --- | --- |
| DIY 制作单 | 食材投料总重 | 理论添加量 | 否 |
| 下单页原料预览 | 订单成品净重 | `netAmount` | 否 |
| 订单详情 | 订单快照中的 `netAmount` | `netAmount` | 否 |
| 采购单 | 订单快照中的 `purchaseAmount` | `purchaseAmount` | 是 |
| 生产单/生产打印 | 生产锅次投料总重 | 理论添加量 | 否 |

## 生产单基准重量

生产单中的 `totalProductionG` 表示锅次成品净重。食材投料量按食谱生产损耗率放大：

```text
锅次投料总重 = totalProductionG × recipeSnapshot.production_loss_rate
```

生产单上的补剂实际添加量应使用同一个锅次投料总重作为基准，不再额外乘补剂损耗率。

示例：

```text
锅次成品净重 = 2962g
食谱生产损耗率 = 1.10
锅次投料总重 = 3258.2g
碘目标值 = 660μg/kg
海带片浓度 = 150μg/片
理论添加量 = 660 × 3.2582 ÷ 150 = 14.34片
```

生产单应显示 `14.34片`，不应显示额外加补剂损耗后的数量。

## 字段含义

| 字段 | 含义 | 使用场景 |
| --- | --- | --- |
| `netAmount` | 理论添加量，不含补剂损耗 | 用户侧展示、订单详情、厨房实际添加 |
| `purchaseAmount` | 采购/备料量，含补剂损耗 | 采购单、库存规划、成本覆盖 |
| `amount` | 历史混合字段，新增代码应优先使用明确字段 | 兼容旧数据 |
| `displayUnit` | 人类可读单位，如 `片`、`粒`、`g`、`ml` | 所有展示场景 |

新增代码只有在明确生成采购、库存预留或成本数量时，才允许加入补剂损耗。
