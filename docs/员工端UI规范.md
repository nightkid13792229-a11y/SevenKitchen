# 员工端 UI 规范（一页纸）

> 适用范围：小程序 `miniapp/` 下的员工端页面（采购、生产、库存、订单、客服、发货、食谱、工作台）。
> 第一批落地：采购管理 8 个页面（2026-11-02 ~ 11-03）。
> 配套：`miniapp/src/styles/staff-tokens.scss`、`miniapp/src/pages/staff-purchasing.ui.regression.spec.ts`

## 1. 色板

| Token | 值 | 用途 | 校验 |
|-------|----|------|------|
| `staff-ink` | `#26261F` | 主文字 | 白底 14.8:1 |
| `staff-ink-2` | `#6B6653` | 次要文字 | 5.58:1 |
| `staff-ink-3` | `#8A8A7E` | 占位/禁用/装饰 | 3.49:1，不用于正文 |
| `staff-bg` | `#FBFCF7` | 页面底色 | — |
| `staff-surface` | `#FFFFFF` | 卡片 | — |
| `staff-line` | `#EEF1E2` | 分隔线 | — |
| `staff-brand` | `#1E3A2F` | 主色 / 主按钮 / 导航 | 米白字 10.56:1 |
| `staff-cream` | `#F3EDDD` | 深色底上的文字 | — |
| `staff-gold` | `#B08D4F` | 装饰线、≥36rpx 加粗数字 | 大字 3.01:1 |
| `staff-gold-ink` | `#7A5C28` | 小号金色文字 | 浅底 ≥4.7:1 |
| `staff-gold-soft` | `#F6EFE0` | 徽标/提示浅底 | 配 `gold-ink` |
| `staff-brand-soft` | `#EEF2E4` | 徽标/分区浅底 | 配 `brand` |
| `staff-danger` | `#B4453A` | 驳回/删除/超支 | 浅红底 4.58:1 |
| `staff-danger-soft` | `#F8E8E2` | 危险浅底 | — |

**四条硬规则**

1. 深色底上只用 `cream` / `rgba(243,237,221,.72)`，禁止 `ink`。
2. 金色只做“大号数字 + 描边 + 装饰”，小字金色一律 `gold-ink`。
3. 金额常态用 `ink`，红色只表示驳回、删除、超支。
4. 固定底栏必须带 `env(safe-area-inset-bottom)`；内容区同步留白。

## 2. 字号（6 档）

| 用途 | 字号 |
|------|------|
| 页面大数字 | 40rpx |
| 区块标题 | 32rpx（加粗） |
| 列表主标题 | 30rpx（加粗） |
| 正文 | 28rpx |
| 次要正文 | 26rpx |
| 辅助说明 | 24rpx（最小；22rpx 停用） |

## 3. 间距与形状

- 页面左右 32rpx；卡片内 28rpx；卡片间距 16rpx；分区 24rpx
- 圆角三档：卡片 20rpx / 控件 12rpx / 药丸 999rpx
- 阴影两档：卡片 `0 6rpx 18rpx rgba(30,46,36,.05)`；浮层/底栏 `0 -4rpx 16rpx rgba(30,46,36,.06)`
- 触控最小 88rpx × 88rpx；文字型动作左右留 16rpx 以上

## 4. 页面结构

1. **导航**：深绿 `#1E3A2F` + 白字，标题只出现一次（系统导航栏），页面内不再写大标题。
2. **首屏**：先给“今天要做什么”（日期/状态/主按钮），再给列表；一屏尽量看到 2–3 条实际内容。
3. **清单卡**：三行制——`日期 + 类型 + 状态` / `种类 + 记录 + 金额` / `时间 + 动作`。
4. **详情行**：三行制——`名称 + 关键数量` / `渠道·规格·单价` / `订单·抵扣 + 小动作`；0 需求折叠。
5. **空态**：一句说明 + 一个下一步动作，不堆三遍同样的文案。

## 5. 组件约定

优先复用（后续抽到 `components/staff/`）：

| 组件 | 说明 |
|------|------|
| 页头 | 只用系统导航栏；需要上下文时用一行 `*-hint` |
| 状态徽标 | 浅底 + 深字，必须带文字，不只靠颜色 |
| 分段筛选 | 选中 = 深绿底米白字；未选 = 浅底深字 |
| 底栏 | 主按钮深绿、次按钮描边；左侧放汇总（进度/金额/已选） |
| 数量文本 | 数字 + 单位同 `nowrap`；拉丁单位加空格（148 g），中文单位不加（2 瓶） |

## 6. 防回归

提交前跑：

```bash
cd miniapp
npx vitest run src/pages/staff-purchasing.ui.regression.spec.ts
```

它会拦截：

- 同一条规则里 `color` 与 `background` 相同（对比度 1.0）
- 显式声明的“文字/底色”组合低于 WCAG AA（普通 4.5、大字 3.0）
- 有贴底固定栏但没写安全区

> 它不检查继承底色与真机渲染，这两项仍需截图走查（每种宽度 375 / 430）。
