# 微信开发者工具使用指南

> 本指南帮助你避免微信开发者工具的不稳定问题，建立稳定的开发工作流程。

---

## 🎯 核心原则

**重要：微信开发者工具是「预览工具」，不是「开发工具」**

- ✅ **在 VS Code 中编写代码**
- ✅ **使用自动化脚本编译**
- ✅ **在微信开发者工具中预览效果**
- ❌ **不要在微信开发者工具中修改代码**
- ❌ **不要让微信开发者工具自动编译**

---

## 📋 标准开发流程

### 第一次开发（项目初始化）

#### 1. 编译项目

在 `miniapp` 目录下运行：

```bash
./build-dev.sh
```

这个脚本会自动：
- 清理旧的编译文件
- 安装依赖（如果需要）
- 执行开发编译
- 验证输出结果

#### 2. 导入项目到微信开发者工具

1. 打开微信开发者工具
2. 点击左上角 **「导入项目」**
3. 填写信息：
   - **项目目录**：`/Users/zhaochen/Documents/SevenKitchen/miniapp/dist/dev/mp-weixin`
   - **项目名称**：`SevenKitchen (开发版)`
   - **AppID**：使用「测试号」或填入你的 AppID
4. 点击 **「导入」**

#### 3. 配置项目设置（仅第一次需要）

导入后，在微信开发者工具中：

1. 点击右上角 **「详情」**
2. 在 **「本地设置」** 标签页：
   - ✅ 勾选 **「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」**
   - ✅ 勾选 **「启用调试」**
   - ❌ **取消勾选**「自动保存时编译」
   - ❌ **取消勾选**「上传时自动压缩」
3. 在 **「基本设置」** 标签页：
   - 确认 **「调试基础库」** 版本 ≥ 2.30.0

### 日常开发流程

#### 步骤 1: 在 VS Code 中修改代码

在 `miniapp/src/` 目录下修改你的代码。

#### 步骤 2: 重新编译

保存文件后，在终端中运行：

```bash
./build-dev.sh
```

等待编译完成，看到「编译完成！」提示。

#### 步骤 3: 刷新微信开发者工具

**方式 1：清除缓存（推荐）**

在微信开发者工具中：
1. 点击顶部菜单 **「工具」**
2. 点击 **「清缓存」**
3. 选择 **「清除全部缓存」**
4. 确认清除
5. 点击 **「编译」** 按钮（或按 Cmd+B）

**方式 2：重新编译（如果方式 1 无效）**

在微信开发者工具中：
1. 点击顶部菜单 **「项目」**
2. 点击 **「重新构建」**
3. 等待构建完成

#### 步骤 4: 预览效果

- 在模拟器中查看效果
- 点击 **「预览」** 生成二维码，手机扫码预览
- 点击 **「真机调试」** 进行调试

## ⚠️ 常见问题及解决方案

### 问题 1：页面显示没有样式

**症状**：页面能显示内容，但完全没有样式，像简陋版 HTML。

**原因**：样式文件加载失败或编译不完整。

**解决方案**：

```bash
# 1. 完全清理编译输出
rm -rf dist/dev/mp-weixin

# 2. 清理依赖缓存（可选）
rm -rf node_modules/.vite

# 3. 重新编译
./build-dev.sh

# 4. 在微信开发者工具中清缓存
# 工具 → 清缓存 → 清除全部缓存 → 点击编译
```

### 问题 2：微信开发者工具反复自动编译

**症状**：修改代码后，微信开发者工具自动重新编译，导致预览窗口闪烁、报错。

**原因**：微信开发者工具监听了文件变化并自动编译，与 Vite 编译冲突。

**解决方案**：

1. 确保已取消勾选 **「自动保存时编译」**（见「第一次开发」步骤 3）
2. 使用 `build-dev.sh` 脚本手动编译
3. 编译完成后在微信开发者工具中点击 **「编译」** 按钮（Cmd+B）

### 问题 3：预览窗口报错或白屏

**症状**：模拟器显示错误信息或白屏。

**解决方案**：

1. **检查控制台错误**：
   - 点击 **「调试器」** 标签页
   - 查看 Console 中的错误信息
   - 根据错误信息修复代码

2. **清除缓存**：
   - 工具 → 清缓存 → 清除全部缓存
   - 重新编译

3. **重启微信开发者工具**：
   - 完全退出微信开发者工具
   - 重新打开项目

### 问题 4：编译后看不到变化

**症状**：代码已修改并重新编译，但效果没有变化。

**解决方案**：

```bash
# 1. 确认编译成功
./build-dev.sh
# 查看输出是否显示 "编译成功！生成了 XXX 个文件"

# 2. 在微信开发者工具中
# 清除全部缓存 → 重新编译

# 3. 如果还不行，完全重启微信开发者工具
```

### 问题 5：编译脚本执行失败

**症状**：运行 `./build-dev.sh` 报错。

**解决方案**：

```bash
# 1. 检查是否有执行权限
chmod +x build-dev.sh

# 2. 检查是否在正确的目录
pwd
# 应该显示: /Users/zhaochen/Documents/SevenKitchen/miniapp

# 3. 检查 node_modules 是否存在
ls node_modules
# 如果不存在，运行: pnpm install

# 4. 手动运行编译命令
pnpm run dev:mp-weixin
```

## 🚀 最佳实践

### 开发习惯

1. **代码修改 → 手动编译 → 刷新预览**
   - 不要依赖自动编译
   - 每次代码修改后都运行 `./build-dev.sh`
   - 编译完成后再刷新微信开发者工具

2. **定期清理缓存**
   - 每天开始开发前清一次缓存
   - 遇到奇怪问题时先清缓存

3. **使用版本控制**
   - 代码提交前确保编译成功
   - 不要在 Git 中跟踪 `dist/` 目录

4. **关闭不必要的功能**
   - 关闭「自动保存时编译」
   - 关闭「上传时自动压缩」（生产构建时再开启）

### 编译模式说明

#### 开发模式（dev）

```bash
./build-dev.sh
# 或
pnpm run dev:mp-weixin
```

- **输出目录**：`dist/dev/mp-weixin`
- **特点**：
  - 带热重载
  - 未压缩代码
  - 包含 sourcemap
  - 编译速度快
- **适用场景**：日常开发、调试

#### 生产模式（build）

```bash
pnpm run build:mp-weixin
```

- **输出目录**：`dist/build/mp-weixin`
- **特点**：
  - 代码压缩优化
  - 移除调试信息
  - 文件体积更小
  - 性能更好
- **适用场景**：发布前、测试正式版

## 📂 目录结构说明

```
miniapp/
├── src/                    # 源代码目录（在这里修改代码）
│   ├── pages/             # 页面文件
│   ├── components/        # 组件文件
│   ├── api/               # API 接口
│   └── utils/             # 工具函数
├── dist/                  # 编译输出目录（不要手动修改）
│   ├── dev/              # 开发模式输出
│   │   └── mp-weixin/    # 微信开发者工具导入这个目录
│   └── build/            # 生产模式输出
│       └── mp-weixin/
├── build-dev.sh          # 开发编译脚本
├── vite.config.ts        # Vite 配置文件
└── package.json          # 项目依赖配置
```

**重要**：
- ✅ 在 `src/` 中修改代码
- ❌ 不要手动修改 `dist/` 中的文件
- ✅ 修改代码后运行 `./build-dev.sh` 重新生成 `dist/`

## 🔧 调试技巧

### 1. 使用真机调试

模拟器有时与真机行为不一致，建议定期使用真机调试：

1. 点击 **「真机调试」** 按钮
2. 用微信扫描二维码
3. 在手机上打开调试页面
4. 查看真实效果

### 2. 查看网络请求

在微信开发者工具的 **「调试器」** 中：

1. 切换到 **「Network」** 标签
2. 触发 API 请求
3. 查看请求和响应详情
4. 检查请求参数和返回数据

### 3. 使用 console.log

在代码中添加日志：

```javascript
console.log('当前状态:', this.status);
console.log('API 响应:', response);
```

在 **「调试器」** → **「Console」** 中查看输出。

### 4. 断点调试

在 **「调试器」** → **「Sources」** 中：

1. 找到需要调试的文件
2. 在行号上点击设置断点
3. 触发代码执行
4. 查看变量值和调用栈

## 📞 获取帮助

如果按照本指南操作后仍然遇到问题：

1. **查看错误信息**：
   - 终端中的编译错误
   - 微信开发者工具控制台错误
   - 网络请求错误

2. **检查环境**：
   - Node.js 版本：`node --version`（建议 ≥ 18）
   - pnpm 版本：`pnpm --version`（建议 ≥ 8）
   - 微信开发者工具版本：确保是最新稳定版

3. **重置环境**（最后手段）：
   ```bash
   # 1. 删除所有编译输出和依赖
   rm -rf dist/ node_modules/

   # 2. 重新安装依赖
   pnpm install

   # 3. 重新编译
   ./build-dev.sh
   ```
