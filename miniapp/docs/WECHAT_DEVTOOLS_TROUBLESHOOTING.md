# 微信开发者工具问题修复指南

## 问题1: 域名校验错误

### 现象
```
http://localhost:3001 不在以下 request 合法域名列表中
request 合法域名校验出错
```

### 原因
微信开发者工具的"域名校验"设置覆盖了项目配置文件中的`urlCheck: false`设置。

**重要:** 即使配置文件中设置了`urlCheck: false`,开发者工具的本地设置也会覆盖它。

### 解决步骤
1. 打开微信开发者工具
2. 点击右上角**"详情"**按钮
3. 切换到**"本地设置"**标签页
4. ✅ **勾选**"不校验合法域名、web-view(业务域名)、TLS版本以及HTTPS证书"
5. 关闭详情面板
6. 重新编译项目(点击"编译"按钮)

### 验证
查看控制台,应该不再出现域名校验错误,API请求能够正常发送。

## 问题2: 本地存储超限

### 现象
```
writeFile:fail the maximum size of the file storage limit is exceeded
```

### 原因
微信小程序本地存储限制为10MB,缓存数据过多导致超限。

常见原因:
- 图片缓存过多
- API响应数据缓存过多
- 长时间运行的项目积累了大量临时数据

### 解决步骤

#### 方法1: 在开发者工具中清除缓存(推荐)
1. 点击微信开发者工具菜单栏的**"工具"**
2. 选择**"清除缓存"**
3. 选择**"清除全部缓存"**
4. 重新编译项目

#### 方法2: 在模拟器中清除数据
1. 在模拟器中,点击右上角**"..."**菜单
2. 选择**"清除缓存"**
3. 重新编译项目

#### 方法3: 删除项目后重新导入(彻底清除)
1. 关闭当前项目
2. 在项目列表中找到"SevenKitchen"项目
3. 点击**"删除"**图标(仅移除项目引用,不删除文件)
4. 点击**"+"**导入项目
5. 选择项目目录:`/Users/zhaochen/Documents/SevenKitchen/miniapp`
6. 重新编译

### 验证
重新编译后,控制台不应再出现存储超限错误。

**project.private.config.json:**
```json
{
  "setting": {
    "urlCheck": false
  }
}
```

**manifest.json (mp-weixin部分):**
```json
{
  "mp-weixin": {
    "setting": {
      "urlCheck": false
    }
  }
}
```

- DevTools检测 → 使用localhost

- 生产环境 → 使用生产域名

代码逻辑正确,问题在于开发者工具设置覆盖了配置。

## 常见问题FAQ

### Q: 为什么配置文件设置了urlCheck: false还是报域名错误?
A: 微信开发者工具的"本地设置"优先级高于项目配置文件,需要在工具界面中手动关闭域名校验。

### Q: 清除缓存后数据会丢失吗?
A: 开发环境下清除缓存是安全的,会清除模拟器中的本地存储数据。真实手机上的数据不受影响。

### Q: 存储超限问题反复出现怎么办?
A: 可能是代码中有数据缓存逻辑未及时清理,检查:
- 是否缓存了大量图片
- 是否有定时器不断存储数据
- 是否有内存泄漏导致数据持续增长
