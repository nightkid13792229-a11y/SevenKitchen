# 长图上的小程序码 —— 把图片放这里

## 需要做什么

从微信后台下载一张**小程序码**，命名成 `miniapp-code.png`，放在本目录下：

```
miniapp/src/static/delivery/miniapp-code.png
```

放好之后**不用改代码** —— 长图底部会自动出现：
码 + 「扫码打开小程序」+「看电子版、提售后、找客服」。

## 怎么下载

微信公众平台 → 小程序 → **设置** → 基本设置 → 小程序码与线下物料 →
**下载小程序码**。

选「**普通二维码**」或「小程序码」都行，尺寸选 **430×430** 或更大（太小的扫不出来）。

## 为什么现在没有它

小程序码是**微信后台生成的静态图片**，代码生不出来。
所以长图这边的做法是「**有素材就画、没素材就不画**」：

- 页面先用 `uni.getImageInfo` 探测这个路径
- 读得到 → 画（`print-canvas.ts` 的 `drawMiniProgramCode`）
- 读不到 → **整块不画**

**为什么不画个占位方块**：上线后顾客扫到的是空白 —— **比没有二维码更糟**。
宁可少一块，也不要给一个假的。

## 扫了跳哪儿

**小程序首页**（老板 2026-10-18 定），不是这张订单 —— 交付内容是私密的，
陌生人扫码不该看到别人的食谱。

因为是通用码，**一张固定图片就够**，不用按订单调接口生成 ——
长图渲染不用等网络，也不会因为生成失败少个角。
