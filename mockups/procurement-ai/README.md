## 2026-11-05 · 日采清单详情「原料明细」重构原型

打开 `detail-items.html`，截图见 `shots/p1b-items.png`。

数据取自 2026-11-03 真实日采清单：共 30 项（食材 23、补剂 7），其中库存足够 12、无需采购 14、待采购 4；关联订单 `SK20261102-005`、`SK20261102-004`，狗狗「皮蛋」，食谱「糙米红薯青花鱼牛肉」「鸭胸猪里脊鸡蛋青花鱼」。

设计要点：

- **进度分母 = 全部原料 30 项**，不再排除库存足够；库存足够、无需采购、已录入都算“已处理”，示例为 27/30。
- **库存足够的原料也列出来**，用「库存足够」徽标区分，并保留「采购记录」按钮，防止库存不准时无法补录。
- 原料卡片状态：待采购 / 库存足够 / 无需采购 / 已采购（有记录）；食材不显示品牌、渠道、规格、参考价，补剂和包材保留。
- **每张卡片只有一行操作**：左侧是状态或记录汇总，右侧是按钮；「无需采购」在最左、「采购记录」在最右，拉开距离避免误点。
- 已录入的记录默认折叠成「已录入 N 条 · ¥金额 · 查看明细」，点开才展开，不再每项挂一大块。
- 「关联订单」每单一行：订单号 · 狗狗 · 食谱。
