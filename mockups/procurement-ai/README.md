# 采购-报销 AI 接入 · 原型

对应设计文档：`docs/superpowers/specs/2026-11-04-procurement-reimbursement-ai-design.md`

打开 `prototype.html` 可看全部页面（已按 390×844 手机画布排版）。
`shots/` 里是逐页截图，可直接发给别人看。

| 文件 | 页面 | 说明 |
|---|---|---|
| `shots/p0-manage.png` | 采购管理（列表页） | 清单卡片加「含截图识别 N 条」，结构不变 |
| `shots/p1-list.png` | 采购清单详情 | 「用订单截图快速录入」入口常驻 |
| `shots/p2-upload.png` | 上传订单截图 | **不选渠道**；1~5 张，每张一笔订单 |
| `shots/p3-processing.png` | 识别中 | 按订单数显示进度；长图自动分段 |
| `shots/p4-review.png` | 识别结果核对（核心） | 顶部按订单切换、渠道可改、行级四态、每行可点开修改 |
| `shots/p4b-edit.png` | 修改一行 | 改数量/单价/原料/个人；改动会与截图比对 |
| `shots/p5-pick.png` | 选择原料 | 只列清单内原料，不做搜索；可标记个人 |
| `shots/p6-records.png` | 生成后的采购记录 | 「截图 / 手填」来源徽标，可编辑 |
| `shots/p7-submit.png` | 报销提交 | 金额、费用、凭证预填；显示凭证/报销/差额 |
| `shots/p8-detail.png` | 报销详情 | 待审核可撤回，撤回后清单解锁 |
| `shots/p9-admin-review.png` | 管理员审核台（第三期） | 审核 Agent 建议 + 凭证对比 + 通过/驳回/退回 |

示例数据取自真实订单 O2（盒马，实付 134.86）与 O7（沃尔玛，实付 208.26）：
盒马 5 行采购 ¥31.46、个人 4 行 ¥54.60、未匹配 2 行 ¥47.80，包装费 ¥1.00；
两单合计将生成 12 条记录、采购 ¥98.00。
报销单示例：报销 ¥32.46，凭证 ¥134.86，差额 ¥102.40。

图中手机外壳、状态栏仅为示意，实际实现以小程序现有底部栏和导航为准。
